# Code of the Trust Territory of the Pacific Islands, Volume 1, 1980 Edition

## Source and scope

Order 3027 pp 44–47 defines the four-district FSM unit and takes effect 1 October 1978. Title 3 section 1 pp 115–116 defines district island bounds. Central social-security arrangements and transitional powers continue; this is not proof of complete statistical reporting.
