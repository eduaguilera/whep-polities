# Russia (1991-2014)

## Summary

> **Correction (2026-07-29): `polygon_feature_year` 1991 -> 1992.** The row was
> drawing the USSR, not Russia. CShapes gwcode 365 has **six** time-steps that
> contain the year 1991: the durable `1991-2014` configuration (16,882,578 km2,
> Russia proper) and five transitional `1991-1991` steps recording the dissolution
> month by month. `build_database.py` matches `within` and then prefers a step whose
> START equals the queried year — which all six satisfy — so the winner was decided
> by order in the shapefile, and it landed on a 21,824,572 km2 step. The polygon
> measured **21,824,142 km2** against Russia's 17,098,242, and geometrically
> contained 12 live polities including Kazakhstan, Ukraine, Uzbekistan and the three
> Baltic states.
>
> 1992 is inside this row's span and is contained by only the `1991-2014` step, so it
> selects that configuration unambiguously. `RUS-2014-2025` needed no change: its
> `2014` matches both `1991-2014` and `2014-2019`, and the start-year preference
> resolves it correctly to the latter (16,907,946 km2).
>
> Found by a spatial containment check — no polygon should swallow a polity that
> coexists with it — which needs no reference data and no recorded area. The area
> check could not see this: `polygon_area_km2` is empty for this row, and that check
> only compares rows that record one. See
> [validate_spatial_containment](../../scripts/validate_spatial_containment.py) and
> issue 45.
