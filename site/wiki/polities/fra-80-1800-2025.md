# Somme (département)

## Summary

Somme is a French département in the Hauts-de-France region, on the English Channel coast at the mouth of the river of the same name, with its préfecture at Amiens. It is one of the roughly 83 original départements created by the 4 March 1790 Revolutionary administrative reform that replaced the old provinces (here, most of historic Picardy and part of Artois and Vimeu) with a uniform grid of units. Somme is not one of the four recognized departures this pipeline tracks for French subnational units: it was not carved from Alsace-Lorraine, not split off like the Territoire de Belfort, not part of the 1975 Corse split, and not a post-1946 overseas département. It has therefore kept its present administrative form, boundary, and INSEE code (80) continuously since 1790. This entry is `type: subnational` rather than `national` because Somme is an ordinary administrative subdivision of the sovereign state of France, not a state in its own right and not a historical territory with an identity distinct from the modern département -- the same reasoning already applied to the sibling département entries (Aisne, Calvados, and others) created in this same pipeline run. It exists as a row in this table only because a statistical source reports data for Somme specifically, at a finer grain than any national FRA row carries.

**Why this entry exists.** Input data: a juan-subnational series for Somme (NUTS code FRE23), per the routing verdict for unit FRA-FRE23, spanning data years 1862-2023 (97.6% observed/blank, 1.4% luh2_residual), all of which fall inside this entry's 1800-2025 span. Row count was not independently re-tallied in this authoring pass -- the verdict records the year range but not a row total, which is flagged as an open item for whoever next touches this entry's sourced_claims. Previously, in the absence of any Somme-level polity, this data had no natural home except one of the national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year), which would mean attributing département-scale series to the whole of metropolitan France -- a roughly ninety-fivefold territorial overstatement, since metropolitan France comprises around 95-96 départements of comparable size. What confirms Somme is a distinct, real administrative entity rather than an artifact of the source's labelling: it is one of the original 1790 départements, it carries its own INSEE code (80) and préfecture (Amiens), and it is the reporting unit behind NUTS3 code FRE23 in the EU's own statistical nomenclature -- this is not a source inventing a unit with no corresponding jurisdiction, but the standard French administrative and EU statistical geography for this territory.

## Territorial extent

**Polygon status:** Not yet assigned. No polygon available in the GeoPackage for this period. No registered source in this repository currently digitises French département boundaries: gadm-4.1-adm1 is registered but its locally-held file is an 81-country subset confirmed to exclude France (0 FRA features), and no other registered source (cshapes, cshapes-europe, paine, cliopatria, histogis-habsburg, constructed, reporting-areas) operates at department granularity for this period -- cshapes-europe/cshapes-2.0 carry only whole-France polities. A correct polygon would come from the full global GADM 4.1 admin-1 layer (not the local subset) or from an IGN ADMIN-EXPRESS/COG département shapefile, either of which almost certainly carries a Somme feature; obtaining and registering one of those sources is the blocking step, tracked as an open question below.

**Territory description:** Somme covers the north-central part of the Hauts-de-France region, bordered by the English Channel to the west, and by the départements of Pas-de-Calais, Nord, Aisne, Oise, and Seine-Maritime. Its modern extent is approximately 6,170 km2, a figure drawn from standard current INSEE/IGN reference statistics for the département (not measured from any geometry attached to this entry, since none is attached). A reader can locate it on a modern map as the département containing Amiens, Abbeville, and the Somme bay/estuary, and as the site of the WWI Battle of the Somme battlefields around Albert and Péronne. The département's boundary has not changed since its 1790 creation, so this description applies to the whole 1800-2025 span this entry covers.

## Predecessors and successors

Somme has no predecessor and no successor row in this table: it is one of the original ~83 départements created directly by the 4 March 1790 Revolutionary administrative reform, and it has never been split, merged, renamed, or ceded in whole or in part in the way that would justify a predecessor/successor edge (unlike Belfort, carved from Haut-Rhin in 1871, or the Alsace-Lorraine départements annexed 1871-1919). The département's INSEE code and boundary have been stable since creation, so this single entry spans its entire administrative life to date.

## Decisions

### d-start-year-1800-not-1790

**Start year set to 1800, not the 1790 creation date the routing decision proposed**

The routing decision for FRA-FRE23 argued for start_year 1790, the year the Revolutionary reform created Somme along with the other original départements. But the FRA national container chain in this table begins at FRA-1800-1871 -- there is no FRA polity row covering 1790-1800, and the containment gate rejects any container edge that falls outside the container's own span. Tiling this entry's container edges over 1790-1800 is therefore impossible without either fabricating an early-FRA container row (out of scope for this task) or shortening the span. Following the same resolution already used for the sibling entries created in this pipeline run (Aisne FRA-02, and others matching the 1800-2025 pattern), start_year is set to 1800 so the container chain has no gap. The département's actual administrative history still begins in 1790; the ten-year gap between creation and this entry's start is a table limitation, not a claim that Somme did not exist 1790-1800.

## Open questions

### oq-1790-1800-gap-uncontained

**Somme existed as a département from 1790, but no FRA container row covers 1790-1800**

This entry's span starts in 1800 rather than the département's actual 1790 creation date, purely because the earliest available FRA national container (FRA-1800-1871) does not reach back further. If any data source has valued rows for Somme dated 1790-1799, they currently have no eligible polity to route to at all (not even the national FRA rows, which also start at 1800). Resolving this would require either an early-FRA national row (FRA-1790-1800 or similar) or documented justification that no source in this pipeline ever reports at that resolution before 1800.

### oq-no-polygon-source-registered

**No registered geometry source in this repository currently digitises French départements**

gadm-4.1-adm1 is registered but the locally-held file is an 81-country subset that excludes France entirely (0 FRA features), and no other registered source (cshapes, cshapes-europe, paine, cliopatria, histogis-habsburg, constructed, reporting-areas) operates at French department granularity -- cshapes-europe/cshapes-2.0 only carry whole-France polities for this period. A real GADM 4.1 global admin-1 feature for Somme almost certainly exists outside this repo's curated subset, and IGN's ADMIN-EXPRESS/COG department layer is another candidate, but until one is added to the repository's source registry this entry has polygon_status unassigned rather than proxy or assigned.
