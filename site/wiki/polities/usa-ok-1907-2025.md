# Oklahoma (state of the United States)

## Summary

This entry tracks Oklahoma as a state of the United States, from its 1907-11-16 admission to the Union (the Oklahoma Enabling Act of 1906, merging the former Oklahoma Territory and Indian Territory) through the present. `type: subnational` because Oklahoma has never held sovereign statehood outside the US federal union — it is a first-order administrative division inside the national USA chain, the same status as every other US state entry in this family (e.g. ALK-1867-1959 before 1959 statehood changed Alaska's own type boundary). The span starts at 1907 rather than the 1894 start of the underlying USDA production data because the country convention's default start rule uses the year of formal administrative existence (admission to statehood), not the earliest year data happens to be reported for the future state's territory; the pre-1907 years are back-cast reconstructions onto a boundary that did not yet exist as 'Oklahoma,' not evidence the polity itself existed sooner. The end_year of 2025 reflects the database's standard present-day cutoff, since Oklahoma remains an unbroken US state with no administrative discontinuity to mark a successor.

**Why this entry exists.** **Input data:** USDA-sourced production/agricultural data for a unit labeled `OKLAHOMA`, spanning years 1894-1906 per the routing decision (the routing record does not give an exact row count, but characterizes the series as continuous single-state agricultural reporting, consistent with the format of sibling US-state entries created in this same pass).

**Previous match and why it was wrong:** before this entry, there was no Oklahoma-specific polity row in the table at all — the routing reasoning states 'Oklahoma has no existing polity match.' Absent a state-level entry, the USDA rows for `OKLAHOMA` would have had no home other than the national `USA-1867-1959`/`USA-1959-2025` rows, which is the wrong container: national-level totals are roughly fifty times the area and would silently absorb state-specific series as if they were national aggregates, the same failure mode documented for the Manchuria/China mismatch in the exemplar page.

**Confirmation this is a distinct reporting unit:** the source data itself labels the unit `OKLAHOMA` as a discrete state-level reporting geography (not a national aggregate or a differently-scoped region), and the state's own administrative history — formal admission to the Union in 1907 as the 46th state via the Oklahoma Enabling Act, merging two previously distinct federal territories (Oklahoma Territory and Indian Territory) — establishes Oklahoma as a genuinely separate administrative and statistical unit from both its predecessor territories and from the national United States figures it is nested inside.

## Territorial extent

**Polygon:** `gadm-4.1-adm1`, feature `USA.37_1`, `polygon_status: assigned`. This is the registered GADM 4.1 administrative level-1 layer, which — per the routing decision — contains exactly one feature named Oklahoma (`GID_1: USA.37_1`), matching the established pattern for other US states in this table (e.g. `USA.2_1` for Alaska on ALK-1867-1959). No construction or proxy substitution was needed; the feature is used directly because Oklahoma's state boundary is not disputed or subject to territorial-change history the way e.g. post-Trianon Hungary is.

**Territory description:** Oklahoma occupies the south-central United States, bordered by Texas (south and west, including the Panhandle), Kansas (north), Missouri and Arkansas (east), New Mexico (west), and Colorado (northwest corner). Its capital is Oklahoma City. The state's land area is commonly cited at approximately 181,038 km2 (about 69,899 sq mi), making it the 20th-largest US state — a figure independently documented in standard US Census Bureau state-area tables and used here as external corroboration of what the attached GADM polygon should measure, not derived from the geometry itself.

**Vintage note:** the GADM 4.1 layer is present-day (c. 2020s) vintage applied back to a state admitted in 1907. Oklahoma's external boundary has not changed since admission in any source consulted for this page, so the vintage risk is assessed as low, consistent with the routing decision's own note — but this has not been checked against a primary 1907 source, which is recorded as an open question below.

## Decisions

### d-code-follows-dominant-pattern

**Code follows the dominant <ISO3>-<SUBUNIT>-<start>-<end> pattern, not the ALK bespoke form**

The routing decision names an existing sibling, ALK-1867-1959, as the polygon-source precedent, but ALK is one of only three bespoke-code rows in the table and its code form (a historical territory name, not a subunit abbreviation) does not apply here. Oklahoma has no name distinct from the modern US state — there is no 'Territory of Oklahoma' identity worth preserving in the code the way 'Alaska' or 'Hyderabad' are historical polities in their own right that outlived a later administrative label. Oklahoma follows the 57-row dominant pattern used for the other US-state-shaped entries in this family: USA-OK-1907-2025.

### d-two-container-edges-required

**Container needs two edges to tile 1907-2025, not one**

The routing decision's proposed container_code is only USA-1867-1959, but that national era ends in 1959, 66 years before this polity's end_year of 2025. The polity table (data/final/polities_database.csv) shows the national USA chain split at 1959 into USA-1867-1959 and USA-1959-2025. This page instead lists two container edges, one per national era, so the containment gate does not reject a span reaching outside either party's coverage.

### d-1894-1906-rows-excluded

**Back-cast USDA rows for 1894-1906 are out of scope for this page's start_year**

The routing reasoning notes that USDA data for Oklahoma runs 1894-1906, predating the 1907 statehood this entry starts at, and describes those rows as a back-cast reconstruction onto the future state boundary. Per the country convention's default start rule (no departure listed for Oklahoma), those pre-statehood rows are routed as back_cast data attached to this polity's post-1907 span rather than causing the polity itself to start earlier; this page does not claim an 1894 start.

## Open questions

### oq-gadm-vintage-for-1907-boundary

**Does the GADM 4.1 present-day boundary match Oklahoma's 1907 admission boundary exactly?**

The attached polygon (gadm-4.1-adm1, feature USA.37_1) is a c.2020s administrative boundary. Oklahoma's external state line has been stable since 1907 in the historical record consulted for this page (no subsequent boundary adjustment is documented for the state as a whole), so the polygon_route memo's low vintage-risk assessment was accepted at face value. This has not been independently verified against a primary 1907 Enabling Act boundary description or a historical GIS layer, and county-level boundary churn within the state is a separate question from the external state line this polygon represents. If a mismatch is later found, this would need requalifying from assigned to proxy with a stated km2 delta.

### oq-1894-1906-usda-rows-routing

**Where do the 1894-1906 USDA back-cast rows actually get filed?**

The routing reasoning describes 1894-1906 USDA rows for Oklahoma as back_cast data routed to 'the proposed polity' despite predating its 1907 start_year. This page's own span is 1907-2025 per the default start rule, so it is not resolved here whether those 13 years of data are (a) filed under this code with a back_cast flag despite falling before start_year, (b) filed under Indian Territory / Oklahoma Territory precursor rows if any exist, or (c) dropped. No predecessor code is listed above because no Oklahoma Territory or Indian Territory row was found in the current polity table; if one is added later, it should become this page's predecessor and the 1894-1906 rows should route there instead.
