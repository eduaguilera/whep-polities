# Saint Lucia

## Summary

Saint Lucia is a Caribbean island nation in the Windward Islands, southeast of Martinique. WHEP tracks this row from 1838 (succeeding a separate row LCA-1800-1838) to 2025. The 1838 start year likely reflects the abolition of slavery and the end of the apprenticeship period in British Caribbean colonies, which was a significant social and economic transition point. Saint Lucia became independent on 22 February 1979. The predecessor LCA-1800-1838 row covers the earlier colonial period. COW assigns ccode=56 (stateabb=SLU) to St. Lucia, but the CSV has cow_code=57 — which is the COW code for St. Vincent and the Grenadines. This is a data error; see [Contradictions](#contradictions).

## Territorial extent

Polygon from CShapes 2.0. Biger (1995) gives: "area: 238 sq. miles [616 sq. km.]." CShapes records St. Vincent and the Grenadines (cowcode=57) as a single time-step from 1979-10-27 at area=0.029 sq deg, but this is the polygon for St. Vincent, not St. Lucia. The polygon used by WHEP for LCA-1838-2025 should be verified — if the CSV cow_code=57 was used to retrieve the CShapes polygon, the wrong polygon may be in use. ## Contradictions

**cow_code mismatch.** The CSV assigns cow_code=57 to LCA-1838-2025. COW ccode=57 is St. Vincent and the Grenadines (SVG); St. Lucia's correct COW code is 56 (SLU). CShapes cowcode=57 is also St. Vincent. The WHEP database may therefore be using the wrong polygon (St. Vincent's geometry) for Saint Lucia. This requires verification and correction: cow_code should be 56, and the polygon source should be confirmed as Saint Lucia's geometry.

## Open questions

### oq-cow-code-and-polygon-error

The CSV cow_code=57 is the COW code for St. Vincent and the Grenadines. St. Lucia's COW code is 56. If the CShapes polygon was retrieved using cowcode=57, the LCA rows in the database may contain St. Vincent's polygon rather than Saint Lucia's. The next ingest should verify the polygon geometry and correct both the cow_code field and, if necessary, the polygon.

### oq-1838-split-rationale

The split between LCA-1800-1838 and LCA-1838-2025 at 1838 is not documented in the CSV (notes=NA). The 1838 date corresponds to the end of the apprenticeship system following slave emancipation in British colonies. Whether this constitutes a WHEP-qualifying territorial change or merely a social/economic shift should be established with a sourced rationale.
