# Alpes-de-Haute-Provence (département)

## Summary

Alpes-de-Haute-Provence is a French département in the southeastern Alpine interior, one of the original ~83 units created by the 1790 Revolutionary administrative reform (under the name Basses-Alpes until a purely administrative 1970 renaming). It is entered here as `type: subnational` because a département is a sub-unit of the sovereign French state, not a state in its own right: France's own sovereignty and national-scale statistics belong to the FRA-* national chain (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025), and this row exists solely to carry data that a source tabulates at department scale for this specific unit. The routing decision found no existing polity match by name, confirmed this unit is not one of the four documented FRA departure cases (Territoire de Belfort, the Alsace-Lorraine trio, the Corsica 1793/1975 split, or an overseas département) that would require a non-default span, and so applied the country's default rule for an original Revolutionary département: creation-year start (1790) and an open end (2025), since the department is still current. The underlying department-level data (1862-2023) is reported as observed rather than back-cast, meaning the reporting territory and the administrative unit have tracked each other for the whole period the source actually measures.

**Why this entry exists.** This entry captures unit FRA-FRL01 ("Alpes-de-Haute-Provence") from the agent-harness routing pipeline: French department-level data spanning 1862-2023, reported as observed (not reconstructed via back_cast), meaning the source measured this specific territory directly across nearly its whole span. Before this entry, the unit had no polity match in the database at all — routing found no name match among existing rows, and Alpes-de-Haute-Provence is not one of the four documented FRA departure cases (Belfort, Alsace-Lorraine, the Corsica split, or an overseas département) that would call for a different span rule than the country default. Routing it to the national FRA-1919-2025 row instead would have folded a ~6,900 km² administrative subdivision into a national total roughly 80 times larger in area, exactly the kind of scale mismatch that is itself evidence the data was previously unmatched or would have been mis-routed. What confirms this is a distinct, addressable reporting unit rather than an arbitrary carve-out is straightforward administrative continuity: it has been one of France's original 1790 départements (under its earlier name Basses-Alpes) for 235 years, treated as a first-class INSEE reporting geography throughout, which is exactly the persistent unit type the country's routing convention directs should get its own row absent one of the four listed exceptions.

## Predecessors and successors

Alpes-de-Haute-Provence has no predecessor or successor row in this table. It is one of the original ~83 départements created directly by the 4 March 1790 Revolutionary administrative reform, formed out of parts of the former Provençal region (the historic County of Provence, itself part of the Kingdom of France since 1481), and named Basses-Alpes until a 1970 decree renamed it Alpes-de-Haute-Provence for regional-marketing reasons — an administrative renaming, not a territorial event, so no predecessor/successor edge is recorded for it. It has not been split, merged, or annexed since 1790 and remains a current French département, so end_year is open at 2025.

## Decisions

### d-code-choice-fra-04

**Chose FRA-04-1790-2025, the INSEE department number, following the dominant table pattern**

The dominant subnational pattern in the table (338 of 351 rows) is <ISO3>-<SUBUNIT>-<start>-<end>, and existing FRA subnational rows already use INSEE department numbers as the subunit token (FRA-02, FRA-08, FRA-14, FRA-18, FRA-19, FRA-21 through FRA-28, FRA-36, FRA-37, FRA-39, FRA-41, FRA-42, FRA-44, FRA-48 and others). Alpes-de-Haute-Provence is INSEE department 04, so FRA-04-1790-2025 both matches the cross-country default and the country-specific precedent already established for two dozen other French départements, unlike the two- or four-letter abbreviations (HP, PYRO) used for a handful of earlier FRA entries before the numeric-code precedent was set. FRA-04 was checked against both the built polities_database.csv and the wiki/polities directory and is unused.

### d-start-year-1790-not-1800

**Used 1790 (the department's actual creation) as start_year, per the routing decision's own span_basis, not 1800**

The routing decision explicitly derives start_year 1790 from the department's creation as Basses-Alpes in the 1790 Revolutionary reform, and end_year stays open at 2025 since the department is still current. The schema requires the code's years to equal the frontmatter's years, so the code is FRA-04-1790-2025, not FRA-04-1800-2025. This produces the same 1790-1800 containment gap already flagged as an open question on sibling entries FRA-PYRO-1790-2025 and FRA-HP-1790-2025 (later resolved there as FRA-1790-2025), since no FRA container row currently starts before 1800; it is recorded here as an open question rather than silently truncated, following that precedent rather than diverging from it.

### oq-boundary-stability-since-1790

**Has Basses-Alpes/Alpes-de-Haute-Provence's boundary been genuinely unchanged since 1790, beyond the 1970 name change?**

This entry treats the whole 1790-2025 span as one uniform territory on the strength of the general claim that French départements are comparatively stable administrative units, following the same reasoning already used for FRA-HP and FRA-PYRO. No department-specific check has been done here for 19th- or 20th-century canton/commune boundary transfers with neighbouring départements (Hautes-Alpes, Var, Vaucluse, Drôme) that might have altered its extent at the margins.
