# Thailand

## Summary

This row tracks Thailand for **117 years**, from the final territorial
loss to the database truncation year
[database](../../data/final/polities_database.csv).

Lost Malay states to Britain (1909) -- modern borders established.
Name changed from Siam to Thailand (1939). Never colonized. Stable
borders since 1909 (minor WWII-era Shan/Malay/Cambodian occupations
reverted post-war).

  Modern borders established.

- **1939: Name change.** Siam renamed Thailand.
  [biger-1995 §thailand](../sources/biger-1995.md#thailand)
