# Canada (original four provinces, 1866–1870)

Split from CAN-1866-1886 at 1870: the Dominion of Canada as constituted by the British
North America Act, before the 1870 transfer of Rupert's Land and the North-Western
Territory.

## Territorial extent

**Polygon status: unassigned.** No polygon is attached and none is claimed.

This page used to read "ESTIMATE polygon (composed GADM union: Ontario + Quebec + Nova
Scotia + New Brunswick) ~500,000 km²", and declared `polygon_source: gadm-4.1` with
`polygon_feature_id: NA` — a source named for a polygon that no recipe could produce,
which is why the row sat in the issue #3 polygon backlog. `polygon_status` was moved from
`estimate` to `unassigned` on 2026-08-04; the prose and the dangling
`polygon_source`/`polygon_feature_year` were brought into line on 2026-08-13.

**The named recipe is not the declared area, and neither describes 1866–1870.** GADM 4.1
adm1 Ontario ∪ Québec ∪ Nova Scotia ∪ New Brunswick measures **2,729,293 km²** in
ESRI:54034 (Ontario 1,080,890 + Québec 1,519,946 + Nova Scotia 55,488 + New Brunswick
72,969), which is **5.5x** the declared 500,000. The reason is the same one that withdrew
[can-1800-1866](can-1800-1866.md)'s polygon: modern Ontario and Quebec absorbed Rupert's
Land, Keewatin and Ungava between 1870 and 1912 — precisely the territory this row exists
to *exclude*, since it ends at the 1870 transfer. Using modern provinces here would
overstate the polity by more than the polity itself.

**No source here covers the period.** Cliopatria's Canada begins 1932 and CShapes' gwcode
20 begins 1886, so an honest gap is the correct state. `gadm41_CAN.gpkg` is present in
`data/geodata/` — the blocker is not missing data, it is that no available polygon has an
1866–1870 vintage.

`polygon_area_km2: 500000` is kept as a stated figure rather than deleted, following the
BLI-1833-1960 / AOI-1936-1941 convention for unassigned rows. It is retained under protest:
it is unsourced and it matches neither the recipe above nor any subset of it, so it should
not be used as evidence. See oq-can-1866-1870-area.

## Open questions

### oq-can-1866-1870-area

Where does `polygon_area_km2: 500000` come from? It is not the GADM union the page used to
name (2,729,293 km²) and no citation was ever recorded. Nothing in this repo derives it,
and no reference has been checked for it here, so whether it is a settled-area figure, an
1867-boundary figure or an invention is genuinely unknown. Until it is
sourced it should be treated as unverified; deleting it would lose the only quantitative
statement on the page, so it is flagged rather than removed.
