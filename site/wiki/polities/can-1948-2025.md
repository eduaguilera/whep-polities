## The 1948 boundary follows the referendum, not the accession (2026-07-24)

This row starts in **1948** because CShapes dates its Canadian boundary change to
**1948-07-22** — the date of the second Newfoundland referendum. The **accession
itself was 31 March 1949**, so calendar-1948 data covers a Canada that did *not*
yet include Newfoundland (9,553,644 km², against 9,952,067 km² after).

Two things surfaced this. Newfoundland's `iso3` was corrected from `CAN` to `NFL`
(see [nfl-1907-1949](nfl-1907-1949.md)), which removed it from Canada's matching
family; with only the two Canada rows left touching 1948, the shared-transition-
year convention then routed 1948 to *this* row — overstating that year's
territory by 398,115 km², about 4%.

**Fixed narrowly** by a year-scoped alias pinning `canada` 1948 to
[can-1886-1948](can-1886-1948.md), which is territorially correct. **The
underlying issue is this row's start year**: it should arguably be **1949** to
match the accession, which would make the alias unnecessary. That means renaming
the polity code, so it is recorded for a decision rather than done here.

Also noted: this page's frontmatter lists `predecessor: [CAN-1866-1948]`, **a code
that does not exist** — the chain's actual predecessor is
[can-1886-1948](can-1886-1948.md). A dangling reference, worth a sweep for others.
