# Vendée (département)

## Summary

Vendée is a French département on the Atlantic (Bay of Biscay) coast, in the Pays de la Loire region, in the historic province of Poitou. It is one of the roughly 83 original départements created by the 4 March 1790 Revolutionary administrative reform, and it is not one of the four recognized departures from that default history this pipeline tracks for French subnational units (not carved from Alsace-Lorraine, not the Territoire de Belfort split, not the 1975 Corse split, not a post-1946 overseas département), so it has kept its present administrative form continuously since creation -- most notably surviving the 1793-1796 War in the Vendée, a counter-revolutionary uprising fought within its borders, without any change to the department's own territorial extent. This entry is `type: subnational` because Vendée is an ordinary administrative subdivision of the sovereign state of France, not a state in its own right and not a historical territory with an identity distinct from the modern département -- the same reasoning already applied to sibling entries such as Aisne, Calvados, Cher, Côte-d'Or and Doubs created in this pipeline run. It exists as a row in this table because a source reports data specifically labelled for Vendée at a finer grain than any national FRA row carries; before this entry, that data had no département-level home.

**Why this entry exists.** Input data: per the routing decision (unit_id FRA-FRG05), a source reports a series labelled specifically for Vendée, spanning years 1862-2023, entirely inside this entry's 1800-2025 span; the exact row count and originating source name were not independently re-verified in this authoring pass (flagged in sourced_claims and open questions). Previously, in the absence of any Vendée-level polity, this data had no natural home except one of the national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year), which would mean attributing département-scale figures to the whole of metropolitan France -- a roughly ninety-fivefold territorial overstatement, since metropolitan France has around 95-96 départements of broadly comparable size. What confirms Vendée is a distinct, real administrative entity rather than an artifact of the source's labelling: it is one of the original 1790 départements, it carries its own INSEE code (85) and préfecture (La Roche-sur-Yon), Eurostat's GISCO NUTS classification independently assigns it the code FRG05 with official name "Vendée" (per data/final/nuts_code_names.csv, sourced from NUTS_AT_2021.csv), and the region's continuity is further attested by its being the site of a named historical episode (the War in the Vendée, 1793-1796) fought specifically within its borders -- not a source inventing a unit with no corresponding jurisdiction.

**Territory description:** Vendée is a coastal département in the Pays de la Loire region, in the historic province of Poitou, fronting the Atlantic Ocean (Bay of Biscay) to the west and bordering the départements of Loire-Atlantique to the north, Maine-et-Loire and Deux-Sèvres to the east, and Charente-Maritime to the south. Its administrative seat (préfecture) is La Roche-sur-Yon, a town purpose-built by Napoleon in 1804 as a new, more central capital after the département's role in the 1793-1796 War in the Vendée; other significant towns include Les Sables-d'Olonne on the coast and Fontenay-le-Comte, the pre-1804 seat. On a modern map it corresponds to INSEE département code 85, and includes the offshore Île d'Yeu and part of the Île de Noirmoutier. Its modern area is approximately **6,720 km²** (a figure quoted from published French administrative statistics for the present-day département, not measured from any polygon attached to this entry, since none is attached), making it one of the larger French départements by area, consistent with the broadly similar sizing intended for the 1790-era grid.

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the département's 1790 creation date, per the container floor**

The routing decision proposed start_year 1790, citing the 4 March 1790 Revolutionary reform that created Vendée along with the ~83 original départements (Vendée is named for the small river that crosses its southeastern corner, not for any prior province -- the pre-1790 area was carved from parts of Poitou, Aunis and Bas-Poitou). That administrative date is correct as département history, but it is not usable as this entry's start_year: the FRA container chain in the polity table begins at FRA-1800-1871 (cshapes-europe, first vintage 1816), and there is no France row covering 1790-1800 for this entry to container against. The containment gate rejects any edge that falls outside either party's span, so an 1790 start with no container for the first decade would fail immediately -- the container-floor rule the harness enforces (commit 11e8ca1). Rather than leave a gap or invent a France row this pipeline wasn't asked to create, this entry starts at 1800, matching the earliest available container and every sibling FRA département entry created so far (Aisne/02, Calvados/14, Cher/18, Côte-d'Or/21, Doubs/25, and others). The data this entry actually receives (1862-2023 per the routing decision) is unaffected either way, since it falls entirely inside 1800-2025. The 1790-1800 gap is left open below.

### d-subunit-code-is-insee-number

**Subunit code '85' follows INSEE numbering, matching the dominant ISO3-SUBUNIT pattern and the sibling département entries**

French départements are conventionally identified by their INSEE two-digit code rather than a postal, NUTS, or historical abbreviation. Vendée's INSEE code is 85 (the routing decision's admin_name 'FRG05' is a Eurostat NUTS-2021 code used only to look up the official name in nuts_code_names.csv, not the département's own administrative identifier, and is not reused as the polity code here). This keeps the code in the dominant <ISO3>-<SUBUNIT>-<start>-<end> family (57 of 66 subnational rows, and the established convention for every other French département entry created in this pipeline run) rather than treating Vendée as a bespoke historical territory. Vendée has no name-of-its-own distinct from the modern département's administrative identity -- the region's own historical episode, the 1793-1796 War in the Vendée, is a political/military event within the existing département's borders, not a claim that the territorial unit itself is discontinuous -- so bespoke-code treatment (like ALK or HYD) would be unwarranted.

## Open questions

### oq-1790-1800-gap-uncontained

**1790-1800 creation decade has no France container row to attach to**

Vendée existed as a département from March 1790, a full decade before this entry's start_year of 1800. The FRA container chain in the polity table begins at FRA-1800-1871, so there is currently no polity row representing France 1790-1800 for Vendée (or any other French département entered so far) to container against. If a pre-1800 France row is ever added to the table, this entry's start_year should be reconsidered and moved back to 1790, consistent with the département's actual creation date and the routing decision's original span_basis reasoning.

### oq-no-polygon-source-registered

**No registered, locally-present source can supply a Vendée boundary today**

The routing decision's polygon_reasoning found that gadm-4.1-adm1, the only registered source with département-level granularity for France, is present locally only as an 81-country subset that excludes France entirely (0 rows for FRA). cshapes-2.0 and cshapes-europe, the sources used for the national FRA rows, only carry whole-country geometry, not sub-national units. No union/difference of currently registered, locally-present features can construct Vendée's boundary. A real boundary certainly exists (GADM 4.1's full/global adm1 layer, IGN's ADMIN-EXPRESS/GEOFLA, or Eurostat GISCO's NUTS3 boundary set, which is where the 'FRG05' code used to resolve the official name originates) but none of these is registered in scripts/sources.yaml as a working route today, so polygon_source is 'none' and polygon_status is 'unassigned' rather than a proxy. This should be revisited once gadm-4.1-adm1 is re-sourced as its full global layer, or a GISCO/IGN product is registered for French départements.

### oq-row-count-and-data-quality-unverified

**Underlying row count and War-in-the-Vendée-era data quality were not checked in this authoring pass**

The routing decision states the underlying series spans 1862-2023 but does not give a row count, and this authoring pass did not independently query the source table to confirm it. Separately, Vendée's most territorially disruptive historical episode -- the 1793-1796 War in the Vendée counter-revolutionary uprising, with its severe population and production losses -- predates the 1862 data start by nearly seventy years, so it should not distort the series this entry actually receives; but this has not been explicitly verified against the source's earliest observed years, and it is worth a check if any pre-1870 data for Vendée is ever added upstream.
