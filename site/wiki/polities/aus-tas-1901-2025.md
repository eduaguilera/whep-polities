# Tasmania (state of Australia)

## Summary

This entry captures Tasmania as a state of the Commonwealth of Australia from Federation (1 January 1901) to the present (2025, open-ended per convention). It is `type: subnational` because Tasmania has never held sovereignty independent of Australia in this window -- it is one of the six original federating states, alongside New South Wales, Victoria, Queensland, South Australia and Western Australia -- and this row exists purely to carry any statistical series reported at the Tasmania-specific level rather than the Australia-wide level. Before 1901, the same island was the separate British colony of Tasmania (Van Diemen's Land before 1856), which is expected to be recorded in a distinct pre-Federation row (TAS-1825-1900) rather than folded into this one, since the constitutional status changed materially at Federation even though the territory and population did not. This row was created following the routing decision for unit AUS-TASMANIA, which found that the country's default Federation-start convention applies straightforwardly to Tasmania -- unlike border-drawing states such as Queensland, there is no ambiguity about what territory "Tasmania" denotes at 1901 versus 2025.

**Why this entry exists.** This row is created to hold any input data reporting statistics at Tasmania-state granularity from 1901 onward -- the routing decision names no specific dataset or row count for this unit, only that AUS-TASMANIA's data (starting 1860 per the decision) needs a home after Federation, since Tasmania's constitutional status changed from self-governing colony to Commonwealth state on 1 January 1901. Before this entry, the 1901-2025 portion of any such series had no dedicated subnational row to land in: it would either have been mismatched onto the national AUS row (which conflates Tasmania with the other five states and two territories) or onto the pre-Federation colonial row TAS-1825-1900, which is the wrong political entity for anything dated after 1900 given the country convention's default Federation-start rule for Australian states. That default rule -- and the precedent already set for AUS-ACT-1911-2025, the sole existing AUS subnational row in the table -- is the source that confirms Tasmania is treated as a statistically distinct reporting unit from the national total: Australian federal and colonial-era statistical collections (e.g. Commonwealth Bureau of Census and Statistics yearbooks) have reported Tasmania as a separate administrative division continuously since 1901.

**Territory description:** The state of Tasmania comprises the island of Tasmania -- located roughly 240 km south of the Australian mainland across the Bass Strait, centred near 42°S 147°E -- together with its offshore islands, principally Macquarie Island (a subantarctic island roughly 1,500 km southeast of Tasmania, administered as part of the state since 1900) and the smaller islands of the Furneaux and Hunter groups in Bass Strait. The state's total land area is approximately 68,400 km2 (roughly 90,800 km2 including Macquarie Island and other external territories, depending on convention), a figure drawn from current Australian Bureau of Statistics geography rather than measured from any polygon attached to this entry, since no polygon is attached. The boundary has not changed since Federation: this is the same landmass a reader would find labelled "Tasmania" on any modern map of Australia.

## Decisions

### d-code-pattern-aus-tas

**Code follows the dominant <ISO3>-<SUBUNIT>-<start>-<end> pattern, not the AUS-TASMANIA working id**

The routing decision's unit_id AUS-TASMANIA and the state name Tasmania are not a code. 338 of 351 subnational rows in the table use <ISO3>-<SUBUNIT>-<start>-<end>, and the one existing AUS subnational row (AUS-ACT-1911-2025) already follows it. Tasmania as an Australian state is not a historical territory with a name of its own in the sense the five bespoke codes (ALK, CAL, HAW, AUWA-style) are -- it is a standard federated state, structurally identical to the ACT entry already in the table. So AUS-TAS-1901-2025 was chosen over any bespoke alternative, using the standard three-letter ISO 3166-2 subdivision abbreviation TAS for Tasmania, matching the two-to-four letter subunit codes used elsewhere (BA, CAT, CF, ACT).

### d-drop-predecessor-edge

**Predecessor edge to TAS-1825-1900 dropped rather than asserted, per the prior rejection**

The routing reasoning describes a clean predecessor relationship from TAS-1825-1900 (Van Diemen's Land/Tasmania to Federation) into this new state-of-Australia row. But TAS-1825-1900 was already rejected once for declaring successor: ['AUS-1901-2025'] -- a generic national container code -- not any subnational Tasmania-state row, and that page cannot be edited from here. Rather than assert a one-directional predecessor edge that validate_chain_integrity will again reject (since the baseline in the other direction still points at AUS-1901-2025, not AUS-TAS-1901-2025), predecessor is left empty on this page. The relationship is real but only recorded as an open question naming the exact fix TAS-1825-1900 needs, since asserting it unilaterally would fail the same gate that rejected the previous answer, and leaving it entirely unremarked would hide a genuine coverage gap.

## Open questions

### oq-tas-1825-1900-successor-mismatch

**TAS-1825-1900 declares successor AUS-1901-2025, not this state-level Tasmania row**

TAS-1825-1900 (Van Diemen's Land / colonial Tasmania to Federation) currently lists successor: ['AUS-1901-2025'], the generic national container, rather than AUS-TAS-1901-2025 created here. That is very likely a modelling gap from before any Tasmania-specific post-Federation row existed, rather than a deliberate choice -- but this page cannot edit TAS-1825-1900, and asserting predecessor: [TAS-1825-1900] unilaterally on this page would reproduce exactly the asymmetric-edge failure this page was previously rejected for. The concrete fix: TAS-1825-1900's successor field should be changed from ['AUS-1901-2025'] to ['AUS-TAS-1901-2025'] in a future pass over that page, at which point this page's predecessor field should be updated to match and the edge will validate in both directions.

### oq-1900-single-year-gap

**Where does the single year 1900 (TAS-1825-1900's exclusive end year) actually get counted?**

The routing reasoning notes TAS-1825-1900 has end_year=1900 (exclusive), so it covers 1825-1899 only, leaving the calendar year 1900 itself uncovered by any Tasmania-specific row -- the reasoning proposes routing that single year to AUS-1800-1901 (Australian Colonies) instead. This page starts at 1901 and does not resolve that gap; it is a pre-existing question about TAS-1825-1900 and AUS-1800-1901's boundary, not something introduced by creating AUS-TAS-1901-2025. Confirming whether 1900 data was in fact routed to AUS-1800-1901, and whether that convention holds for the other Australian states noted in routing_concerns (e.g. Queensland), is unresolved here.

### oq-tas-no-polygon-registered

**No registered adm1 source currently covers Tasmania; the fetch that would fix this is unconfirmed**

The routing decision classified this as polygon_route: new_source_needed because the gadm-4.1-adm1 file present in this repository is an 81-country subset that excludes Australia entirely (0 AUS features), even though GADM's global adm1 layer (the same source family, just not the truncated local copy) would very likely contain Tasmania as a stable, uncontroversial state boundary. Whether fetching that global layer is licence-clear and worth doing now, versus waiting for a batch fetch across all missing AUS states (this table already implies at least Queensland has the same gap), is unresolved. Until then polygon_source is none and polygon_status is unassigned rather than proxy, since no other registered source (cshapes-2.0 is country-level only; geobr-ibge, paine, cliopatria, histogis are not applicable) offers even an approximate substitute.
