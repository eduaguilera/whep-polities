# Barcelona (province of Spain)

## Summary

Barcelona is one of the fifty provinces created by the 1833 Javier de Burgos territorial reorganization of Spain, which replaced the old kingdom/intendencia structure with a uniform grid of provinces used since for civil administration, elections, and statistical reporting. Barcelona sits in the northeast of Spain, on the Mediterranean coast, and is the most populous and economically significant province of Catalonia, containing the city of Barcelona itself. `type: subnational` because Barcelona never held sovereignty of its own — it is, and always has been, a first-order administrative division of the Spanish state, reporting into the ESP national chain for the entire 1833-2025 span. There is no predecessor/successor break: the province has not been split, merged, or renamed since its creation in 1833, unlike the Canary Islands provinces (created 1927) which required a later start year.

**Why this entry exists.** This entry captures administrative unit ES511 (Barcelona) as identified in Spain's NUTS/INE unit table, which the agent-harness routing pass matched against the existing ESP subnational rows and found no candidate: the three closest existing candidates were A Coruna (ESP-C), Madrid (ESP-M), and the national Spain polity (ESP-1800-2025), none of which is Barcelona province. This mirrors sibling units ES112-ES241, which were routed the same way in the same pass and were all create_new. Previously, any data keyed to "Barcelona" or ES511 would have had nowhere to route except the national ESP row, which is far larger in area and would have silently merged Barcelona-specific statistics into all-Spain totals. Federico-Tena and the INE both treat Spain's 50 provinces, including Barcelona, as the standard disaggregation unit for 19th-20th century Spanish statistics, which is the historical precedent for giving Barcelona its own row rather than folding it into the national series. Git status at the start of this session shows a prior esp-b-1833-2025.md deleted in the same pipeline pass that created 290 subnational polities and de-duplicated ledger-bug output (commit afe9dbd); this entry recreates that row against the current routing verdict for ES511.

## Decisions

### d-follow-default-1833-start

**Use the country-wide 1833 default start year rather than a Barcelona-specific date**

Barcelona is a standard mainland Spanish province created in the 1833 Javier de Burgos division, with no earlier distinct administrative identity that would justify a different start year. This matches the convention already applied to the other ESP provincial rows (e.g. ESP-BU-1833-2025, ESP-BI-1833-2025), all of which use 1833 unless the province was part of the 1927 Canary Islands split, which introduced a later start year for those provinces only. Barcelona is mainland Catalonia, not a Canary Islands unit, so no departure from the default is warranted.

### d-code-b-not-bcn

**Use single-letter code B, matching Spain's official province abbreviation, not a longer bespoke code**

The routing decision's proposed polity_name is 'Barcelona (province of Spain)' with no explicit code beyond the proposed candidate polygon feature 'B'. The dominant pattern for ESP subnational rows is <ISO3>-<SUBUNIT>-<start>-<end> using INE's official province abbreviations (e.g. ESP-BA for Badajoz, ESP-BI for Vizcaya/Bilbao). Barcelona's official INE/IGN abbreviation is B, so ESP-B-1833-2025 follows the established pattern rather than introducing a bespoke or three-letter code such as ESP-BCN; this is also the code implied by the git status showing a prior esp-b-1833-2025.md file deleted earlier in this same pipeline pass, and matches the polygon_feature_id 'B' given in the routing decision.
