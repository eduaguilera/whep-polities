# Ille-et-Vilaine (department)

## Summary

Ille-et-Vilaine is one of the original French departements created in the 1790 Revolutionary administrative reform, formed largely from the northeastern portion of the former province of Brittany, with its prefecture at Rennes. It has kept essentially the same borders and the same name for over two centuries, unlike the four documented departures from this default pattern (Territoire de Belfort split off from Haut-Rhin in 1871, the Alsace-Lorraine trio ceded and regained between 1871 and 1919, Corsica split into two departments in 1975, and the overseas departments created in 1946). `type: subnational` because Ille-et-Vilaine has never held sovereignty of its own -- it has always been a first-order administrative division inside France -- but France's national rows (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025) only carry country-level totals, and this entry exists to give a department-level reporting unit a code of its own when department-level statistics need one. No FRA subnational polity existed before this one, so there is no in-country precedent to depart from; the code follows the dominant cross-country <ISO3>-<SUBUNIT>-<start>-<end> pattern using France's own ISO 3166-2 numeric department code (35) rather than a letter abbreviation.

**Why this entry exists.** This entry captures a France, department-level administrative unit (Ille-et-Vilaine, INSEE code 35) for which the routing decision found no existing WHEP polity row: only the national FRA rows (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025) exist, which aggregate all French territory rather than isolating this department. Any department-level statistical series for Ille-et-Vilaine would previously have had nowhere to route except the national row, which is wrong because it would conflate one department's figures with all-France totals at roughly 1/91st the country's metropolitan area. What confirms this is a distinct, nameable administrative entity rather than an arbitrary subdivision is that it is one of France's ~83 original 1790 Revolutionary departements, a unit type with its own continuous 235-year administrative history, its own INSEE statistical code, and its own ISO 3166-2 subdivision code (FR-35) -- exactly the kind of first-order administrative division that GADM's ADM1 layer digitises worldwide and that this repository's subnational entries (e.g. the ESP province rows) exist to carry. This particular entry is being created now as part of a systematic sweep of France's original departements through the agent harness, following the same pattern already applied to Spain's provinces.

**Territory description:** Ille-et-Vilaine is a department in northwestern France, in the Brittany (Bretagne) region, with its prefecture at Rennes. On a modern map it sits in Brittany's northeastern corner: it borders the Manche department to the northeast across a short land boundary, Mayenne to the east, Maine-et-Loire to the southeast, Loire-Atlantique to the south, Morbihan to the southwest, and Cotes-d'Armor to the west, with a coastline on the English Channel around Saint-Malo and the Rance estuary in the north. Its official area today is approximately 6,775 km2 (INSEE figure for department 35), making it one of the larger Breton departments. It has not been subject to any territorial reorganization since 1790 comparable to the Belfort/Alsace-Lorraine/Corsica/overseas departures noted in the routing decision, so the 1800-2025 span is expected to describe one essentially unchanged territory throughout, subject to the unverified commune-level caveat in the open questions below.

## Decisions

### d-start-year-1800-not-1790

**Start year set to 1800, not the department's 1790 creation date**

The routing decision's proposed span was 1790-2025, following the default start rule for an original Revolutionary departement. But the polity table has no FRA container row that begins before 1800: the earliest national row is FRA-1800-1871. Extending this entry back to 1790 would leave 1790-1800 uncontained, which the containment gate rejects (an edge cannot fall outside either party's span, and there is no party to cover those ten years). Rather than fabricate a container edge referencing a row that does not exist, this entry starts at 1800, matching the earliest available container. This is a data-availability constraint, not a claim that Ille-et-Vilaine did not exist 1790-1800 -- it certainly did, under the same 1790 Revolutionary reform that created the other 82 original departements. If a pre-1800 FRA container row is ever added, this entry's start_year should move back to 1790 to match.

### d-subunit-code-numeric

**Subunit code chosen as ISO 3166-2:FR style, not an ad-hoc abbreviation**

France has no existing subnational polity rows, so there is no in-repo precedent to follow for this country specifically (the harness's own count says 0). The dominant cross-country pattern is <ISO3>-<SUBUNIT>-<start>-<end> using a short subunit code, as in ESP-AS or DZA-CVD. French departments are officially identified by INSEE/ISO 3166-2:FR two-digit numeric codes rather than letter abbreviations (Ille-et-Vilaine is 35), unlike Spain's provinces which use letter codes. Using the numeric code ('35') that a reader would recognize from any modern French map or postal address is more locatable than inventing a three-letter abbreviation with no external referent, so the code is FRA-35-1800-2025.

### d-polygon-unassigned-not-proxy

**Polygon status set to unassigned, not proxy or estimate**

The routing decision classified this as polygon_route: new_source_needed, specifically the full/global GADM 4.1 ADM1 download, which is not the locally cached 81-country subset currently on disk (that subset excludes France entirely -- 0 FRA admin-1 rows available today). Since no candidate feature can actually be attached right now, polygon_status is 'unassigned' with polygon_feature_id left null, rather than pointing at a feature that does not exist locally. This is different from a proxy decision (reusing a real, already-available feature from another period) -- there is nothing to reuse yet.

## Open questions

This entry needs the GADM 4.1 admin-1 boundary for Ille-et-Vilaine (expected GID_1 pattern FRA.35_1, unverified since the France rows aren't in the locally cached subset), but the locally stored GADM 4.1 ADM1 data covers only 81 countries and France is not one of them. ### oq-1790-1800-uncovered

**1790-1800 is real history this entry does not cover**

Ille-et-Vilaine was created in 1790 along with the other original departements, ten years before this entry's start_year of 1800. That decade (Revolutionary Wars, the Terror, the Directory) is not nothing -- it's simply uncontainerable today because no FRA polity row exists for it. If a pre-1800 FRA national or Revolutionary-period row is ever added to the table, this entry should be re-spanned to 1790-2025 and a new container edge added, rather than leaving a silent decade-long gap in the department's own history.

### oq-boundary-stability-unverified

**Commune-level boundary changes across 225 years are asserted, not checked**

The routing decision's vintage_risk note says French departments have been 'geographically stable since their 1790 creation' with only minor commune-level adjustments (citing 1801 and WWII-era reorganizations as examples). That claim has not been checked against any documented boundary-change record for Ille-et-Vilaine specifically -- it is a general claim about French departments as a class. A modern GADM snapshot used as the eventual polygon would silently encode whatever the current (post-2015) boundary is, including any commune transfers between Ille-et-Vilaine and its neighbours (Manche, Mayenne, Maine-et-Loire, Loire-Atlantique, Morbihan, Cotes-d'Armor) that happened at any point 1800-2025. No such transfer is known to be large enough to matter at country-level statistical resolution, but none has actually been ruled out either.
