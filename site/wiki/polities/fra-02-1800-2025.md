# Aisne (département)

## Summary

Aisne is a French département in the Hauts-de-France region, in the historic province of Picardy, on the Belgian frontier. It is one of the roughly 83 original départements created by the 4 March 1790 Revolutionary administrative reform that replaced the old provinces with a uniform grid of units, and it is not one of the four recognized departures from that default history that this pipeline tracks for French subnational units (it was not carved from Alsace-Lorraine, not split off like the Territoire de Belfort, not part of the 1975 Corse split, and not a post-1946 overseas département), so it has kept its present administrative form continuously since creation. This entry is `type: subnational` rather than `national` because Aisne is an ordinary administrative subdivision of the sovereign state of France, not a state in its own right and not a historical territory with an identity distinct from the modern département -- the same reasoning already applied to the sibling entries for Calvados, Cher, Côte-d'Or and Doubs created in this same pipeline run. It exists as a row in this table only because a statistical source (mitchell) reports production/agricultural data for Aisne specifically, at a finer grain than any national FRA row carries; before this entry, that data had no département-level home and would have had to be routed to whichever national FRA row spans the relevant year -- a roughly ninety-fivefold territorial overstatement relative to Aisne's actual extent, since metropolitan France has around 95-96 départements.

**Why this entry exists.** Input data: mitchell reports a production/agricultural series labelled specifically for Aisne, per the routing decision, beginning in 1862 and falling entirely inside this entry's 1800-2025 span (row count not independently re-verified in this authoring pass -- flagged in sourced_claims). Previously, in the absence of any Aisne-level polity, this data had no natural home except one of the national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year), which would have meant attributing département-scale series to the whole of metropolitan France. **Territory description:** Aisne is a landlocked département in the Hauts-de-France region, in the historic province of Picardy, bordering Belgium's Wallonia region to the north and the départements of Nord, Ardennes, Marne, Seine-et-Marne, Oise and Somme. Its administrative seat (préfecture) is Laon; other significant towns include Saint-Quentin and Soissons. On a modern map it corresponds to INSEE département code 02, drained by the Aisne, Oise and Marne rivers, and it is well known as the site of repeated First World War front lines (the Chemin des Dames ridge runs through it). Its modern area is approximately **7,369 km²** (a figure quoted from published French administrative statistics for the present-day département, not measured from any polygon attached to this entry, since none is attached -- consistent with the general pattern that 1790-era départements were drawn to a broadly similar size, crossable on horseback in a day from any point to the seat).

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the département's 1790 creation date, per the container floor**

The routing decision proposed start_year 1790, citing the 4 March 1790 Revolutionary reform that created Aisne along with the ~83 original départements. That administrative date is correct, but it is not usable here: the FRA container chain in the polity table begins at FRA-1800-1871 (cshapes-europe, first vintage 1816), and there is no France row covering 1790-1800 for this entry to container against. The containment gate rejects any edge that falls outside either party's span, so an 1790 start with no container for the first decade would fail immediately -- this is the container-floor rule the harness now enforces (commit 11e8ca1). Rather than leave a gap or invent a France row this pipeline wasn't asked to create, this entry starts at 1800, matching the earliest available container, and the 1790-1800 gap is left open below, exactly as done for the sibling entries FRA-14-1800-2025 (Calvados) and FRA-18/21/25-1800-2025. The data this entry actually receives (mitchell, from 1862 per the routing decision) is unaffected either way, since 1862 falls entirely inside 1800-2025.

### d-subunit-code-is-insee-number

**Subunit code '02' follows INSEE numbering, matching the dominant ISO3-SUBUNIT pattern and the sibling département entries**

French départements are conventionally identified by their INSEE two-digit code rather than a postal or historical abbreviation. Aisne's INSEE code is 02. This keeps the code in the dominant <ISO3>-<SUBUNIT>-<start>-<end> family (57 of 66 subnational rows, and now the established convention for every French département entry created in this pipeline run: 14, 18, 21, 25, and this one) rather than treating Aisne as a bespoke historical territory. Aisne has no name-of-its-own distinct from the modern département and is not one of the four listed departures from the default départment history (not Territoire de Belfort, not an Alsace-Lorraine département, not the Corsican split, not a post-1946 overseas département), so bespoke-code treatment (like ALK or HYD) would be unwarranted.

## Open questions

### oq-1790-1800-gap-uncontained

**1790-1800 creation decade has no France container row to attach to**

Aisne existed as a département from March 1790, a full decade before this entry's start_year of 1800. The FRA container chain in the polity table begins at FRA-1800-1871, so there is currently no polity row representing France 1790-1800 for Aisne (or any other French département entered so far -- Calvados, Cher, Côte-d'Or, Doubs) to container against. If a pre-1800 France row is ever added to the table, this entry's start_year should be reconsidered and moved back to 1790, consistent with the département's actual creation date and the routing decision's original span_basis reasoning.

### oq-no-polygon-source-registered

**No registered, locally-present source can supply an Aisne boundary today**

The routing decision's polygon_reasoning found that gadm-4.1-adm1, the only registered source with département-level granularity for France, is present locally only as an 81-country subset that excludes France entirely (0 rows for FRA). cshapes-2.0 and cshapes-europe, the sources used for the national FRA rows, only carry whole-country geometry, not sub-national units. No union/difference of currently registered, locally-present features can construct Aisne's boundary. A real boundary certainly exists (GADM 4.1's full/global adm1 layer, or IGN's ADMIN-EXPRESS/GEOFLA for France specifically) but is not registered in scripts/sources.yaml today, so polygon_source is 'none' and polygon_status is 'unassigned' rather than a proxy. This should be revisited once gadm-4.1-adm1 is re-sourced as its full global layer, or an IGN product is registered.

### oq-wwi-front-line-territorial-disruption-unaddressed

**Aisne's 1914-1918 front-line status is not reflected in the territorial/data record**

Unlike the other French départements entered in this pipeline run, Aisne sat directly on the Western Front for most of the First World War (the Battles of the Aisne, the Chemin des Dames, and Second Battle of the Marne were all fought within or adjacent to it), and parts of the département were under German occupation or contested from 1914 to 1918. This entry's container basis treats 1871-1919 as continuous, unaffected metropolitan French territory, which is true in the strict sovereignty/administrative sense (France never ceded Aisne), but any agricultural or production series (e.g. mitchell) reporting Aisne data for 1914-1918 may reflect wartime devastation or occupation-period non-reporting rather than ordinary peacetime figures. Whether the underlying series this entry receives actually cover those years, and if so whether they need a data-quality flag, has not been checked in this authoring pass.
