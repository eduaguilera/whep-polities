# Latin America Other


> **RETIRED 2026-08-05 — replaced by [rlam-1850-2025](rlam-1850-2025.md) (issue 50).**
>
> The end year 2013 was an artefact of when this row was written. FAOSTAT reports this
> reporting area through 2024, so this bucket stopped before the data did and its most
> recent years resolved to nothing. The replacement ends 2025 and carries the same
> polygon, regenerated under the new code.
>
> `polygon_status` is therefore `unassigned` here, and that is a statement of fact
> rather than a downgrade: `scripts/sources/reporting-areas/build.py` keys its
> features by `polity_code`, so once the source was regenerated no feature carries
> this code and this row genuinely has no geometry. Leaving it `assigned` would have
> been a page asserting a polygon that does not exist — which
> `validate_polygons` check C caught immediately.
## Summary

> **`polygon_status` migrated derived -> assigned (2026-07-29).** `derived` is a legacy value that predates the documented vocabulary in [wiki/README.md](../README.md#page-schema), which says not to use it in new pages. It was never migrated, so the manifest's `claims_polygon_status` set omitted it and consumers were told this row does not claim a polygon. The polygon is composed from its members by `scripts/sources/reporting-areas/build.py`, so it IS this row's territory by construction. See [lint-polygon-status-vocabulary](../log.md#lint-polygon-status-vocabulary).


WHEP aggregate reporting-area row for residual Latin American and Caribbean territories in WHEP harmonization tables. The 1850-2013 range follows the current WHEP land-footprint production rows for area code 904.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** WHEP Latin America Other component territories from `regions_full.csv`, including Caribbean overseas territories and the Netherlands Antilles successor-island proxy polygons.
- **Proxy note:** This is a residual reporting-area polygon, not a country polygon.

## Sourced Claims

- `inst/extdata/regions.csv` in WHEP records `RLAM`, area code 904, as Latin America Other.
- `inst/extdata/harmonization/regions_full.csv` lists the component territories grouped under `RLAM`.
