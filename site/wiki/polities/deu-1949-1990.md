# Germany (divided, 1949-1990)

## Summary

Germany as an undifferentiated statistical aggregate during the Cold War
partition, from the parallel foundings of the Federal Republic of Germany
(FRG, 23 May 1949) and the German Democratic Republic (GDR, 7 October 1949)
to reunification on 3 October 1990. This row captures input data streams
that report "Germany" as a single country for the 1949-1990 window without
distinguishing between the two states.

Two companion rows exist for datasets that *do* distinguish:

- [f77-1949-1990](f77-1949-1990.md) — East Germany (GDR)
- [f78-1949-1990](f78-1949-1990.md) — West Germany (FRG)

Per the WHEP polity rule
([decision-whep-polity-definition](../log.md#decision-whep-polity-definition)),
these three rows overlap in time but not in data sources: any given input row
maps to exactly one of them depending on how it's labelled.

## Territorial extent

**Polygon:** `constructed` source, feature `DEU-1949-1990`. Built by
`scripts/sources/constructed/build.py` as the **union of CShapes 2.0 gwcode
260 (FRG) and gwcode 265 (GDR)** using the 1949-1990 time-steps. The area
(~356,800 km²) equals FRG (247,553 km²) + GDR (109,272 km²) exactly. Same
territorial extent as the preceding [deu-1945-1949](deu-1945-1949.md)
(Allied-occupied Germany) and the succeeding
[deu-1990-2025](deu-1990-2025.md) (unified Germany post-reunification) —
Germany's post-war borders were set at Potsdam and didn't move again.

**Why this entry exists:** The pre-1961 agricultural input data reports
"Germany" (iso3c=DEU) as a single country for all 1949-1961 rows. Without
this polity the matcher was routing those rows to
[f78-1949-1990](f78-1949-1990.md) (West Germany alone), which under-counted
the geographic coverage by ~30% (the East Germany share). This row maps
`DEU 1949-1990 → DEU-1949-1990` via natural iso3 lookup — no
`normalise_iso` rewrite needed. The old `DEU → F78` rewrite in
`pipelines/pre1961-matching/match.R` was removed.

## Predecessors and successors

- **Predecessor:** [deu-1945-1949](deu-1945-1949.md) — Allied-occupied
  Germany. Same territory; regime transition from four-power occupation to
  the parallel FRG / GDR foundings in 1949.
- **Successor:** [deu-1990-2025](deu-1990-2025.md) — unified Germany after
  3 October 1990. Same territory; the reunification merged FRG and GDR into
  a single state.

## Decisions

- Created 2026-04-17. Previously the matcher used a `DEU → F78` rewrite,
  implicitly treating undifferentiated "Germany" data as West-German-only.
  Rationale for change: the pre-1961 input reports a single "Germany" stream
  1949-1961 with no companion DDR/FRG rows, so the aggregate must refer to
  the full geographic Germany. Using F78 alone halved coverage on the map
  and in aggregate statistics.

## Open questions

### oq-post-1961-dataset-labelling

The WHEP pre-1961 dataset has no DDR/FRG-specific rows. FAOSTAT and later
datasets do report the two states separately. The F77 / F78 polities remain
load-bearing for those; DEU-1949-1990 specifically absorbs the
undifferentiated "Germany" stream that pre-1961 compilations use.
