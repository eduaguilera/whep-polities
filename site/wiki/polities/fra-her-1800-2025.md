# Hérault

## Summary

Hérault is one of the original 83 départements created by the French Revolutionary administrative reform of March 1790, carved from parts of the former province of Languedoc around the city of Montpellier. It is a `type: subnational` entry because France held continuous national sovereignty over this territory throughout the span; the entry exists only to carry a reporting-territory distinct from the national FRA row, since data sources tabulate Hérault-level agricultural and economic statistics separately from all-France totals. `start_year` is set to 1800 rather than the department's actual 1790 creation date because no FRA container row exists to cover 1790-1800 in the current polity table (the earliest national French row is FRA-1800-1871/FRA-1800-1919, starting in 1800); the department's real administrative continuity goes back further, but this page's span is bounded by what the containment chain can actually tile. Hérault has none of the four departures the country convention enumerates for French départements (it is not Belfort, not part of the Alsace-Lorraine cession/reintegration, not a product of the Corse 1975 split, and not an overseas département), so its span runs to the present (2025, open end_year by convention).

**Why this entry exists.** This entry captures routed input data for admin unit FRA-FRJ13 (Hérault) spanning data years 1862-2023, drawn from at least one national agricultural/economic statistics source keyed to French départements (the routing decision's evidence base). Before this page, no polity row existed for Hérault specifically: the routing pipeline found "no name match among existing polities," meaning any Hérault-labelled rows would previously have fallen through to an unmatched/unassigned bucket or been mis-routed to the all-France national row FRA-1919-2025 or FRA-1800-1919, which is roughly 15-20x Hérault's actual departmental area and would have mixed department-level statistics into national totals. What confirms Hérault is a distinct, separately-tabulated reporting unit rather than an artifact of one idiosyncratic source: French départements are the standard NUTS-3-equivalent statistical and administrative unit used by INSEE and by international compilers (e.g. Mitchell's International Historical Statistics tabulates French agricultural production by département for many series), so a département-level label in the source data reflects the actual collection unit, not a one-off aggregation choice.

## Territorial extent

**Polygon status:** Not yet assigned. No polygon is currently attached in the GeoPackage for this period. `polygon_source` is set to `gadm-4.1-adm1` (a registered source, not `none`) because GADM 4.1 ADM1 is the correct and standard registered source for French département boundaries, and is already used elsewhere in this table for other countries' first-level administrative subdivisions. However, the specific gadm-4.1-adm1.gpkg file present in this repository's local geodata is a subset covering only 81 countries, and France is not among them, so Hérault's feature cannot be identified or attached from what is on disk today. This is a "right source, not fetched" situation (`registered_source_unfetched`) rather than a source gap, hence `polygon_status: unassigned` and `polygon_feature_id: null` rather than `polygon_status: none` — fetching the full or France-specific GADM 4.1 ADM1 release would resolve it directly.

**Territory description:** Hérault is a département in the Occitanie region of southern France, on the Mediterranean coast, with its préfecture at Montpellier. It is bounded by the départements of Gard to the east, Aveyron and Tarn to the north/northwest, Aude to the southwest, and the Mediterranean Sea to the south. Its modern area is approximately **6,224 km2**, per INSEE's current department listing. Because it was created in 1790 as one of the original Revolutionary départements and has not undergone the kind of large-scale territorial reorganization seen in border départements (unlike Alsace-Lorraine, Belfort, or Corse), the assumption underlying this page is that its boundary is essentially the same shape a present-day GADM polygon would show — though this has not been independently verified against a historical atlas (see open questions).

## Decisions

### d-start-year-1800-not-1790

**Span start set to 1800, not Hérault's actual 1790 creation date**

The routing decision proposed start_year 1790, reasoning that Hérault was among the original 1790 Revolutionary départements and none of the four listed exception rules for French départements apply to it. However, the containment requirement is that container edges must tile the entire polity span with no gap, and the earliest national France row available in the current polity table (FRA-1800-1871 / FRA-1800-1919) begins in 1800, not 1790. There is no FRA container row covering 1790-1800. Rather than leave a 10-year uncontained gap at the start of the span (which the containment gate would reject), this page sets start_year to 1800, matching the earliest available container edge. This is a containment-driven adjustment, not a claim that Hérault did not exist as a distinct department in 1790-1800; it is a decision to keep this row's declared span inside what the table can currently container. If a pre-1800 FRA container row is ever added, this page's start_year should be revisited.

## Open questions

### oq-polygon-not-fetched

**GADM 4.1 ADM1 France slice has not been fetched into the local geopackage**

Hérault is a standard mainland French département and GADM 4.1 ADM1 is the correct registered source for this administrative level, used elsewhere in this table for other countries' first-level subdivisions, but the gadm-4.1-adm1.gpkg file present in this repository's data/geodata covers only 81 countries and France is not among them. polygon_status is therefore 'unassigned' rather than 'assigned' or 'proxy': the source is registered and known-correct, it simply has not been fetched into the local file yet. Resolving this requires fetching the full (or France-specific) GADM 4.1 ADM1 release and identifying Hérault's feature within it, then verifying the feature ID against the actual file once fetched, since GADM's internal numbering for France's départements has shifted between releases.

### oq-department-boundary-stability

**Has Hérault's département boundary been genuinely stable since 1790/1800, or were there commune-level border adjustments with neighbouring départements?**

This page assumes Hérault has 'retained its present form' across its span, which is what would justify using a present-day GADM 4.1 boundary as a proxy once fetched. French départements have in fact had minor commune-level boundary adjustments over two centuries (individual communes transferred between neighbouring départements during various reorganizations), and no check was done here against a historical atlas or INSEE's own boundary-change records to confirm none affected Hérault specifically, versus its neighbours Gard, Aveyron, Tarn, or Aude. If such an adjustment exists, a future GADM-derived polygon would carry a small documented discrepancy rather than being an exact historical match.

### oq-data-coverage-vs-span

**Routed data years (1862-2023) leave 1800-1862 and 2024-2025 without confirmed data coverage**

This page's span is 1800-2025 (bounded by container availability, per the decision above), but the evidence described in the routing decision only covers observed data years 1862-2023. Nothing in the input data confirms statistics for Hérault between 1800 and 1862, nor for 2024-2025. The span is inherited from the container chain's eras and the department's presumed administrative continuity, not from direct evidence across every sub-interval, and a reader should not assume dense data coverage across the full span from this page alone.
