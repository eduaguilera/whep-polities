# Principality of Serbia (1816-1878)

Autonomous Ottoman vassal, ~38,000 km². No CShapes coverage (floor 1886). Cliopatria c.1830 feature not yet extracted into the WHEP pipeline. Using any post-1878 polygon overstates by ~21-26%.

## Border era inside this row, and why it is not split (issue 686, 2026-10-07)

Issue 686 listed the 1833 enlargement: the 1830/1833 hatt-i serif added six nahiyas (Krajina, Crna Reka,
Paracin, Krusevac, Stari Vlah, Jadar-Radjevina). **The row is not split.** It has no polygon for either
era (`polygon_status: unassigned`): Cliopatria has no Serbian polity between 1816 and 1878, and CShapes
and CShapes-Europe start Serbia in 1879. A split would create two rows with no geometry and move no data
(layer B starts in 1850, so every routed year is after 1833). The 1816-1832 era is recorded here; if a
polygon for the principality is ever fetched, the split should be made with it.
