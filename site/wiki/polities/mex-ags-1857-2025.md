# Aguascalientes

## Summary

Aguascalientes is one of the 31 states of the United Mexican States, a small landlocked entity on the central Mexican plateau roughly 500 km northwest of Mexico City. It was formally erected as a state of the federation in 1857, having previously been a partido/territory administered under Zacatecas. This entry is `type: subnational`: Mexican sovereignty is carried by the national rows (MEX-1821-1848, MEX-1848-2025), and this row exists only to carry the sub-national reporting territory that agricultural statistics are published against, mirroring the pattern used for other Mexican states and for entries such as ESP-AS-1833-2025. No prior polity in the MEX vocabulary represented Aguascalientes specifically — only the two national-level MEX rows existed before this one, and the national row merely *contains* the state, it does not *stand in for* it. The start year (1857) follows the routing decision's default rule rather than one of the three enumerated departures from it (Baja California, Baja California Sur, Quintana Roo, which were former federal territories converted to states much later, in 1931-1952); Aguascalientes was already a full state by the mid-19th century and has not been reorganized, split, or absorbed since, so a single span to the present (2025) is appropriate. The end year is the open "still exists" default, not evidence of any change in 2025 itself.

**Why this entry exists.** Input data: 124 years of valued agricultural statistics keyed to the label "Aguascalientes" (as reported in Mexican federal-entity-level agricultural series, per the routing decision), with the earliest rows dated to around 1900, well inside the 1857-2025 span this entry now covers. Previously, in the absence of any Aguascalientes-specific polity, these rows would have had to be routed to MEX-1848-2025, the national row — which represents all of Mexico's roughly 1.96 million km2, not the roughly 5,600 km2 state the data actually describes; routing agricultural output for one state into a container that also holds every other state's output means the data can no longer be attributed to the correct territory once other Mexican states are also disaggregated. What confirms Aguascalientes is a distinct, statistically-tracked reporting unit rather than an artefact of the source's labeling: it is a genuine federal entity (admin1) of Mexico with its own government, legislature, and INEGI statistical apparatus, and it is one of the units the country convention for MEX identifies as needing its own row precisely because Mexican agricultural statistics are compiled and published at the state level, not only nationally.

## Territorial extent

**Polygon status:** `polygon_source: none`. **No polygon available in the GeoPackage for this period.** The routing decision's `polygon_route` was `new_source_needed`: GADM 4.1 (registered in scripts/sources.yaml as `gadm-4.1-adm1`) globally covers Mexican states, but the adm1 file actually present in this repository is a curated 81-country subset that does not include Mexico (zero matching features), so the registered source cannot supply this feature without a re-fetch of a different, non-subset file. The candidate named in the routing decision is INEGI's Marco Geoestadístico (Mexico's national statistical/geographic institute's official state-boundary layer), which is not yet a registered source in sources.yaml and whose licence terms have not been checked, so it cannot be attached in this pass.

**Territory description, for a reader locating it on a map:** Aguascalientes is a small, roughly circular/diamond-shaped state in central Mexico, bordered entirely by the state of Zacatecas except for a short southeastern border with Jalisco. Its capital, also named Aguascalientes, sits at approximately 21.88°N, 102.29°W. The state covers approximately **5,618 km2** (a commonly cited modern figure for the state, not a measurement from any geometry attached to this entry, since none is attached) — making it the third-smallest Mexican state by area, after Tlaxcala and Morelos. Its boundary has been essentially stable since 1857 admission, per the routing decision's vintage-risk assessment, so a present-day INEGI or GADM boundary would be a low-risk proxy for the full 1857-2025 span once fetched.

## Predecessors and successors

No predecessor: prior to 1857 there was no distinct Aguascalientes polity row in this database (the territory existed as a partido of Zacatecas, a sub-state administrative unit not separately tracked here), and the routing decision found no earlier Aguascalientes-labeled data to chain from. No successor: Aguascalientes remains a current Mexican state as of 2025, so `end_year: 2025` is the open "still exists" default rather than a transition to a different entity, and `successor` is left empty pending any future need to extend the span past 2025.

## Decisions

### d-code-pattern-ags

**Chose the dominant ISO3-SUBUNIT-start-end code pattern over a bespoke code**

Aguascalientes is a standard Mexican federal state (admin1), not a historical territory with a name and identity of its own outside the modern federal structure (unlike ALK-1867-1959 or HYD-1724-1948, which name entities that existed under different sovereigns or legal statuses than their modern successors). Since 57 of 66 existing subnational rows follow <ISO3>-<SUBUNIT>-<start>-<end>, and MEX has no existing subnational codes to set a country-specific precedent, the dominant pattern was followed: MEX-AGS-1857-2025, using AGS as the standard postal/administrative abbreviation for Aguascalientes (the ISO 3166-2 code is MX-AGU; either would satisfy the pattern, AGS was chosen as the more widely recognized abbreviation for the state).

## Open questions

### oq-1857-admission-year

**Exact admission year of Aguascalientes as a federal state needs source verification**

The routing decision's span_basis asserts 1857 as the admission year, and its own routing_concerns section explicitly flags that this should be verified against the MEX country convention's cited source rather than relied on from general knowledge. Some accounts of Mexican federal history place Aguascalientes' separation from Zacatecas and elevation to territory status earlier (in the 1830s, under Santa Anna), with full state status only confirmed by the 1857 Constitution. If the correct start year is earlier (e.g. 1835), the code and frontmatter years would both need to change, since the gate requires the code years to equal the frontmatter years.

### oq-polygon-source-registration

**INEGI Marco Geoestadístico is not a registered polygon source and its licence is unchecked**

The routing decision names INEGI's Marco Geoestadístico as the candidate boundary source for Aguascalientes and all other Mexican states, since the locally available GADM 4.1 adm1 file excludes Mexico from its 81-country subset. Before any polygon can be attached to this entry (or to any other Mexican state entry), INEGI's licence terms need to be checked and, if usable, the source needs to be registered in scripts/sources.yaml with a fetch/build path — or alternatively the full (non-subset) GADM 4.1 adm1 global layer could be fetched instead, if its licence is preferred. Until then this entry and any sibling Mexican-state entries will remain polygon-less.

### oq-data-year-coverage

**Whether the underlying 124-year data series has gaps or a different actual start year than 1857**

The routing decision states the data begins around 1900 but does not give the full year range or row count for the Aguascalientes-labeled series, only describing it as '124 years of valued agricultural statistics.' It is not yet confirmed whether this means 1900-2024 continuously, or a shorter span with the 124-year figure counting only years with any data present. This should be checked against the actual ingested rows before the `last_ingest` sources list is finalized for this entry.
