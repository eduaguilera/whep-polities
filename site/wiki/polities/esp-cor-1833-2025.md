# Córdoba (province of Spain)

## Summary

Córdoba is one of the 50 present-day provinces of Spain, located in the interior of Andalusia in the south of the country, with its capital city also named Córdoba on the Guadalquivir river. This entry is `type: subnational` because Córdoba has never been a sovereign state: it is, and has been throughout this span, a second-tier administrative unit of Spain (Kingdom of Spain / Second Republic / Francoist State / Kingdom of Spain again), created as a province in the 1833 Javier de Burgos territorial reform that redrew Spain's historic kingdoms and lordships into 49 modern provinces. The 1833 start date follows the country's own default-start convention already applied to all other Spanish provincial rows in this table (A Coruña, Madrid, Ávila, etc.); Córdoba is not one of the two Canary Islands departure units that use a different start rule, so the standard 1833-2025 span applies with no departure. The entry closes with an open `end_year` of 2025 because Córdoba remains a current province with no change in status.

This matches the pattern already established for sibling NUTS/province units ES112 through ES241 in the same table, which were previously verdicted `create_new` under the same reasoning. The distinctness of Córdoba as its own administrative and statistical reporting unit is confirmed structurally by Spain's own 1833 provincial division (Javier de Burgos reform) and its continuation as a first-level NUTS-3/ISO 3166-2:ES-CO administrative unit today — the same evidentiary basis already accepted for the other 49 Spanish province rows in this table (e.g. ESP-B, ESP-BU, ESP-CS), of which this is one more, following identical span and container logic.

## Decisions

### d-code-esp-cor-not-esp-co

**Chose ESP-COR-1833-2025, not the province's own ISO 3166-2 code ES613 or the natural ESP-CO**

The dominant pattern for the 419 <ISO3>-<SUBUNIT>-<start>-<end> rows is to use a short subunit abbreviation, and the routing decision's proposed name is 'Córdoba (province of Spain)', so the natural code would be ESP-CO-1833-2025. That code is already held by 'A Coruña (province of Spain)' (1833-2025) — a different province that uses CO as its abbreviation, most likely from the vehicle registration/postal short code convention (A Coruña = C, but some Spanish province abbreviation schemes use CO differently, and evidently the harness picked CO for A Coruña already). Since ESP-CO-1833-2025 is taken, I picked ESP-COR-1833-2025: three letters, unambiguous, matches no other existing ESP code in the table (checked against the 50 listed), and stays within the dominant <ISO3>-<SUBUNIT>-<start>-<end> pattern rather than switching to a bespoke code. This is a Córdoba-specific collision avoidance, not a departure from the country's coding convention.
