# Hungary (1940-1944)

>

> been replaced**. Measured:
>

> ROU 1920-1940            296,087 km²   lon 20.26..30.51

> check because the two differ by 2%.
>
> **The replacement:** CShapes gwcode 310 at **1939** (the 1938-1947 step, 108,785 km²;

> unioned with an eight-county proxy for Northern Transylvania (43,685 km² against the
> award's 43,104, +1.3%).
>

This row tracks Hungary for **~4 years**, the peak-expansion WWII period
from the Second Vienna Award to the Soviet occupation and forced reversion.

The Second Vienna Award (30 August 1940) added northern Transylvania
(~43,492 km²) from Romania to Hungary. The April 1941 Yugoslav occupation
added the Backa and Baranya strips (~10,000 km²). At peak, Hungary
controlled ~172,000 km² — 58% larger than the Trianon-plus-First-Award
~109k km² baseline. From October 1944 Soviet forces began occupying
Hungary and stripping the annexations; the effective end of this regime is
placed at ~1944-10, when Soviet control made the enlarged borders
non-functional. The Treaty of Paris (10 February 1947) formally declared
the Vienna Awards null and void.

Predecessor: [hun-1938-1940](hun-1938-1940.md) — Second Vienna Award.
Successor: [hun-1944-1947](hun-1944-1947.md) — Soviet reversion.

## Polygon blocked (added 2026-07-24)

`polygon_status` set to **`unassigned`**: this page claimed `assigned` while the
build attached **no geometry at all**, because `polygon_feature_id` held a recipe
rather than a resolvable id — and the recipe is also wrong.

It read `cshapes-HUN310-1938 + cshapes-ROU360-1920minus1940`. Checking the
actual features:

- Hungary gwcode 310, 1938-1947 feature = **108,785 km²** — Trianon
  (92,991 km²) plus the First Vienna Award only. It does **not** include
  northern Transylvania.
- Romania gwcode 360: the 1920-1940 feature is 296,087 km² and the 1940-2019
  feature is 237,379 km², so their difference (~58,708 km²) is
  **Bessarabia + northern Bukovina + southern Dobruja** — the territory
  permanently lost to the USSR and Bulgaria. The 1940-2019 feature already
  includes northern Transylvania, which returned to Romania in 1947.

So that subtraction yields the wrong territory entirely. **CShapes 2.0 never
models the 1940-44 Hungarian holding of northern Transylvania** — the same gap
documented on [rou-1940-1947](rou-1940-1947.md) — so this row's ~167,492 km²
extent cannot be composed from it.

Resolving it needs a source with the Second Vienna Award boundary (or a
hand-digitised northern-Transylvania polygon) added as a builder in
`scripts/sources/constructed/build.py`. Until then the 201 layer-B rows matched
here have no geometry, which is the honest state rather than a wrong one.
