# Burgos (province of Spain)

## Summary

Burgos is one of the fifty provinces created by the 1833 Javier de Burgos territorial reorganization of Spain, which replaced the old kingdom/intendencia structure with a uniform grid of provinces used ever since for civil administration, elections, and statistical reporting. Burgos sits in the north of the Castile-and-Leon region, on the northern sub-plateau, and was historically the seat of the medieval Kingdom of Castile before the province took its modern administrative form. `type: subnational` because Burgos never held sovereignty of its own — it is, and always has been, a first-order administrative division of the Spanish state, reporting into the ESP national chain for the entire 1833-2025 span. There is no predecessor/successor break: the province has not been split, merged, or renamed since its creation, unlike the Canary Islands provinces (created 1927) which required a different start year.

**Why this entry exists.** This entry captures administrative-unit ES412 (Burgos) as identified in Spain's INE/NUTS unit table, which the agent-harness routing pass matched against the existing 50 ESP subnational rows and found no candidate: A Coruna (ESP-C) and Madrid (ESP-M) are distinct, differently-located provinces, and no other existing row's name or territory overlaps Burgos. Previously, any data keyed to "Burgos" or ES412 would have had nowhere to route except the national ESP row, which is roughly 36x the area of this one province and would have silently merged Burgos-specific statistics into all-Spain totals. Federico-Tena and the INE both treat Spain's 50 provinces, including Burgos, as the standard disaggregation unit for 19th-20th century Spanish statistics, which is the historical precedent for giving Burgos its own row rather than folding it into the national series. A prior version of this row (esp-bu-1833-2025.md) existed in the wiki and was deleted in this same pipeline pass (see git status), apparently as part of a broader ledger cleanup of duplicate/malformed subnational pages; this entry recreates it against the current routing verdict for ES412.

## Territorial extent

**Polygon status:** Not yet assigned. No polygon available in the GeoPackage for this period. The correct source is `mapspain-ign` — the IGN `provinces.gpkg` file already used for 50 other ESP provinces under the `ESP-<cpro>-1833-2025` naming convention with `id_column cpro` — but that file is not present locally, so `polygon_route: registered_source_unfetched` applies: the slug is recorded as the source and `polygon_status` is `unassigned` rather than `assigned`, with `polygon_feature_id` left null until the fetch happens. `gadm-4.1-adm1` was checked and has zero name matches for Spain at the province level (only 18 higher-level autonomous-community regions), so it cannot substitute.

**Territory description:** Burgos is a province in northern Spain, in the autonomous community of Castile and Leon, bordering Cantabria and the Basque Country to the north, La Rioja to the east, Soria and Segovia to the south, and Palencia and Valladolid to the west. Its capital, the city of Burgos, sits on the Arlanzon river and was the medieval capital of the Kingdom of Castile. The province covers approximately 14,022 km2 on modern maps (INE cadastral figure) — no geometry is attached to this entry yet, so this figure is independent map evidence about the territory, not a measurement of any polygon in this database. Provincial boundaries in Spain have been essentially stable since the 1833 division aside from minor 20th-century cadastral adjustments, so once fetched, a present-day IGN boundary is expected to be a reasonable proxy for the full 1833-2025 span.

## Decisions

### d-follow-default-1833-start

**Use the country-wide 1833 default start year rather than a Burgos-specific date**

Burgos is a standard mainland Spanish province created in the 1833 Javier de Burgos division, with no earlier distinct administrative identity that would justify a different start year. This matches the convention already applied to the other 50 ESP provincial rows (e.g. ESP-B-1833-2025, ESP-BI-1833-2025), all of which use 1833 unless the province was part of the 1927 Canary Islands split, which introduced a later start year for those two provinces only. Burgos is mainland Castile-and-Leon, not a Canary Islands unit, so no departure from the default is warranted.

### d-code-bu-not-bur

**Use two-letter code BU, matching Spain's official province abbreviation, not a longer bespoke code**

The routing decision's proposed polity_name is 'Burgos (province of Spain)' with no explicit code, but the dominant pattern for ESP subnational rows is <ISO3>-<SUBUNIT>-<start>-<end> using INE's official two-letter province abbreviations (e.g. ESP-BA for Badajoz, ESP-BI for Vizcaya/Bilbao). Burgos's official INE abbreviation is BU, so ESP-BU-1833-2025 follows the established 49-row pattern rather than introducing a bespoke or three-letter code; this is also the code implied by the git status showing a prior esp-bu-1833-2025.md file that was deleted earlier in this same pipeline pass.

### oq-cadastral-vs-projected-area

**The 14,022 km2 figure is a cadastral/map figure, not computed from any attached geometry**

Because no polygon is attached to this entry yet, the ~14,022 km2 figure cited here comes from INE's published cadastral area, not from any geometry in this database. Once provinces.gpkg is fetched and a feature assigned, the geometry-measured area (in the project's standard equal-area projection) should be checked against this cadastral figure; per the project's documented two-area-conventions issue, projected vs. geodesic area measurements can diverge by roughly -0.43% to +0.60% depending on latitude, so a small discrepancy would not itself indicate a wrong feature.
