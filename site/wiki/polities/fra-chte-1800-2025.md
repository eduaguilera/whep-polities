# Charente

## Summary

Charente is a département in southwestern France, on the Atlantic-facing side of the country, with its préfecture at Angoulême. It was one of the roughly 83 original départements created by the Revolutionary administrative reform of 1790 and has kept essentially the same boundaries ever since -- it is not one of the handful of French départements (Territoire de Belfort, the Alsace-Lorraine trio, Corse's 1975 split, or the 1946 overseas départements) whose creation or reorganization departs from that 1790 default. `type: subnational` is used deliberately: Charente is a first-order administrative subdivision of France, not a sovereign state, and this row exists specifically because at least one data source (an agricultural/production series identified in the source data by the NUTS3 code FRI31) tabulates statistics at the département level rather than for France as a whole, continuously from 1862 to 2023. None of the four existing FRA-coded rows in the polity table (FRA-1800-1871, FRA-1800-1919, FRA-1871-1919, FRA-1919-2025) can receive this data correctly: all four are national totals for France as a whole across successive eras (defined by the presence or loss of Alsace-Lorraine), and a département is a distinct, much smaller reporting unit nested inside whichever national era is current, not identical to any of them. This entry's start_year is set to 1800, not the département's true 1790 origin, because the earliest available France container row in the built table (FRA-1800-1871) begins in 1800 and the containment gate will not accept an edge starting outside a container's own span; the true creation date is documented as an open question rather than silently asserted in the frontmatter.

**Why this entry exists.** This entry captures a French département-level data series identified in the routing decision as unit_id FRA-FRI31 (admin_name FRI31, the NUTS3 code for Charente), reportedly spanning 1862-2023 in the underlying data. Before this decision, no France-related routing existed for this unit at all -- the routing decision explicitly found 'no existing polity in the FRA iso3 group or by-name candidates IS Charente,' since the four FRA-* rows in the table are all national totals for successive eras of France (split by Alsace-Lorraine's presence/absence) and a département is a distinct, smaller reporting unit nested within whichever national era applies, never identical to the whole country. Federico-Tena-style historical trade/production compilations and national statistical series from this period routinely tabulate French agricultural output at the département level (a well-established administrative tier since 1790), which is the historical confirmation that Charente is a genuinely distinct, long-standing reporting entity rather than an artefact of one source's labelling choice -- it has had continuous, unchanged administrative existence and identity since the Revolutionary reform, unlike départements that were created, abolished, or resized later (Belfort, the Alsace-Lorraine trio, Corse, the overseas départements).

## Territorial extent

**Polygon status:** Not yet assigned. No polygon is available in the GeoPackage for this period. `polygon_source` is set to `gadm-4.1-adm1`, which is a correctly registered source for a French département (a standard admin-1 unit), but the copy of GADM 4.1 adm1 data present in this repository is a curated 81-country subset that has zero features for France -- so no `polygon_feature_id` can be assigned yet, and `polygon_status` is `unassigned` rather than `assigned`. This is a fetch gap, not a source gap: someone needs to pull the full global GADM 4.1 adm1 layer (or a France-specific GADM extract) and identify the GID_1 value for Charente before a feature can be attached. See open question oq-gadm-fetch-needed.

**Territory description:** Charente occupies the middle Charente river valley in southwestern France, between the Cognac/Saintonge coastal lowlands to the west and the Limousin plateau to the east. Its modern administrative area is approximately 5,956 km2 (INSEE figure for the département), and it is bordered by the départements of Deux-Sèvres and Vienne to the north, Haute-Vienne and Dordogne to the east, Gironde to the south, and Charente-Maritime to the west. Its préfecture, Angoulême, sits roughly midway between Poitiers and Bordeaux and is easily located on any modern map of France. The 5,972 km2 figure attached to this record as `area_km2_measured` is a measurement of whatever placeholder/no geometry check computed against this record in the harness pipeline (see note below) and should not be read as an independent survey of Charente's territory -- it is not meaningfully distinguishable from the INSEE administrative figure at this level of precision, but no polygon is actually attached yet (polygon_status: unassigned), so this number carries no evidentiary weight about the territory beyond what INSEE already states.

## Predecessors and successors

Charente has no predecessor or successor polity row: it was created directly by the 1790 Revolutionary administrative reform (the entry's start_year is set to 1800 for containment reasons, see open questions) and has not been abolished, merged, split, or renamed since -- it remains a French département and, since 1956/2016 regional reorganizations, the NUTS3 statistical unit FRI31 within the Nouvelle-Aquitaine region. It is contained across three successive eras of the national France row as that entry's own conventions change (see container edges), but Charente itself has no distinct territorial predecessor or successor; it is a single continuous administrative unit end to end.

- mitchell-style / Federico-Tena-adjacent agricultural production series report a unit labelled with NUTS3 code FRI31 continuously from 1862 to 2023 (per the routing decision's row-count evidence), which is the empirical basis for treating Charente as a distinct reporting territory rather than folding it into the national FRA total.

## Decisions

### d-code-fra-chte-not-16

**Code uses FRA-CHTE, not FRA-16, because FRA-16-1800-2025 is already held**

The dominant subnational pattern for FRA would suggest FRA-16-1800-2025, using INSEE department number 16 for Charente. That exact code is already on disk as a page in wiki/polities/ (FRA-16-1800-2025.md), for a different territory whose row is not in the built table -- i.e. an orphaned or stale page, not a live conflict I can resolve by re-examining the data. Rather than touch or overwrite a page I was told is a different territory, I chose FRA-CHTE-1800-2025, using the standard French department abbreviation CHTE (as used on vehicle plates and in postal contexts for Charente) in place of the numeric code. This keeps the <ISO3>-<SUBUNIT>-<start>-<end> pattern (57 of 66 subnational rows) while avoiding the collision. If the stale FRA-16-*.md page is ever cleaned up, a future maintainer may prefer to rename this entry back to the numeric convention for consistency with any other French department rows that get added later.

### d-start-year-1800-not-1790

**start_year set to 1800, not 1790, because no container exists before 1800**

The routing decision's span_basis argues for start_year 1790, since Charente is one of the original ~83 Revolutionary départements created that year and matches none of the four documented departures from that default (Belfort 1922, Alsace-Lorraine 1919, Corse split 1975, overseas 1946). However, the polity table's earliest FRA container row is FRA-1800-1871 (1800-1871) -- there is no FRA-* row covering 1790-1800, and the containment gate rejects an edge that falls outside either party's span. Extending the container edge back to 1790 would violate that gate; asserting Charente existed 1790-1800 with no container would leave a real gap. I set start_year to 1800 to match the earliest available container and recorded the true administrative origin (1790) in the summary and as an open question, rather than silently adopting a start year the data cannot support. This is a compromise: the department's actual creation date is misrepresented by a decade in the code/frontmatter, but the alternative (an untileable span) fails a hard gate.

## Open questions

### oq-pre1800-span-uncontained

**Charente's actual creation (1790) predates the earliest FRA container by 10 years**

Charente was created in 1790 as one of the original Revolutionary départements, per the country convention's own default rule, but the earliest national container row available in the built polity table is FRA-1800-1871 (starting 1800), and no FRA-* row exists for 1790-1800. This entry's start_year was set to 1800 to satisfy the containment gate, which means the page as written understates Charente's continuous existence by a decade. If a container row for France 1790-1800 is ever added (or the existing FRA-1800-1871 row's start_year is corrected to 1790), this entry's start_year and container edge should be updated to match, and the polity_code changed accordingly since the code must equal the frontmatter years.

### oq-gadm-fetch-needed

**polygon_status is unassigned pending a full (non-81-country-subset) GADM 4.1 adm1 fetch**

The locally present GADM 4.1 adm1 data is a curated 81-country subset that excludes France entirely (0 features for FRA), so no polygon_feature_id can be assigned yet even though gadm-4.1-adm1 is the correct registered source for a standard admin-1 unit like a French département. Someone needs to fetch the global GADM 4.1 adm1 layer (or a France-specific GADM download) and identify the GID_1 value corresponding to Charente (expected to be something like FRA.16_1, but not confirmed) before this can move from polygon_status: unassigned to assigned. GADM's licence (free for academic/non-commercial use, no redistribution) has likely been vetted already for the existing subset but was not independently re-verified in this session.

### oq-fri31-vs-charente-confirm

**Unverified that NUTS3 code FRI31 in the source data is Charente and not a renamed/reorganized unit**

The routing decision flags this directly: 'Confirm FRI31 indeed corresponds to Charente NUTS3 code and not a different département that was renamed.' I have not independently verified the FRI31 to Charente mapping against an authoritative NUTS3 code list in this session -- I am relying on the routing decision's admin_name field. If FRI31 turns out to map to a different or reorganized unit, the data (1862-2023, per the routing reasoning) currently slated to route here would need to be re-routed and this page's row-count/source justification revised.
