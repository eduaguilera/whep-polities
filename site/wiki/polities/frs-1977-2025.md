# Djibouti (post-independence, 1977–2025)

## Summary

Independent Djibouti from its independence on 27 June 1977 to the present. The territory — formerly French Somaliland and then the French Territory of the Afars and Issas — became the last country in continental Africa to gain independence. WHEP codes this row as FRS-1977-2025, continuing the FRS polity-code chain from FRS-1884-1977 (the colonial period). The predecessor colonial period is documented on the [dji-1886-2025](dji-1886-2025.md) page. Note: the CSV assigns cow_code=987, which is the COW code for Micronesia (Federated States of); the correct COW code for Djibouti is 522 (DJI). This is a data error flagged in [Contradictions](#contradictions) and [Open questions](#oq-cow-code-error).

## Territorial extent

Polygon from CShapes 2.0 (dependencies=TRUE). Area approximately 23,200 km² [8,958 sq. miles]. Bounded by Eritrea (110 km), Ethiopia (349 km), and Somalia (58 km); coastline along the Gulf of Aden and the Bab-el-Mandeb strait. [biger-1995 §djibouti](../sources/biger-1995.md#djibouti). CShapes assigns the territory to its full independence polygon from 1977 onward under cowcode=522.

## Predecessors and successors

- **Predecessor:** [dji-1886-2025](dji-1886-2025.md) — French Somaliland / French Territory of the Afars and Issas, 1886–1977. The DJI-1886-2025 page covers the colonial period; FRS-1977-2025 continues from independence.
- **Predecessor (CSV field):** FRS-1884-1977 — colonial period row in the CSV chain.
- **Successor:** None. FRS-1977-2025 is the terminal row for this territory.

## Contradictions

**cow_code mismatch.** The CSV assigns cow_code=987 to FRS-1977-2025. COW ccode=987 is the Federated States of Micronesia (FSM), not Djibouti. The correct COW code for Djibouti is 522 (DJI), with a state-system entry date of 1977-06-27 per the COW v2024 statelist. This is a data entry error in the CSV. The database currently follows cow_code=987, which is wrong. A CSV correction is needed; see [oq-cow-code-error](#oq-cow-code-error).

**Relationship to DJI-1886-2025.** The existing wiki page [dji-1886-2025](dji-1886-2025.md) is titled "Djibouti (1900-1977)" and covers the colonial French Somaliland period. Its cow field is 522, which is correct for Djibouti-as-independent-state. However, that page's predecessor/successor links are circular (it references itself as predecessor and successor). The chain should be: FRS-1884-1977 → FRS-1977-2025 (WHEP chain), with DJI-1886-2025 being a separate page covering the same territory under a different polity code. This overlap in page coverage should be rationalized — see [oq-chain-overlap](#oq-chain-overlap).

## Open questions

### oq-cow-code-error

CSV cow_code=987 is wrong. COW ccode=987 is Micronesia; Djibouti's COW code is 522. A CSV correction to cow_code=522 is needed for FRS-1977-2025. This should be filed as a proposal-kind log entry before the correction is applied.

### oq-chain-overlap

Polity code chain ambiguity. The WHEP CSV has two partially overlapping representations of Djibouti: the FRS-* chain (FRS-1884-1977 → FRS-1977-2025, using a regional/dependency code) and the DJI-1886-2025 page (using the ISO/COW code). It is not clear whether DJI-1886-2025 represents a different data source's view of the same territory or a legacy artifact. The next ingest should determine whether DJI-1886-2025 should be merged into the FRS chain, deleted, or kept as a parallel representation with a documented rationale.
