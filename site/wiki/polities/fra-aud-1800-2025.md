# Aude (department, 1800-2025)

## Summary

This entry captures Aude, an ordinary French département in the Occitanie region (historically part of Languedoc-Roussillon), covering the 1800-2025 span for which this database's FRA national containers exist. It is entered as type "subnational" rather than "national" because Aude has never been a sovereign state: it is, and always has been, an administrative subdivision of France, and the subnational type is what keeps it from competing with the FRA-1800-1871 / FRA-1871-1919 / FRA-1919-2025 national rows in any matching or sovereignty ranking. The entry exists because the agent-harness routing pipeline classified the raw admin unit FRJ11 (Aude, INSEE code 11) as needing its own polity row: it is not one of the four French subnational units with a documented territorial break (Belfort, Alsace-Lorraine, Corse, or the overseas départements), so the default rule applied -- start at creation (here floored to 1800 by container availability, see decisions), end at the present (2025, open). No polygon is attached yet; the intended source, GADM 4.1 ADM1, is registered but the local extract does not include France, so polygon_status is "unassigned" pending a fuller fetch.

**Why this entry exists.** This entry captures the raw admin unit FRJ11 (Aude, INSEE code 11) from the agent-harness routing pipeline's country-conventions decision for France -- no source row counts or year ranges were supplied in the routing decision itself (see open question oq-no-data-rows-cited), only the unit identifier and the routing logic that assigned it a start year, end year, and container chain. Previously this unit had no polity row at all in this database (there were zero existing FRA subnational rows before this batch, so there is no prior mis-match to correct -- this country sets its own precedent, as the prompt notes). What confirms Aude is a distinct administrative entity worth its own row is that it is one of France's original 1790 Revolutionary départements, a legally and administratively distinct sub-national unit with continuous existence since creation, as opposed to a mere statistical reporting convenience -- unlike the four listed departure cases (Belfort, Alsace-Lorraine, Corse, overseas départements) it has no territorial discontinuity to model, which is exactly why the country's default rule (start at creation, run to present) applies to it unmodified.

## Decisions

### d-start-year-1800-not-1790

**Start year set to 1800, not the 1790 creation date, because no container tiles 1790-1800**

The routing decision argued for start_year=1790, since Aude is one of the ~83 original Revolutionary départements created that year and has kept its present form since. But the polity table's earliest FRA container row is FRA-1800-1871 (start_year 1800) -- there is no FRA national row covering 1790-1800, and the containment gate rejects an edge falling outside the container's own span. Rather than leave a decade uncovered, this entry's start_year is set to 1800, matching the earliest available container floor. The administrative-continuity argument for 1790 still holds historically, but this database's FRA chain simply does not extend that far back, and a page cannot container itself against a row that does not exist. If a FRA-*-1800 (pre-1800) row is ever added, this entry's start_year should be revisited.

57 of 66 subnational rows use <ISO3>-<SUBUNIT>-<start>-<end> (e.g. ESP-AS-1833-2025, DZA-CVD-1902-1919).
