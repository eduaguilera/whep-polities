# Calvados (département)

## Summary

Calvados is a French département in Normandy, on the English Channel coast, containing the city of Caen. It is one of the original ~83 départements created by the March 1790 Revolutionary administrative reform that replaced the old provinces with a uniform grid of units, and it has kept its present form ever since — it is not one of the recognized departures from that default history (it was not carved out of Alsace-Lorraine, not split off like the Territoire de Belfort, not part of the 1975 Corse split, and not a post-1946 overseas département). This entry is `type: subnational` because Calvados is an ordinary administrative subdivision of France, not a sovereign state or a historical territory with an identity of its own distinct from the modern département — it exists in this table only because a statistical source (mitchell) reports agricultural data for it specifically, at a finer grain than the national FRA rows carry. Before this entry, that data had no département-level home and would have had to be routed to whichever national FRA row spans the relevant year, which is roughly fifteen départements' worth too coarse for series that are specifically about Calvados. No polygon is attached yet: the only source with the right administrative granularity for France (GADM 4.1 admin-1) is registered in this repository but its locally-present copy is an 81-country subset that happens to exclude France, so `polygon_source` is `none` rather than a proxy.

**Why this entry exists.** Input data: mitchell reports agricultural/production series labelled specifically for Calvados, spanning 1862-2023 per the routing decision (row count not independently verified here — the routing decision did not surface an exact count, and no data file was consulted directly in this authoring pass; that is itself worth confirming before this entry leaves draft status). Previously, in the absence of any Calvados-level polity, this data had no natural home except one of the national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year) — routing it there would have meant attributing département-level series to the whole of metropolitan France, a roughly fifteen-fold territorial overstatement (France has about 96 metropolitan départements) that would silently blend Calvados's numbers into a national aggregate no such row is entitled to claim they represent alone. What confirms Calvados is a distinct, real administrative entity rather than an artifact of the source's labelling: it is one of the ~83 original départements from the 1790 Revolutionary reform, it has its own INSEE code (14), its own préfecture (Caen), and GADM 4.1 digitises it as a discrete admin-1 feature — this is not a case of a source inventing a unit that doesn't correspond to any real jurisdiction.

**Territory description:** Calvados is a coastal département in Basse-Normandie (Normandy), on the English Channel, bordered by Manche, Orne, Eure, and Seine-Maritime. Its administrative seat is Caen. On a modern map it corresponds to INSEE département code 14, roughly bounded by the Bay of the Seine to the northeast and the Orne river valley to the south. Its modern area is approximately **5,548 km²** (a figure quoted from published French administrative statistics for the present-day département, not measured from any polygon attached to this entry, since none is attached). This is consistent with the 1790 creation reform's aim of drawing départements small enough to be crossed on horseback in a day from any point to the seat.

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the département's 1790 creation date**

The routing decision proposed start_year 1790, citing the March 1790 Revolutionary reform that created Calvados along with the ~83 original départements. That date is correct administrative history, but it is not usable here: the FRA container chain in the polity table begins at FRA-1800-1871, and there is no France row covering 1790-1800 to container against. The containment gate rejects any edge falling outside both parties' spans, so an 1790 start with no container for the first decade would fail immediately. Rather than leave a gap or invent a container row this pipeline wasn't asked to create, this entry starts at 1800, matching the earliest container available, and the 1790-1800 gap is left open below. The data this entry actually receives (1862-2023, per the routing decision) is unaffected either way, since it falls entirely inside 1800-2025.

### d-subunit-code-is-insee-number

**Subunit code '14' follows INSEE numbering, matching the dominant ISO3-SUBUNIT pattern**

French départements are conventionally identified by their INSEE two-digit code rather than a postal abbreviation (unlike Spanish provinces, which used two-letter codes such as ESP-CA). Calvados's INSEE code is 14. This keeps the code in the dominant <ISO3>-<SUBUNIT>-<start>-<end> family (57 of 66 subnational rows) rather than treating Calvados as a bespoke historical territory, since it is an ordinary, non-renamed administrative unit with no name-of-its-own distinct from the modern département.

## Open questions

### oq-1790-1800-gap-uncontained

**1790-1800 creation decade has no France container row to attach to**

Calvados existed as a département from March 1790, a full decade before this entry's start_year of 1800. The FRA container chain in the polity table begins at FRA-1800-1871 (cshapes-europe, first vintage 1816), so there is currently no polity row representing France 1790-1800 for Calvados (or any other French département) to container against. If a pre-1800 France row is ever added to the table, this entry's start_year should be reconsidered and moved back to 1790, consistent with the département's actual creation date and with the routing decision's original span_basis reasoning.

### oq-no-polygon-source-registered

**No registered, locally-present source can supply a Calvados boundary today**

The routing decision's polygon_reasoning found that gadm-4.1-adm1, the only registered source with département-level granularity for France, is present locally only as an 81-country subset that excludes France entirely (0 rows for FRA). cshapes-2.0 and cshapes-europe, the sources used for the national FRA rows, only carry whole-country geometry, not sub-national units. No union/difference of currently registered, locally-present features can construct Calvados's boundary. A real boundary certainly exists (GADM 4.1's full/global adm1 layer, or IGN's ADMIN-EXPRESS/GEOFLA for France specifically) but is not registered in scripts/sources.yaml today, so polygon_source is 'none' and polygon_status is 'unassigned' rather than a proxy or estimate. This should be revisited once gadm-4.1-adm1 is re-sourced as its full global layer, or an IGN product is registered.

### oq-departement-boundary-stability-unverified

**Calvados's boundary stability across 1800-2025 has not been corroborated against a second source**

This page asserts Calvados has retained its present-day boundary since creation, based on the routing decision's claim of stability for original 1790 départements. That claim has not been cross-checked here against an independent French administrative-history source (e.g., INSEE's historical arrondissement/canton records, or IGN's own boundary-change documentation) to confirm no 19th- or 20th-century adjustment (canton transfers between neighbouring départements are common in French administrative history and would not necessarily show up as a rename). Given [[feedback_conventions_refutable]], this assumption should be corroborated before a polygon is assigned, not just before publication of the numbers themselves.
