# Eivissa y Formentera (province of Spain)

## Summary

Eivissa y Formentera is the pair of islands -- Ibiza (Eivissa) and Formentera -- lying in the western Mediterranean off Spain's eastern coast, forming the southwesternmost group of the Balearic Islands. This entry is `type: subnational`, not national, because Spain has held uninterrupted sovereignty over the islands throughout the span: what the entry exists to carry is a statistical reporting territory (Eurostat/INE NUTS3 unit ES531, 'Eivissa y Formentera'), not a separate polity in the sovereignty sense. Administratively the islands have been part of a single Balearic Islands province since the 1833 Javier de Burgos division (they were never their own province), and since 1978 also of the Balearic Islands Autonomous Community; ES531 is a modern statistical subdivision used to disaggregate Balearic-level data down to the Ibiza/Formentera group specifically, distinct from Mallorca (ES532) and Menorca (ES533). The span 1833-2025 follows the repository's default rule for Spanish provincial-origin units in the absence of a documented departure, though (see open questions) the NUTS3 unit itself is a much more recent statistical artifact than 1833, and that mismatch has not been resolved here.

**Why this entry exists.** This entry captures data keyed to unit id ES531 ('Eivissa y Formentera'), the Eurostat/INE NUTS3 statistical code for the Ibiza-Formentera island group within Spain's Balearic Islands NUTS2 region. The routing decision found no existing ESP polity by name matched this territory: the three iso3-sharing candidates (ESP-CO/A Coruña, ESP-MD/Madrid, and the national ESP row) are each a different province or the country total, none of which is the Ibiza/Formentera group specifically. Before this entry, any data reported at ES531 granularity would have had nowhere accurate to route except the national Spain row, silently merging a ~655 km² island reporting unit into a total roughly 780x larger by area (Spain is ~505,990 km²) -- exactly the kind of mismatch this table exists to catch. What confirms the unit is a genuinely distinct, separately-reported territory rather than an artifact of the source file is that ES531 is an internationally standardized Eurostat NUTS3 code, used specifically because Spanish and EU statistical agencies publish Balearic Islands data disaggregated to this level, distinguishing it from ES532 (Mallorca) and ES533 (Menorca) in the same NUTS2 region -- the distinction is definitional in the classification system itself, not an inference from magnitude or naming alone.

## Territorial extent

**Polygon status:** Not yet assigned. No polygon available in the GeoPackage for this period. `polygon_source` is set to `mapspain-ign`, the registered Spanish provincial-boundary source (IGN) already used for sibling entries ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR and ESP-PO, but its file (data/geodata/mapspain-ign/provinces.gpkg) is not present locally in this environment, so no feature has been fetched or verified -- hence `polygon_status: unassigned` rather than `assigned` or `proxy`. No area figure is claimed or measured here.

**Territory description:** The islands of Ibiza (571 km²) and Formentera (83 km²) together cover approximately **655 km²**, located roughly 90 km off the Spanish mainland coast near Valencia/Alicante and about 100 km southwest of Mallorca. On a modern map this is the smaller, southwestern pair of the Balearic Islands archipelago, administered today as part of Spain's Balearic Islands Autonomous Community. This is a real, geographically bounded island group -- unlike a mainland province, its extent is unambiguous even without a fetched polygon, since it is fixed by coastline rather than by a negotiated administrative line. The eventual polygon should be constructed as the union of the two islands' coastlines (e.g. from GADM admin boundaries or the IGN municipal layer for the municipalities of Eivissa, Sant Antoni de Portmany, Sant Josep de sa Talaia, Santa Eulària des Riu, and Formentera), not copied wholesale from a 'Baleares' province polygon that would also include Mallorca and Menorca and so overstate this unit's territory by roughly 6x.

## Predecessors and successors

No predecessor: Eivissa y Formentera has no distinct statistical or administrative existence recorded before 1833, when it was folded into the newly created Balearic Islands province under the Javier de Burgos division, the same reform that created the other Spanish provincial pages in this table (ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR, ESP-PO). No successor: the span runs to the present (2025) with no dissolution or re-territorialization event on record -- Ibiza and Formentera remain part of the Balearic Islands province and, since Spain's 1978 Constitution, of the Balearic Islands Autonomous Community, with no change to the underlying island territory this entry describes.

## Sourced claims

- The 1833 Javier de Burgos territorial reorganization of Spain created the Balearic Islands as a single province, grouping Mallorca, Menorca, Ibiza and Formentera under one provincial administration seated at Palma -- it did not create a separate 'Eivissa y Formentera' province, which is why this entry captures a statistical reporting unit (Eurostat/INE NUTS3 code ES531) rather than a historical administrative province in its own right.
- Eurostat's NUTS classification subdivides the Balearic Islands (NUTS2 ES53) into three NUTS3 units: ES531 Eivissa y Formentera, ES532 Mallorca, and ES533 Menorca -- the routing unit id 'ES531' for this entry corresponds directly to the Eivissa y Formentera NUTS3 code in that classification.

## Decisions

### d-code-ibz-not-eif

**Chose ESP-IBZ, not ESP-EIF, because ESP-EIF-1833-2025 is already occupied**

The proposed code from the routing decision followed the dominant <ISO3>-<SUBUNIT>-<start>-<end> pattern used by the other 7 Spanish subnational pages (ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR, ESP-PO), and would naturally have been ESP-EIF-1833-2025 (Eivissa y Formentera). That code is already held by a page in wiki/polities/ whose row is not currently in the built table -- a different, stale artefact for a different unit ('ES531' is the NUTS3 code this entry is actually keyed to). Rather than overwrite or collide with that page, this entry uses ESP-IBZ-1833-2025, a bespoke-but-recognizable three-letter subunit token (IBZ, the common abbreviation for Ibiza, paired with Formentera) that keeps the same <ISO3>-<SUBUNIT>-<start>-<end> shape the sibling pages use. If ESP-EIF-1833-2025 is later found to be genuinely orphaned/incorrect, the two pages should be reconciled rather than left as permanent duplicates for the same territory.

### oq-nuts3-vs-province-mismatch

**Is 'Eivissa y Formentera' actually a province, or only a modern NUTS3 statistical unit inside Balearic Islands province?**

The 1833 Javier de Burgos division created a single Balearic Islands province (capital Palma) covering Mallorca, Menorca, and Ibiza/Formentera together -- it did not create a separate 'Eivissa y Formentera' province. The routing decision's unit id (ES531) is a NUTS3 code, and NUTS3 statistical subdivisions of the Balearic Islands (ES531 Eivissa y Formentera, ES532 Mallorca, ES533 Menorca) were only introduced by INE/Eurostat much later, likely in the second half of the 20th century, for statistical reporting rather than administrative provincehood. If the source data being matched is genuinely reported at NUTS3 granularity only from some later year, start_year=1833 (inherited from the generic Spanish-province default rule) may overstate this unit's real existence as a distinct reporting territory by well over a century. This should be checked against when ES531-level data first appears in the source before the start_year is trusted.
