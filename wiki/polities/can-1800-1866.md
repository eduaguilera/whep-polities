# Canada (pre-Confederation)

## Summary

Canada (pre-Confederation) covers British North America from the start of the WHEP time window (1800) until 1866. The polygon is the CShapes 1886 feature — a proxy that overstates pre-Confederation territory roughly 8x and must be treated with caution in any spatial analysis.

## Territorial extent

**Polygon status: proxy — polygon_vintage_drift 20+ years; overstates pre-Confederation territory ~8x.**

**Polygon source:** CShapes 2.0, cowcode=20, feature year 1886 (area: 9,553,644 km²). Used as proxy because no pre-1867 British North America polygon exists in any WHEP pipeline source.

**Vintage drift — genuine territorial overstatement.** The 1886 CShapes polygon post-dates this polity by 20 years and incorporates post-Confederation acquisitions. Pre-Confederation core administered colonies (Province of Canada ~1,076,000 km² + New Brunswick ~72,000 km² + Nova Scotia ~55,000 km² + PEI ~5,660 km²) total ~1.21M km² — roughly 8x less than the 9.55M km² proxy. Approximation direction: the polygon overstates pre-Confederation territory.

**Why no better polygon:** Cliopatria v0.1.3 has no British North America feature (earliest Canada entry SeshatID ca_canada_dominion starts 1932). CShapes-2.0 has no Canada feature before 1886. No other WHEP source (CHGIS, Paine et al. 2024, constructed polygons) covers pre-1867 British North America.

**Future fix path:** Compose a union of GADM province boundaries for Ontario, Quebec, New Brunswick, Nova Scotia, and PEI (~1.21M km²) as a static proxy for the 1800–1866 colonial extent. See oq-british-north-america-polygon.

**2026-06-29 — polygon_vintage_drift documented:** The CShapes 1886 proxy polygon overstates pre-Confederation Canada ~8x. No better polygon source found. Proxy retained with polygon_status=proxy; polygon_area_km2 set to 9,553,644 km².

## Open questions

### oq-british-north-america-polygon

A composed polygon for the core 1800–1866 British North American colonies (Province of Canada + NB + NS + PEI ≈ 1.21M km²) would correct the 8x overstatement. Candidate approach: union of modern GADM province boundaries for Ontario, Quebec, New Brunswick, Nova Scotia, and PEI as a static colonial-era proxy.

### oq-multiple-colonies

Whether to split into separate colony-level rows (Upper/Lower Canada, Nova Scotia, New Brunswick, PEI, Newfoundland) depends on whether source data provides colony-level series. Most 19th-century sources (Mitchell pre-1961) report aggregate "Canada" values. Newfoundland (outside Confederation until 1949) needs its own WHEP polity covering 1800–1949.
