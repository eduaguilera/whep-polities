# China (1895-1912)

## Summary

The current CSV tracks this row as China from **1895** to **1912** --
an **18-year row** covering the late Qing Dynasty
[database](../../data/final/polities_database.csv). COW code 710
[database](../../data/final/polities_database.csv).

This row begins with the Treaty of Shimonoseki (1895, ceding Taiwan
to Japan) and ends with the Xinhai Revolution and the abdication of
the last Qing emperor (12 February 1912). Key events include the
Boxer Rebellion (1899-1901) and the Boxer Protocol, which imposed
foreign concession areas and indemnities but did not cause major
territorial losses from the Qing core.
