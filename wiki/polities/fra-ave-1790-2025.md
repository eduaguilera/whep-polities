# Aveyron (département of France)

## Summary

Aveyron is one of France's original départements, a second-tier administrative subdivision covering a rural, mountainous stretch of the southern Massif Central (part of today's Occitanie region), with its préfecture at Rodez. It was created in March 1790 by the National Assembly's reform that replaced the pre-revolutionary provinces with a grid of roughly 83 départements of comparable size, formed here from the historic province of Rouergue. `type: subnational` is used, exactly as for the sibling Morbihan (FRA-56) and Pyrénées-Orientales (FRA-PYRO) rows and for ESP's provincial rows (esp-17, esp-as, esp-ca): Aveyron was never a sovereign entity and France held continuous sovereignty over it throughout 1790-2025, but statistical and administrative sources (INSEE, and the agent-harness's own admin-unit routing pass over French NUTS/INSEE codes) report at the département level, so a subnational reporting-territory row is needed that does not compete against the national FRA chain (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025) in sovereignty-based matching. Its start year, 1790, follows the country's default département start rule rather than the first year any dataset happens to report it, because Aveyron is not among the four documented exceptions (Territoire de Belfort, the Alsace-Lorraine départements, Corsica's 1793 split, the overseas départements) that would justify a later or different start.

**Why this entry exists.** This entry captures unit FRA-FRJ22 (Aveyron) from the agent-harness's admin-unit routing pass over France, which identified Aveyron as a French département-level administrative unit with data spanning 1862-2023 and no existing matching polity row. Before this entry, any data reported at Aveyron's level had nowhere correct to route: the only existing FRA rows are national totals (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025, and the deprecated FRA-1800-1919), none of which represents the département specifically, so Aveyron-level statistics would either have been silently dropped or mis-routed to a national aggregate roughly 60x too large (metropolitan France's ~551,695 km2 against Aveyron's ~8,735 km2). A prior attempt to capture this same territory exists on disk as wiki/polities/fra-12-1800-2025.md under the code FRA-12-1800-2025, but per the harness's own rejection note that page's row is absent from the built polities table -- it is an orphaned, non-live artefact, not a correctly matched prior entry, and its 1800 start additionally omits the 1790-1800 decade this entry restores. What confirms Aveyron is a distinct, individually-tracked administrative unit rather than an artefact of the routing pass is INSEE's own statistical apparatus: Aveyron has held a continuous, individually numbered administrative identity (INSEE code 12) since 1790, the same kind of standing, independently published administrative unit this repository's other département/province-level entries already track.

## Predecessors and successors

Aveyron has no predecessor or successor polity rows. It was created directly by the 4 March 1790 National Assembly decree establishing the départements, as one of the original ~83 units, carved from the pre-revolutionary province of Rouergue, and it has continued under that same name and administrative status without interruption or renaming through to the present. It is not one of the four documented France-wide departures from the default 1790 start (Belfort, Alsace-Lorraine, Corsica's split, the overseas départements), so no predecessor row represents an earlier different status, and it remains current (end_year 2025 per the open-end convention), so no successor row exists.

## Decisions

### d-letter-code-not-insee-12

**Used a letter abbreviation (AVE) rather than the INSEE numeric code (12) for the SUBUNIT token**

The dominant subnational pattern for French départements established by the sibling Morbihan page (FRA-56) and this pipeline's own convention is to use the INSEE numeric department code as the SUBUNIT token, and Aveyron's INSEE code is 12, which would normally give FRA-12-1790-2025. That exact numeric slot is unavailable here: wiki/polities/fra-12-1800-2025.md already exists on disk, already names itself 'Aveyron (département)', and already occupies the FRA-12-* code family, but per the harness's rejection note that page's row is not present in the built polities table -- it is an orphaned artefact from an earlier run, not a live entry this page can safely coexist with or silently overwrite. Rather than reuse the numeric 12 with a different year span (which would create two different FRA-12-* codes for the same département and likely collide again), this page uses the letter abbreviation AVE, which is unambiguous, does not collide with any bespoke non-FRA code (unlike MOR, already reserved for Morocco), and is still legible as short for Aveyron. If the orphaned fra-12-1800-2025.md is later confirmed dead and removed, a future editor may wish to migrate this page back to the numeric FRA-12-1790-2025 for internal consistency with FRA-56 and other INSEE-numbered rows, but that migration is out of scope here.

### d-start-year-1790-not-1800

**Set start_year to 1790, not the 1800 in the previous rejected page or the routing decision's own container note**

The routing decision proposes start_year 1790 based on Aveyron being one of the ~83 original 1790 départements, not one of the four documented exceptions (Belfort, Alsace-Lorraine, Corsica's split, overseas départements). The polity table has no FRA national row earlier than FRA-1800-1871, so a literal 1790 start would leave 1790-1800 uncontained. Rather than truncate the span to 1800 (as the previously rejected fra-12-1800-2025.md did), this page follows the precedent set by fra-56-1790-2025.md and fra-pyro-1790-2025.md: keep start_year at the historically correct 1790 and stretch the FRA-1800-1871 container edge's start_year back to 1790 to tile the gap, since that edge is the only container available for the earliest era and the basis for treating it as continuous is identical (Aveyron sat inside the same undivided pre-1871 France as Morbihan throughout).

## Open questions

### oq-no-polygon-source

**No registered source in this repository carries French ADM1 (département-level) boundaries**

As with Morbihan (FRA-56), every source registered in scripts/sources.yaml that touches FRA (cshapes-europe, cshapes-2.0) is country-level only, and the locally trimmed data/geodata/gadm-4.1/gadm41_adm1.gpkg excludes France entirely (0 FRA rows), even though GADM's full global ADM1 release does digitise French départements. This page is therefore created with polygon_source: none and polygon_status: unassigned rather than routed to a source slug that cannot actually produce a feature today. Resolving this requires fetching the full global GADM 4.1 ADM1 release (licence terms not yet re-verified for this use) or sourcing IGN ADMIN-EXPRESS boundaries for French départements and registering a new source slug, neither of which this page-authoring task performs.

### oq-orphan-fra12-page-disposition

**What should happen to the orphaned wiki/polities/fra-12-1800-2025.md page now that this page exists for the same territory**

wiki/polities/fra-12-1800-2025.md already describes Aveyron under a different code (FRA-12-1800-2025) and a different start year (1800), but its row is absent from the built polities table, meaning it was never successfully ingested or was later dropped. Leaving both files on disk risks future confusion or a duplicate-territory routing error if the build process is later changed to pick up orphaned pages. This page does not delete or modify that file (outside this task's scope), but flags that a maintainer should either delete fra-12-1800-2025.md, or reconcile it by merging any content worth keeping into this page and then removing the orphan, before the numeric FRA-12 code is reused for anything else.

### oq-1790-boundary-stability

**Whether Aveyron's boundary has been perfectly stable since 1790, or only essentially so**

This page follows the country's default départment-start convention and assumes Aveyron's boundary, carved from the historic province of Rouergue, has been essentially unchanged since 1790 (it is not among the four documented France-wide departures: Belfort, Alsace-Lorraine, Corsica's split, or the overseas départements). This has not been checked against a canton- or arrondissement-level administrative history specific to Aveyron (e.g., minor 19th-century commune boundary adjustments with neighbouring Cantal, Lozère, Tarn, or Lot are common across French départements and have not been ruled out here). If confirmed, a modern administrative boundary would still be an adequate but imperfect proxy for the full 1790-2025 span once a source is found.
