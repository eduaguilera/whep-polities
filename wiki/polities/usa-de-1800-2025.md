# Delaware (state of the United States)

## Summary

Delaware, one of the thirteen original U.S. states and the first to ratify the Constitution (7 December 1787), as a subnational reporting unit within the United States. `type: subnational` because Delaware never held sovereignty independent of the federal union -- it is a constituent state, and this row exists purely to give juan-subnational's state-level Delaware data (previously absorbed into the country-wide USA-* national rows) a container of its own size, distinct from the roughly 3.8-million-km2 national territory those rows represent. The entry's start_year is 1800, not Delaware's actual 1787 admission: the polity table's earliest national USA row (USA-1800-1803) itself only begins in 1800, and the containment gate rejects any edge whose span falls outside its container's own recorded span, so 1800 is the earliest year any USA state-level row can currently be containered against. This mirrors the identical compromise already made for Connecticut (USA-CT-1800-2025), also an original-13 state.

**Why this entry exists.** **Input data:** juan-subnational rows for Delaware ("Delaware" / USA subnational label), part of the same batch that produced usa-al, usa-ar, usa-az, usa-co and usa-ct in this session; the routing decision's own reasoning cites the underlying extract's data years as running from 1866, though the exact row count for Delaware specifically was not inspected in authoring this page (see open questions). **Previously matched to:** the country-wide USA national rows (USA-1867-1959, USA-1959-2025, etc.), which is wrong because those rows represent the entire United States (~3.8 million km2 at any given era) rather than the ~5,130 km2 Delaware actually reports on -- a roughly 750x territory mismatch. **Confirmation of distinctness:** Delaware is a constitutionally and administratively distinct U.S. state with its own state government, and juan-subnational tabulates it as a separate reporting unit from both the national total and from neighboring states, which is the same evidentiary bar already applied to create the sibling state-level entries in this batch.

## Territorial extent

**Polygon status:** assigned. `polygon_source: gadm-4.1-adm1`, feature `USA.8_1`, matching Delaware's present-day state boundary. Delaware's boundaries were substantially settled before this entry's 1800 start (the Mason-Dixon-derived Delaware/Maryland line and the Twelve-Mile Circle with Pennsylvania both predate statehood), so the modern GADM boundary is a low-risk proxy for the full 1800-2025 span, the same reasoning used for the other original-13 and long-settled Eastern states in this batch (cf. usa-al, usa-ct).

**Territory description:** the modern U.S. state of Delaware, on the Delmarva Peninsula's northern end along the western shore of Delaware Bay, bordered by Pennsylvania to the north, Maryland to the west and south, and New Jersey across the bay/river to the east. It is the second-smallest U.S. state by area. **Area measured from the attached GADM polygon: approximately 5,130 km2** (this is a measurement of the geometry, not an independent historical figure -- no separately sourced historical km2 for Delaware was consulted for this page).

## Predecessors and successors

No predecessor or successor: Delaware has been a single, continuously governed state since before this entry's 1800 start (predecessor list empty because no distinct prior polity precedes it in the table -- it is simply the earliest era the containing national chain supports) and it remains a current U.S. state, so successor is empty and end_year is the open convention value 2025.

## Sourced claims

- Delaware was the first of the thirteen original states to ratify the U.S. Constitution, doing so unanimously on 7 December 1787, which is the historical basis (though not the effective start_year, see decisions) for its long-standing nickname "The First State".
- juan-subnational is the sole source assigning Delaware-level (state-of-the-United-States) rows in this pipeline's data, distinguishing this entry from the country-wide USA-* national rows that the data was previously (mis)matched to before this page's creation.

## Decisions

### d-start-year-1800-not-1787

**start_year set to 1800, departing from the proposed 1787 admission year**

The routing decision that motivated this page proposed start_year=1787, Delaware's ratification date and the first of the original 13. But the polity table's earliest USA national row is USA-1800-1803 ("United States (original)"), and the container-tiling rule this harness enforces rejects any container edge whose span falls outside the container's own recorded span (1800-1803 at the earliest). There is no national USA row covering 1787-1800 to attach an edge to, so a 1787 start would leave a 13-year gap the containment gate cannot pass. Rather than invent an unbacked container row, this page follows the precedent already set for Connecticut (USA-CT-1800-2025), an original-13 state that ratified in 1788 but whose page also starts at 1800 for the identical reason: the earliest available container is what bounds the earliest state row, not the state's own history. If USA gets an earlier national row in a future ingest (e.g. USA-1787-1800 covering the Confederation-to-Constitution period), Delaware's start_year should be revisited alongside every other original-13 state page that made the same compromise.

## Open questions

### oq-pre-1800-gap

**Is there a case for a USA-1787-1800 (or similar) national row that would let original-13 states start at their true admission years?**

Delaware (ratified 1787) and Connecticut (ratified 1788, see USA-CT-1800-2025) both have their subnational start_year pinned to 1800 purely because that is where the polity table's national USA chain begins (USA-1800-1803, cow=2). If a future ingest adds an earlier national USA row -- covering the Confederation period or the 1787-1800 span under the same COW state code -- every original-13 state page, including this one, should be re-spanned to its actual ratification year rather than the shared 1800 floor. Until then, the 13 years 1787-1800 of Delaware's actual statehood are simply not represented by any polity row in this database.

### oq-juan-subnational-coverage

**What does the juan-subnational source actually cover for Delaware, and does it justify the full 1800-2025 span?**

This entry's sole listed source is juan-subnational, and the page was authored to create a container/routing home for that source's Delaware rows, not because a specific row count was inspected here. It is unconfirmed whether juan-subnational has continuous Delaware coverage across 1800-2025 or only a subset of years (e.g. post-1866, as flagged for the country as a whole in the routing decision's own reasoning, which described the raw data's start year as 1866). If the source is sparse before 1866, that should be noted rather than implying dense reporting back to 1800.

### oq-boundary-vintage

**Does the GADM 4.1 Delaware boundary match the state's boundary at each point since 1800?**

Delaware's northern boundary with Pennsylvania (the 12-mile circle) and its Delaware/Maryland line were essentially settled by the late 18th century, well before this entry's 1800 start, so the vintage risk is low as the routing decision states. But no specific check was made here against, e.g., 19th-century survey disputes (the Wedge, later resolved in 1921) that could mean the modern GADM polygon slightly over- or under-states the historical boundary in the 1800s. This is flagged rather than resolved.
