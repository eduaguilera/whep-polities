# Czechoslovakia (1947-1992) [SUPERSEDED]

> **This polity has been retired.** It is a duplicate of F51-1947-1993 (Czechoslovakia 1947-1993), which is the canonical entry for post-WWII Czechoslovakia. All data previously routed to CZE-1947-1992 should be re-routed to F51-1947-1993. See decision dec-cze-1947-1992-retire below.

## Summary

CZE-1947-1992 was a miscoded duplicate of F51-1947-1993. Both polities covered the same sovereign state (post-WWII Czechoslovakia, ~127,000 km²) for an overlapping period (1947-1992/1993). The root error was assignment of iso3_code=CZE and cow_code=316, which belong to the Czech Republic (post-1993 successor), not to Czechoslovakia (COW code 315). Having two active entries for the same state caused double-counting of staple production data (wheat ~1,514,000 t; sugar ~4,946,000 t) confirming full-Czechoslovakia magnitude, inconsistent with a Czech-Lands-only (~79,000 km²) entry.

## Territorial extent

This row never had an independent polygon. It referenced CShapes 2.0 feature 315 (cowcode=315), identical to F51-1947-1993. The canonical entry F51-1947-1993 uses the same polygon (vintage 1947). No territory was unique to this row.

## Decisions

### dec-cze-1947-1992-retire

**Date:** 2026-06-29

**Decision:** Retire CZE-1947-1992. Redirect all data and aliases to F51-1947-1993.

**Evidence:**
- Staple magnitudes (wheat ~1,514,000 t; sugar ~4,946,000 t) match full-Czechoslovakia scale, not Czech-Lands-only (~79,000 km²) which would produce roughly half those totals.
- F51-1945-1947 (contain_ratio=1.0, wheat 1,320,000 t, sugar 4,341,000 t for 1946) confirms spatial extent identity with CZE-1947-1992.
- CShapes polygon_feature_id=315 is identical between both polities.
- CZE/316 codes belong to the Czech Republic (1993-), not to Czechoslovakia.
- COW assigns code 315 to Czechoslovakia; code 316 is the Czech Republic.

**Alias redirects applied:**
- `czech republic` (years 1947-1993) -> F51-1947-1993 (was: CZE-1947-1992)
- `czechoslovakia` (years 1947-1993) -> F51-1947-1993
