# Morbihan (department of France)

## Summary

Morbihan is one of France's original départements, a second-tier administrative subdivision (below the national state, above communes and, in the modern era, above arrondissements/cantons) covering the southern Breton coast around the Gulf of Morbihan, with its préfecture at Vannes. It was created in March 1790 by the National Assembly's reform that replaced the old provinces of the Ancien Régime with a grid of roughly 83 départements of comparable size, largely out of the southern portion of the historic province of Brittany. `type: subnational` is used, exactly as for ESP's provincial rows (esp-17, esp-as, esp-ca) and JPN's prefecture rows (jpn-aomori): Morbihan was never a sovereign entity and France held continuous sovereignty over it throughout 1790-2025, but statistical and administrative sources report at the département level, so a subnational reporting-territory row is needed without competing against the national FRA chain in sovereignty-based matching. Its start year (1790) follows the country's default départment start rule rather than the first year any dataset happens to report it, because Morbihan is not among the four documented exceptions (Belfort, Alsace-Lorraine, Corsica's 1793 split, the overseas départements) that would justify a later or different start.

**Why this entry exists.** This entry captures unit FRA-FRH04 (Morbihan) from the agent-harness's admin-unit routing pass over France: the pipeline identified Morbihan as a French départment-level administrative unit with no existing matching polity row. Before this entry, any data reported at Morbihan's level had nowhere correct to route: the only existing FRA rows are national totals (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025, and the deprecated FRA-1800-1919), none of which represents the départment specifically, so Morbihan-level statistics would either have been silently dropped or mis-routed to a national aggregate roughly 79x too large (France's ~551,695 km2 against Morbihan's ~6,823 km2). What confirms Morbihan is a distinct, individually-tracked administrative unit rather than an artefact of the routing pass is INSEE's own statistical apparatus: Morbihan has held a continuous, individually numbered administrative identity (INSEE code 56) since 1790, exactly the kind of standing, independently-published administrative unit this repository's départment/province-level entries (the ESP-* provincial rows, JPN prefecture rows) already track elsewhere.

**Territory description:** Morbihan is a French département on the south coast of Brittany, bordered by the Atlantic Ocean (including the tidal Gulf of Morbihan) to the south, Finistère to the west, Côtes-d'Armor to the north, and Loire-Atlantique and Ille-et-Vilaine to the east. Its préfecture is Vannes; other principal towns include Lorient, Pontivy, and Auray. Its modern area is approximately 6,823 km2 (INSEE figure for the current département), and this figure has been essentially stable since the department's 1790 creation -- unlike Alsace-Lorraine, Belfort, or Corsica, Morbihan is not among the documented exceptions to France's départements having fixed 1790-origin boundaries, so a modern administrative boundary (once sourced) would be expected to serve as a low-risk proxy across the full 1790-2025 span, subject to the caveat in the open questions below about unverified minor commune-level boundary adjustments.

## Predecessors and successors

Morbihan has no predecessor or successor polity rows: it was created directly by the March 1790 National Assembly decree establishing the départements as one of the original roughly 83 units carved from the pre-revolutionary province of Brittany (it corresponds closely to the southern part of historic Brittany around Vannes), and it has continued under that same name and administrative status without interruption or renaming through to the present. It is not one of the four documented France-wide departures from the default 1790 start (Territoire de Belfort, the Alsace-Lorraine départements, the Corsican split into Corse-du-Sud/Haute-Corse, or the overseas départements), so no predecessor row is needed to represent an earlier different administrative status. It remains current (end_year 2025 per the open-end convention), so no successor row exists either.

## Decisions

### d-code-numeric-insee

**Used the numeric INSEE department code (FRA-56) rather than a name-abbreviation code**

The dominant subnational pattern is <ISO3>-<SUBUNIT>-<start>-<end>, and for French départements the natural SUBUNIT token is the INSEE department number, not a letter abbreviation. Morbihan is INSEE department 56 (ISO 3166-2:FR-56). A letter code such as MOR would collide in spirit with the existing bespoke code MOR (Morocco, 1800-1904 and related rows) even though the string is namespaced under FRA- and would not collide exactly in the table. There is direct sibling precedent for numeric subunit tokens: esp-17-1833-2025.md uses Spain's numeric province code 17 (Girona) rather than a letter code, alongside other ESP rows that do use letters (esp-as, esp-ca). Since France has no existing subnational precedent to depart from (0 existing FRA-* subnational rows), the INSEE numeric code is the most legible and least ambiguous token: it is the identifier the source administrative system itself uses, it is stable across the department's entire 1790-2025 life (unlike a postal abbreviation, which for Morbihan is inconsistently rendered as MOR/MRB in different systems), and it avoids inventing a new abbreviation this repository would need to remember.

## Open questions

### oq-no-polygon-source

**No registered source in this repository carries French ADM1 (département-level) boundaries**

Every source currently registered in scripts/sources.yaml that touches FRA (cshapes-europe, cshapes-2.0) is country-level only. The local gadm-4.1-adm1 file on disk (data/geodata/gadm-4.1/gadm41_adm1.gpkg) is confirmed to be a subset of 81 countries and does not include FRA (0 rows for France), even though GADM's full global ADM1 release does cover French départements. So this page is created with polygon_source: none and polygon_status: unassigned rather than routed to a source that cannot actually produce the feature today. Resolving this requires either downloading the full global GADM 4.1 ADM1 release (licence terms not yet verified for this repository's use) or sourcing IGN ADMIN-EXPRESS boundaries for French départements, then adding a Morbihan feature under a newly registered source slug -- neither of which this page-authoring task is positioned to do.

### oq-1790-start-year-boundary-stability

**Whether Morbihan's boundary has been perfectly stable since 1790, or only 'essentially' so**

This page assumes Morbihan's boundary has been stable since its creation as one of the ~83 original 1790 départements, following the routing decision's span_basis and the country's default-start convention (departures are only Belfort, Alsace-Lorraine, Corsica, and the overseas départements -- Morbihan is none of these). But 'essentially unchanged since 1790' has not been checked against a canton-level or arrondissement-level administrative history for Morbihan specifically (e.g., minor 19th-century commune reassignments at borders with Loire-Atlantique or Finistère are common across French départements and have not been ruled out here). If any such adjustment is later confirmed, a modern administrative boundary would still be an adequate but imperfect proxy for the full 1790-2025 span, and the km2 figure below should be treated as approximate rather than exact for the earliest decades.
