# Serbia (2008-2025)

## Summary

> **Polygon corrected 2026-08-05 — it had included Kosovo for seventeen years.**
> `polygon_feature_year` was `2006`, which selects CShapes gwcode 340's **2006-2008**
> time-step: Serbia *including* Kosovo, 87,993 km². This row runs 2008-2025 and its
> sibling [kos-2008-2025](kos-2008-2025.md) is a live polity covering exactly that
> Kosovo, so Kosovo's 10,735 km² was claimed twice — measured at **100.0% of Kosovo
> inside this polygon** — for the whole 2008-2025 span. The geometry was byte-identical
> to `SRB-2006-2008`'s, which is what a duplicated feature-year looks like.
>
> Changed to `polygon_feature_year: 2008`, which selects the 2008-2019 step at
> 77,183 km² in source and 77,251 km² after simplification.
>
> **The page said so all along.** Both the Summary and Territorial extent below state
> "~77,474 km² (excluding Kosovo)" — the prose was right and the binding was wrong.
> Nothing compared them, because `polygon_area_km2` is `null` here: `validate_polygons`'
> area check is opt-in via that hand-entered field, so a wrong `polygon_feature_year` on
> a null-area row is undetectable (issue 59). `validate_spatial_containment` reports
> containers holding **three or more** coexisting polities and this one holds one, a
> limitation that check documents by name — it lists `SRB-2008-2025 contains
> KOS-2008-2025` as a case its threshold cannot see. An area is now declared below so the
> comparison exists.
>
> This row is `status: reviewed`, the only reviewed page in the family. Review did not
> catch it.
