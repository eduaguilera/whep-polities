# Cádiz (province of Spain)

## Summary

This entry represents Cádiz, one of the 50 provinces of Spain created in 1833 by the Javier de Burgos territorial reform, which for the first time divided the country into a uniform grid of provincial administrative units. Cádiz province occupies the southwestern tip of Andalusia on the Atlantic coast, containing the cities of Cádiz, Jerez de la Frontera, and Algeciras, and bordering Málaga and Sevilla provinces, plus the British territory of Gibraltar. `type: subnational` is used because this is a first-order administrative subdivision of a sovereign state (Spain), not an independent country -- the same convention already applied to the seven sibling ESP province rows (Asturias, Cantabria, A Coruña, Lugo, Madrid, Ourense, Pontevedra). This entry exists because national-level Spain data (ESP-1800-2025) cannot represent province-specific statistics, and the harness's country convention for Spain defaults every NUTS/province unit without a Canary Islands departure to a 1833 start year tied to the same reform event, which is why ES612 (Cádiz's NUTS3 code) was routed here rather than left unmatched or folded into the national row.

**Why this entry exists.** Input data: this entry is created to receive the NUTS3-coded unit ES612 (Cádiz) as identified in the harness's routing decision, following the same pattern already applied to sibling Spanish province units that produced ESP-AS-1833-2025, ESP-CA-1833-2025, and the five other existing ESP-XX rows. Country and unit_id are given directly in the decision (country: Spain, admin_name: ES612); the decision itself is a routing/creation decision rather than a data-ingest record, following the identical pattern of prior sibling creations that carried NUTS-coded provincial statistics. Previously, ES612 (and Cádiz generally) had no dedicated polity row: the only ESP candidates in the table before this entry were A Coruña, Madrid, and the national Spain polity (ESP-1800-2025), none of which represents Cádiz's own territory, so any data keyed to Cádiz would have been misrouted to the national aggregate, diluting a province-level statistic into an all-Spain total. What confirms this entity is distinct: Cádiz is a de jure, continuously existing first-order administrative division of Spain with its own INE statistical code (cpro=11) and its own NUTS3 code (ES612), officially distinct from every other Spanish province since 1833 -- the same standing already relied upon to justify the seven existing ESP-XX sibling rows.

## Territorial extent

**Polygon status:** Assigned. Source `mapspain-ign`, feature id `11` (INE provincial code `cpro=11`, Spain's official statistical code for Cádiz), via the `registered_source_feature` route already used for sibling provinces (Asturias, Cantabria, A Coruña, Lugo, Madrid, Ourense, Pontevedra). This is a present-day IGN provincial boundary standing in for the boundary at creation in 1833; vintage risk is assessed as low because Cádiz's outline has been essentially stable since 1833 (no province-level splits or major boundary revisions are documented for it), and because the polity's own span (1833-2025) runs up to the present, so the "modern" boundary is not actually a proxy for an earlier, different shape -- it is the boundary for most of the span, including today.

**Territory description:** Cádiz province covers the southwestern coastal corner of Andalusia, Spain, at the point where the Atlantic Ocean meets the Strait of Gibraltar. It includes the provincial capital Cádiz, the larger city of Jerez de la Frontera, and the port town of Algeciras opposite Gibraltar. It is bounded by Málaga province to the east, Sevilla province to the north, and the Atlantic coastline plus the British territory of Gibraltar to the south. A reader can locate it on a modern map as the southwesternmost of Andalusia's eight provinces. Its measured area from the attached geometry is approximately **7,440 km2** (reported separately as the harness's cross-check figure, not written into the frontmatter as a self-referential value); this is consistent with published present-day figures for the province (commonly cited as ~7,436 km2), supporting the low-vintage-risk assessment above since an independently known modern figure matches the polygon within rounding.

## Predecessors and successors

Cádiz has no predecessor polity: it was created directly by the 1833 Javier de Burgos reform, which established Spain's 50 provinces simultaneously rather than reorganizing pre-existing units into it, so there is no earlier entity to link as predecessor. It has no successor either, since the province remains a current first-order administrative division of Spain (part of the Autonomous Community of Andalusia) with no scheduled abolition or merger; end_year is open at 2025, matching the pattern used for the other ESP province rows in the table (ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR, ESP-PO), all of which are treated as ongoing.

## Sourced claims

- The 1833 Javier de Burgos royal decree divided Spain into 49 (later 50, with the Canary Islands split) provinces in a single simultaneous administrative reform, of which Cádiz was one.
- INE (Instituto Nacional de Estadística) assigns Cádiz province the official statistical code cpro=11, used as the polygon_feature_id in mapspain-ign to identify this unit.

## Decisions

### d-code-pattern-iso3-subunit

**Code follows the dominant ISO3-SUBUNIT-start-end pattern, not a bespoke code**

Cádiz is an ordinary administrative province created simultaneously with the other 49 Spanish provinces in the 1833 Javier de Burgos reform. It has no separate identity as a historical territory the way ALK (Alaska Territory) or HYD (Hyderabad) do -- it is a generic tier-1 subdivision of Spain, exactly like the seven ESP-XX siblings already in the table (ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR, ESP-PO). Cádiz's ISO 3166-2 code is ES-CA, but ES-CA is already taken by Cantabria in this table (ESP-CA-1833-2025), so I used CDZ (first three letters) to avoid a collision while keeping the ISO3-SUBUNIT-start-end pattern intact.

### d-single-container-edge

**Single container edge for the whole span**

The container is ESP-1800-2025, which the polity table shows spans 1800-2025 and therefore fully covers the requested 1833-2025 span with no need for multiple edges -- Cádiz province was never administered through any container Spain row change that would require splitting the containment into multiple eras.

## Open questions

### oq-mapspain-ign-vintage

**Present-day IGN boundary stands in for the 1833 creation without any pre-modern check**

polygon_source mapspain-ign supplies the current INE provincial boundary (cpro=11) rather than any boundary contemporaneous with 1833. Cádiz province's outline is described as stable since its creation, but this has not been checked against a historical atlas or 19th-century administrative map -- Spain's province boundaries did see minor municipal-level adjustments through the 19th and 20th centuries (e.g., disputed municipal exchanges with neighbouring provinces), and none of those are verified against the current 7,440 km2 IGN shape used here. A dedicated check against a 19th-century source would either confirm the near-zero vintage risk claimed in the routing decision or reveal a small discrepancy.

### oq-open-end-year-currency

**Open end_year of 2025 assumes the province still exists unchanged**

end_year is set to 2025 on the assumption Cádiz remains a current, unaltered province of Spain, consistent with the sibling ESP-XX rows. This has not been independently re-verified against any 2024-2026 administrative change in Spain (e.g., any devolution proposal affecting Andalusian provinces); if Spain's province tier is ever reorganized this row's end_year and the container edge upper bound would both need revision.
