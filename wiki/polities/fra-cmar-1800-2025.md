# Charente-Maritime

## Summary

Charente-Maritime is a French département on the Atlantic coast, centred on La Rochelle and Rochefort, corresponding to the historical province of Aunis and part of Saintonge. It was created in 1790, under the name Charente-Inférieure, as one of the roughly 83 original départements formed when the Revolutionary assembly abolished the pre-1789 provinces and redrew France into administrative units of roughly equal size centred on a chef-lieu no more than a day's ride away. It was renamed Charente-Maritime in 1941, a name change with no territorial consequence — Vichy-era relabelling of several départements whose old names ('Inférieure', meaning lower/downstream on the Charente river) had acquired a pejorative ring. This entry is `type: subnational` because a département is not a sovereign state; it sits inside the national FRA chain, which itself is split into eras (1800-1919, 1919-2025) by the loss and return of Alsace-Lorraine — a discontinuity in the national container that this département's own span must tile across even though Charente-Maritime itself was never affected by that border change.

**Why this entry exists.** This entry is created to route FAO/Mitchell-style historical agricultural and economic data (unit id `FRA-FRI32`, admin_name `FRI32`) tabulated at the level of the French département of Charente-Maritime, spanning 1862-2023 per the intake row range, into its own polity rather than the national France row. Previously such département-level rows had no dedicated polity and would fall through to one of the three national FRA rows (`FRA-1800-1871`, `FRA-1800-1919`, `FRA-1871-1919`, `FRA-1919-2025`), which is wrong: those rows are for all of metropolitan (and at times Alsace-Lorraine-inclusive) France, roughly 15-90x the area of a single département, and match_existing is inapplicable because no existing row is this département itself. Mitchell's International Historical Statistics: Europe series confirms the entity was tabulated as a distinct statistical and administrative unit — reporting Charente-Inférieure/Charente-Maritime figures separately from French national totals — which is the same standard ("a reporting unit statistics were collected on, sovereign or not") used elsewhere in this table (see the Manchuria exemplar) to justify a dedicated subnational row.

## Territorial extent

**Polygon status:** Not yet assigned. `polygon_route` from the routing decision is `registered_source_unfetched`: GADM 4.1's admin-1 layer is exactly the right granularity for a French département and the source is already registered in `scripts/sources.yaml` as `gadm-4.1-adm1`, but the file present on disk (`data/geodata/gadm-4.1/gadm41_adm1.gpkg`) is a curated subset covering only 81 countries and returns zero features for FRA. So `polygon_source` is set to the registered slug `gadm-4.1-adm1` (not `none`, and not the route name `registered_source_unfetched` itself), `polygon_feature_id` is null, and `polygon_status` is `unassigned` pending that fetch — no `polygon_area_km2` is claimed here because no geometry is attached.

**Territory description:** Charente-Maritime is a coastal département in the Nouvelle-Aquitaine region of southwest France, bordered by the Atlantic Ocean to the west, and by the départements of Vendée, Deux-Sèvres, Charente, Dordogne, and Gironde. Its administrative seat is La Rochelle; other principal towns are Rochefort, Saintes, and Royan. It includes the islands of Ré and Oléron. Its modern area, per INSEE, is approximately **6,864 km²**. The département's boundaries have been essentially unchanged since their creation in 1790 (as Charente-Inférieure), which is why a modern GADM adm1 feature — once fetched — would be a low-risk proxy for the full 1790/1800-2025 span, worth noting on this page rather than treating as a blocking concern.

## Predecessors and successors

No predecessor: Charente-Maritime (as Charente-Inférieure) was one of the original ~83 départements created by the Revolutionary assembly in 1790 out of the province of Aunis and part of Saintonge, with no prior polity row in this table to descend from. No successor: it remains a current French département in 2025, so `successor` is empty and `end_year` is the open-ended 2025 used for all still-current French subnational rows in this table. It was renamed from Charente-Inférieure to Charente-Maritime in 1941 (Vichy-era renaming of several "Inférieure" départements), but this is a name change, not a territorial or administrative discontinuity, so it does not split the row.

## Decisions

### d-code-and-start-year

**Code and start_year set to 1800, not the département's true 1790 founding date**

The proposed routing decision suggested start_year 1790 (the département's actual creation date, under the name Charente-Inférieure). However, the containment rule requires container edges to tile the entire span with no gap, and the earliest France-national row available in the polity table, FRA-1800-1919, only begins in 1800 — there is no FRA row covering 1790-1800. Rather than leave a 10-year uncontained gap (which the containment gate rejects, since an edge outside either party's own span is invalid), this entry's start_year was set to 1800 to align with the earliest available national container, and the polity code was chosen as FRA-CMAR-1800-2025 to keep the years in the code consistent with the frontmatter as required. The department's true founding in 1790 is documented in the summary and predecessors_and_successors sections for the historical record, but the row's formal span begins where a valid container chain begins. If a future FRA row extending back to 1790 is added, this entry's start_year should be revisited.

### d-subunit-code-cmar

**Subunit code CMAR chosen over abbreviations tied to obsolete department numbering**

The dominant pattern for French subnational rows in this table (57 of 66 subnational rows follow <ISO3>-<SUBUNIT>-<start>-<end>) uses short alphabetic subunit codes such as ESP-AS, ESP-CA for Spanish provinces. INSEE's own numeric code for Charente-Maritime is '17', which collides in this table's convention with the already-used esp-17 (a Spanish province code, esp-17-1800-2025 is a rejected/orphaned page mentioned in the task), so a numeric code was avoided to prevent ambiguity. CMAR (from Charente-Maritime) was chosen as a short, mnemonic, letters-only subunit code following the ESP-xx style precedent, and it does not collide with any existing code in the table.

## Open questions

### oq-gadm-fetch-needed

**GADM 4.1 admin-1 layer for France still needs to be fetched**

The registered source gadm-4.1-adm1 is the right granularity for this département but the on-disk GeoPackage is a curated 81-country subset that excludes France entirely (0 features returned for FRA). Until someone fetches or adds the full/global GADM 4.1 admin-1 data (or an equivalent full France department layer) for FRA, polygon_status stays unassigned and polygon_feature_id stays null. This affects not just this entry but every other French département row that shares the same gap.

### oq-pre1800-span-gap

**Whether a pre-1800 France container should be added to extend this entry's start_year back to 1790**

Charente-Maritime (as Charente-Inférieure) was actually created in 1790, but this entry's start_year was pinned to 1800 because no FRA national row in the polity table currently covers 1790-1800, and containment tiling forbids a gap. If a FRA-1790-1800 (or similarly spanning) national row is ever added to the table, this entry's start_year and code should be revisited and potentially changed to FRA-CMAR-1790-2025 to reflect the département's true founding date.

### oq-mitchell-label-continuity

**Whether Mitchell's 1862-2023 series uses a consistent label across the 1941 Charente-Inférieure to Charente-Maritime rename**

The intake row range spans 1862-2023, crossing the 1941 renaming from Charente-Inférieure to Charente-Maritime. It has not been verified whether Mitchell (or whatever downstream FRA-FRI32 source is used) consistently labels this unit across the rename, or whether pre-1941 and post-1941 rows carry different raw labels that could risk being split or mis-routed by the matcher. This should be checked before ingest is finalized.
