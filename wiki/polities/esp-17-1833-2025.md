# Girona (province of Spain)

## Summary

Girona is one of the four provinces of Catalonia, in the north-east of Spain, bordering France and Andorra to the north and the Mediterranean Sea to the east. Corresponding to NUTS unit ES512, it was created along with the rest of Spain's current provinces by Javier de Burgos's 1833 territorial reorganisation, which replaced the country's earlier kingdoms and historical territories with 49 (later 50) provinces built for uniform civil and statistical administration. Girona's provincial boundary has been essentially unchanged since 1833, corresponding closely to the historical comarques of the Alt and Baix Empordà, Gironès, La Selva, Garrotxa, Ripollès and the Spanish portion of La Cerdanya. This entry is `type: subnational`, not national, because Girona has never held sovereignty of its own; it is a first-order administrative division of Spain, reporting through provincial (and, since 1980, Catalan autonomous-community) statistics that this row exists to hold separately from both the ESP national total and Spain's other 49 provinces, none of which share Girona's territory.

**Why this entry exists.** This entry captures the NUTS-3 unit ES512 (Girona) from the Eurostat/INE province-level series the pipeline is routing, alongside 49 sibling ES1xx/ES2xx province units that were all verdicted create_new under the same reasoning: no existing polity in this database is named Girona or covers its territory. Before this decision, rows for ES512 had no home to be routed to other than the national total ESP-1800-2025, which aggregates all 50 provinces and cannot represent Girona's own figures, or the neighbouring province codes ESP-CO (Córdoba) and ESP-MD (Madrid), which are different, non-adjacent provinces entirely and were never plausible matches. A prior page under this same code (ESP-17-1833-2025) existed with an assigned mapspain-ign polygon (feature id 17) but was removed from the wiki in an earlier stage of this same harness run (visible as a `D` in git status alongside a wave of other Spanish province deletions/recreations), leaving the code free to reissue. Girona's status as a distinct administrative and statistical unit is confirmed by its own INE provincial code (cpro 17) and by its continuous appearance as a separate NUTS-3 region (ES512) in Eurostat's regional statistics, which is the immediate source motivating this entry.

## Territorial extent

**Polygon status:** Not yet assigned. `mapspain-ign` is the correct source — it is the IGN provincial-boundary dataset already used for all other Spanish provinces in this database (49 sibling ESP-XX-1833-2025 rows, keyed by INE province code `cpro`), and Girona's own `cpro` is 17 — but the source file (`data/geodata/mapspain-ign/provinces.gpkg`) is not present on disk in this run, so no specific feature can be verified or attached yet. `gadm-4.1-adm1`'s 18 ESP admin-1 features do not include a matching Girona unit, ruling it out as a fallback. `polygon_status: unassigned` and `polygon_feature_id: null` reflect this; once the source is fetched, `cpro=17` is the feature to attach.

**Territory description:** Girona province covers the north-easternmost corner of Spain and of Catalonia, reaching from the French border at the Pyrenees south to the Tordera river and east to the Costa Brava on the Mediterranean. Its provincial capital is the city of Girona. The modern province spans approximately 5,910 km2 — a figure from INE/IGN provincial-area statistics for cpro 17, not a measurement of any geometry attached by this entry, since none is yet attached. Vintage risk for this figure and for the eventual polygon is low: the 1833 provincial boundary is essentially unchanged today, so a modern IGN boundary is a valid proxy for the entry's full 1833-2025 span.

## Predecessors and successors

No predecessor: Girona province was created directly by the 1833 Javier de Burgos reform, which did not carve it from any single prior unit tracked in this database but redrew Catalonia's earlier comarcal/corregimiento divisions wholesale. No successor: the province remains current (open `end_year: 2025`), and the 1980 creation of the Catalan autonomous community did not abolish or absorb the province, which continues to exist as the layer beneath it for both civil registry and Eurostat NUTS-3 reporting.

## Sourced claims

- Eurostat's NUTS 2021 classification lists ES512 (Girona) as one of Catalonia's four NUTS-3 provinces, matching Spain's own INE provincial code cpro=17.
- The 1833 Javier de Burgos royal decree (division territorial de España) established Spain's 49 (later 50) provinces, including Girona, replacing the prior historical kingdoms and corregimientos for uniform civil and statistical administration.

## Decisions

### d-reuse-esp-17-code

**Reissued ESP-17-1833-2025 rather than inventing a new code**

A page for Girona already existed at polity_code ESP-17-1833-2025, using the province's INE cpro code (17) as the subunit segment rather than a letter abbreviation, consistent with how mapspain-ign's id_column (cpro) keys all 50 ESP provinces. That page was deleted from the wiki in an earlier stage of this same harness run (visible in git status as `D wiki/polities/esp-17-1833-2025.md`), which freed the code without indicating the territory itself was wrong. Since the routing decision's proposed name, span, and container for ES512/Girona match that prior page exactly, and ESP-GI-1833-2025 (the letter-code candidate) is already held by a different province (Gipuzkoa), reissuing ESP-17-1833-2025 was preferred over minting a new letter-based or numeric variant, to avoid creating a second, competing code for the same territory once the deleted page's history is reconciled.
