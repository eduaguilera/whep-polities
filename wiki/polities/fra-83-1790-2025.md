# Var (département)

## Summary

Var is a French département on the Mediterranean coast in the southeast, one of the original ~83 units created by the 1790 Revolutionary administrative reform, with its historic and modern seat at Toulon, France's principal Mediterranean naval base. It is entered here as `type: subnational` because a département is a sub-unit of the sovereign French state, not a state in its own right: France's own sovereignty and national-scale statistics belong to the FRA-* national chain (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025), and this row exists solely to carry data that a source tabulates at department scale for this specific unit. The routing decision (unit FRA-FRL05) found no existing polity match by name for Var itself — the FRA-* candidates in the database are national totals across different eras, which contain Var but are not Var — confirmed Var is not one of the four documented FRA departure cases (Territoire de Belfort, the Alsace-Lorraine trio, the Corsica 1793/1975 split, or an overseas département) that would require a non-default span, and so applied the country's default rule for an original Revolutionary département: creation-year start (1790) and an open end (2025), since the department is still current. This mirrors the immediately preceding sibling entries FRA-04-1790-2025 (Alpes-de-Haute-Provence) and FRA-05-1790-2025 (Hautes-Alpes) in structural approach: same span rule, same container-chain resolution, and the same unresolved GADM polygon-fetch gap.

**Why this entry exists.** This entry captures unit FRA-FRL05 ("Var") from the agent-harness routing pipeline: French department-level data reported under the juan-subnational source, tabulated at department scale for this specific unit across its operative years. Before this entry, the unit had no polity match in the database at all — routing found no name match among existing rows, since the FRA-* candidates in the database are national totals across different eras (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025) that contain but are not Var itself. Routing it to the national FRA-1919-2025 row instead would have folded a ~5,973 km² administrative subdivision into a national total roughly 90 times larger in area, exactly the kind of scale mismatch that is itself evidence the data was previously unmatched or would have been mis-routed had it defaulted to the national chain. What confirms this is a distinct, addressable reporting unit rather than an arbitrary carve-out is straightforward administrative continuity: Var has been one of France's original 1790 départements for 235 years, treated as a first-class INSEE reporting geography throughout (department code 83), which is exactly the persistent unit type the country's routing convention directs should get its own row absent one of the four listed exceptions (Belfort, Alsace-Lorraine, Corsica, overseas départements) — none of which apply to Var.

## Decisions

### d-container-spans-full-1790-range

**Container chain extended to 1790, not just FRA-1919-2025**

The routing decision proposed container_code FRA-1919-2025 alone "for convenience" but explicitly flagged in routing_concerns that Var's actual span (1790-2025) crosses all three national FRA eras (1800-1871, 1871-1919, 1919-2025) in the containment chain, and that the harness's containment gate requires edges to tile the whole span with no gap. Using a single 1919-2025 edge would leave 129 years (1790-1919) uncontained and would be rejected by the containment gate, which checks that an edge falls inside both parties' spans. This page therefore uses three container edges, one per national era, mirroring the pattern already established by the sibling entries FRA-04-1790-2025 (Alpes-de-Haute-Provence) and FRA-05-1790-2025 (Hautes-Alpes), which face the identical span-vs-container-chain mismatch and resolve it the same way. This departs from the routing decision's literal proposed.container_code field but implements the routing_concerns note attached to that same decision, and follows the precedent already on file for two sibling FRA subnational rows.

### d-polygon-source-registered-unfetched

**polygon_source recorded as gadm-4.1-adm1 despite 0 local France rows, per registered_source_unfetched route**

The routing decision's polygon_route is new_source_needed with polygon_source left blank, on the reasoning that no registered source currently carries French département polygons (gadm-4.1-adm1 is registered but the locally cached extract covers only an 81-country subset excluding France). However, per this pipeline's harness-level instruction, new_source_needed and registered_source_unfetched are the two routes whose naive polygon_source values (new_source_needed itself, or a blank) are rejected by validate_declared_sources — a registered slug or none is required. Since gadm-4.1-adm1 IS a registered source in principle for adm1-level administrative boundaries and the gap here is a fetch/coverage gap (0 France rows locally) rather than an absence from the registry, this page follows the same resolution as the sibling FRA-04 and FRA-05 entries: polygon_source is set to the registered slug gadm-4.1-adm1, polygon_status is unassigned, and polygon_feature_id is null, with the fetch gap documented as an open question rather than silently dropped.

Until the France-inclusive GADM extract or an alternative source such as IGN ADMIN-EXPRESS is fetched and checked at the correct tier, no polygon_feature_id can be assigned and polygon_area_km2 cannot be measured.

### oq-var-1793-corsica-relationship

**Whether Var's early boundary interacted with the 1793/1860 Alpes-Maritimes carve-out needs checking**

Var as created in 1790 initially had a larger territory than its present extent: the historic département of Var briefly included what became Alpes-Maritimes (created in stages, formalized in 1860 when the County of Nice was annexed to France) and interacted with early Revolutionary administrative reorganizations along the Italian frontier before the modern boundary stabilized. This entry currently treats Var's span as a flat 1790-2025 continuity following the country convention's default rule, on the same basis as the FRA-04/FRA-05 sibling entries, but the precise territorial boundary of 1790s Var versus its modern extent has not been individually verified against a period-appropriate map, unlike the more clearly bounded interior Alpine départements FRA-04 and FRA-05. This should be checked before any polygon feature is assigned for pre-1860 years specifically.
