# Rest of World

## Summary

WHEP aggregate reporting-area row for residual Rest of World data. This row exists so data reported against area code 999 has a first-class polity-database entry and polygon. The 1850-2023 range follows the current WHEP primary-production rows; CBS rows are observed for 1961-2023 and detailed-trade rows for 1986-2021.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** Union of the WHEP aggregate reporting-area polygons BLX, ANT, RAFR, RASI, REUR, RLAM, RNAM, and ROCE.
- **Proxy note:** This is a residual reporting-area polygon. It is not a global land mask and should be interpreted in the context of the source dataset that reports RoW.

## Sourced Claims

- `inst/extdata/regions.csv` in WHEP records `ROW`, area code 999, as RoW.
- `inst/extdata/harmonization/regions_full.csv` marks `ROW` as a CBS reporting row.

## Polygon status consolidated (added 2026-07-28)

`polygon_status` changed from `derived` to **`assigned`** in the polygon_status
vocabulary consolidation ([log lint-consolidate-polygon-status](../log.md#lint-consolidate-polygon-status)).

`derived` described *how* the polygon was made — by the `reporting-areas`
builder — rather than what it claims, and it was not one of the values
`scripts/validate_polygons.py` check C recognises, so this row could have
declared a polygon it did not have and nothing would have failed. It does have
one: the attached geometry measures **2,569,652 km2** in an equal-area projection
(the residual rest-of-world reporting area). That geometry *is* this reporting area's territory rather than a
stand-in for another entity, which is what `assigned` means. The row is now
covered by check C, and by check A whenever `polygon_area_km2` is filled in
(it is currently null, so the area comparison is skipped). The builder
provenance is unchanged and stays documented under Territorial Extent.
