# Ariège

## Summary

Ariège is a département in the far south of France, in the central Pyrenees on the border with Andorra and Spain (Catalonia), with its préfecture at Foix. It is one of the roughly 83 original départements created by the Revolutionary reform of 4 March 1790, carved out of the pre-Revolutionary province of Foix together with slivers of Languedoc. Unlike the four documented exceptions in this country's convention — the Territoire de Belfort split off from Haut-Rhin in 1871, the Alsace-Lorraine départements annexed by Germany 1871-1919, Corse's 1975 split into two départements, and the overseas départements — Ariège has kept its 1790 boundary essentially unchanged for over two centuries. This entry is `type: subnational` because a département is an administrative subdivision of France, not a sovereign state; France's own national chain (FRA-1800-1871 / FRA-1871-1919 / FRA-1919-2025) already carries sovereignty and diplomatic history, and this row exists purely to hold data reported at the département level so it is not misattributed to all of France.

**Why this entry exists.** This row is created from a routing decision for unit FRA-FRJ21 (admin_name "FRJ21"), a French administrative unit corresponding to Ariège identified via GADM-style adm1 codes, with the harness noting a data span of 1862-2023 (source rows not itemized in the routing payload beyond the year range). Before this entry, the only FRA candidates in the polity table were the national rows FRA-1800-1871, FRA-1871-1919 and FRA-1919-2025 — a département's production or demographic series would previously have been folded into one of those national totals, silently overstating the scale of whatever indicator this data measures by roughly the ratio of Ariège's area to metropolitan France's (Ariège is under 0.9% of French territory). What confirms Ariège is a distinct, long-lived administrative unit rather than an artifact of one dataset's coding scheme is that it has appeared under the same name and footprint in the INSEE département nomenclature (code 09) continuously since the 1790 creation of the départements, which is also the basis the routing decision cites for the proposed 1790 start year.

## Territorial extent

**Polygon status:** Not yet assigned. No polygon is attached to this entry yet. The routing decision's `polygon_route` was `registered_source_unfetched`: GADM 4.1 admin-1 is the correct registered source type for a French département (the convention already used for other adm1-level subnational entries in this repository), but the GADM 4.1 adm1 file currently present on disk is a curated 81-country subset that excludes France entirely (0 FRA rows). Per this pipeline's rule, when the route is `registered_source_unfetched` the slug itself — `gadm-4.1-adm1` — is recorded as `polygon_source`, with `polygon_status: unassigned` and no `polygon_feature_id`, rather than inventing a placeholder value that `validate_declared_sources` would reject (as happened to the prior `new_source_needed`/`registered_source_unfetched` literal-string attempts on this same unit).

**Territory description:** Ariège occupies the central Pyrenees in the Occitanie region of southern France, bordered by Haute-Garonne and Aude to the north, Pyrénées-Orientales to the east, Andorra and Spain's Catalonia to the south, and Haute-Garonne again to the west. Its préfecture is Foix; other towns include Pamiers and Saint-Girons. The modern département covers approximately 4,890 km2 (INSEE figure for the current INSEE code 09 boundary). Because GADM has not yet been fetched for this unit, no measured polygon area is attached to this entry — the 4,890 km2 figure is the département's own stated administrative area, not a measurement of any geometry in this repository.

## Predecessors and successors

No predecessor or successor is recorded. Ariège's boundary as a département has been continuous since 1790 with no documented split, merger, or renaming event (unlike Belfort, which split from Haut-Rhin in 1871, or Corse, which split in 1975), so there is no adjacent French subnational entry to chain to. Container assignment instead threads Ariège through all three eras of the FRA national chain (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025), since the département itself outlived the political changes — the 1871 loss of Alsace-Lorraine and its 1919 return — that mark the national chain's era boundaries, without Ariège's own territory being affected by either.

## Sourced claims

- Ariège is département code 09 in the INSEE nomenclature, created by the decree of 4 March 1790 that established the original ~83 French départements, formed principally from the former province of Foix.
- INSEE's administrative area figure for Ariège (code 09) is approximately 4,890 km2, making it one of the smaller mainland French départements.
- GADM 4.1's globally distributed admin-1 layer includes a France polygon set (ISO code FRA) at the département level; the copy currently vendored in this repository's `gadm-4.1-adm1` source is a curated subset covering 81 countries that does not include France, so the France features must be fetched separately from the global GADM release.

## Decisions

### d-start-year-1800-not-1790

**Start year set to 1800, not the 1790 creation date, to satisfy container tiling**

The routing decision's proposed start_year was 1790, matching the actual creation date of the Revolutionary départements. However, the only container candidates available in the polity table for FRA are FRA-1800-1871, FRA-1871-1919 and FRA-1919-2025, none of which reaches back before 1800 — no FRA national row exists for 1790-1800. The containment gate rejects an edge whose interval falls outside either party's span, so containing a 1790-1800 slice against FRA-1800-1871 would fail. Rather than leave a 10-year gap uncontained or fabricate a container row that does not exist in the table, this entry's start_year was moved to 1800 to align exactly with the earliest available FRA container edge. The true administrative origin (1790) is preserved in prose in the Summary and Why-this-entry-exists sections. If a FRA container row is ever added for the 1790-1800 window, this entry's start_year should be reconsidered.

### d-code-choice-fra-ari

**Chose polity_code FRA-ARI-1800-2025 after FRA-ARIEGE-1800-2025 was found taken**

A prior attempt at this same routing decision used polity_code FRA-ARIEGE-1800-2025, which was rejected because that code already has a page in wiki/polities/ for a different, unbuilt territory (its row is not in the built polities table, meaning it is either stale or describes something else entirely). To avoid colliding with that orphaned page, this entry uses a shorter subunit token, FRA-ARI, following the dominant `<ISO3>-<SUBUNIT>-<start>-<end>` pattern seen in ESP-AS-1833-2025 and ESP-CA-1833-2025, where SUBUNIT is a short abbreviation rather than the full département name.

## Open questions

### oq-gadm-france-not-fetched

**GADM 4.1 admin-1 has not been fetched for France; no polygon is attached**

The locally vendored `gadm-4.1-adm1` source is an 81-country curated subset that excludes France (0 FRA rows), so this entry has polygon_status: unassigned and no polygon_feature_id despite gadm-4.1-adm1 being the correct registered source type for a French département. Fetching the global GADM 4.1 admin-1 release (or a France-specific GADM download) and extracting the Ariège feature (GADM GID likely FRA.<n>_1, exact code unknown until fetched) would resolve this. Until then, any area or boundary computation for this entry is unavailable rather than approximate.

### oq-1790-1800-container-gap

**No FRA container row exists for 1790-1800, so this entry's true origin year is not represented**

Ariège has existed as a département since 4 March 1790, ten years before the earliest available FRA national container row (FRA-1800-1871). This entry's start_year was set to 1800 purely to satisfy the containment gate (see decision d-start-year-1800-not-1790), meaning any source data for Ariège between 1790 and 1800 (unlikely given the data span cited in the routing decision is 1862-2023, but not verified here) would currently have no valid container to route through on this row. If a FRA container row covering 1790-1800 is ever added to the table, this entry's start_year and its first container edge should be revisited.

### oq-frj21-source-detail-unverified

It is not verified whether FRJ21 unambiguously identifies Ariège versus some other GADM/administrative coding scheme, nor whether the 1862-2023 span reflects one continuous series or several disjoint ones.
