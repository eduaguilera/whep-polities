# Greece (1881–1913)

## Summary

This row tracks Greece for **32 years**, from the Convention of Constantinople
(2 July 1881, Thessaly and part of Epirus ceded by the Ottoman Empire) to the
Balkan Wars conclusion (Treaty of Bucharest, 10 August 1913)
[database](../../data/final/polities_database.csv).

Split from the former GRC-1830-1913 entry, which was superseded because the
1881 Thessaly cession constitutes a significant mid-span border change
(~28% area increase from ~47,000 km² to ~63,711 km²). Each period now has
its own polygon.

Predecessor: [grc-1830-1881](grc-1830-1881.md).
Successor: [grc-1913-1919](grc-1913-1919.md).

## Territorial extent

- **Polygon source.** CShapes 2.0, cowcode 350, feature year 1886 (63,711 km²).
  This polygon was always the correct fit for post-1881 Greece; the previous
  problem was it being applied to pre-1881 Greece as well.
- **Polygon vintage drift.** Row start is 1881; polygon vintage is 1886.
  Drift = 5 years — well within acceptable range. No significant border changes
  occurred between 1881 and 1886; this is documented here and treated as
  negligible. polygon_status=assigned.
- **No significant border changes 1881–1913.** The territory remained stable
  at ~63,711 km² from the Thessaly cession (1881) until the Balkan Wars (1913).
- **COW code 350** [database](../../data/final/polities_database.csv).

## Open questions

### oq-polygon-vintage-drift-1881-1886

The polygon (CShapes 1886, 63,711 km²) has a 5-year vintage drift from the row
start (1881). The key question is whether Greece had any border adjustments
between 1881 and 1886 that the polygon might not capture. Current evidence
suggests no significant changes occurred; drift is treated as negligible and
documented. If further evidence of 1881–1886 changes emerges, this should be
revisited.
