# Tarn (département)

## Summary

Tarn is a French département in the Occitanie region of southern France, with its préfecture at Albi. It is one of the roughly 83 original départements created by the Revolutionary administrative reform of 4 March 1790, carved out of the former province of Haut-Languedoc, and its boundaries have not been split, merged, or otherwise redrawn since. This entry is `type: subnational` because Tarn has never been a sovereign entity -- France held (and holds) sovereignty over it throughout -- and the row exists purely to carry a reporting territory that a Eurostat statistical geography (NUTS code FRJ27) tabulates separately from all-France national totals. The routing decision found zero existing name candidates and zero boundary matches for this unit in the polity table, and confirmed the FRA national rows (which contain it) are not equal to it in extent, which is the standard justification for creating a new subnational row rather than routing the data to the national chain.

**Why this entry exists.** The input data is a Eurostat NUTS3-keyed series for unit FRJ27 (Tarn), spanning 1862-2023, tied to country France. The routing decision does not give an exact row count in the reasoning text, but characterises it as a standard NUTS-level regional series entirely nested within the country-wide FRA container chain (FRA-1871-1919 and FRA-1919-2025), meaning no back-cast or territorial reconciliation was needed for the data itself -- French statistical territory has been continuously reported at this level. Before this entry, there was no polity row for Tarn at all: the routing search returned 0 name-candidate matches and 0 boundary matches, so the data would otherwise have had to be routed to a FRA national row, which is roughly 15-20x the area Tarn's figures actually describe (mainland France is about 543,000 km2 against Tarn's own ~5,758 km2). What confirms Tarn is a distinct, individually-tracked entity rather than an arbitrary statistical slice: it is a French département with its own INSEE code (81), its own préfecture and administrative apparatus, and is tabulated by Eurostat's NUTS3 geography (FRJ27) as a reporting unit in its own right, independent of whether any single historical trade-polity catalogue happens to list it separately.

**Territory description:** Tarn is a French département in the Occitanie region of southern France, roughly 80 km northeast of Toulouse, bordered by Aveyron, Hérault, Aude, Haute-Garonne, and Tarn-et-Garonne. Its préfecture is Albi (UNESCO World Heritage old town, on the Tarn river, which gives the département its name). Its modern administrative area is approximately **5,758 km2** -- a figure quoted from general reference knowledge of the current département, not measured from any attached polygon, since none is attached to this entry. A reader can locate it on a modern map as the department containing Albi and Castres, in the northern part of the Occitanie administrative region.

## Sourced claims

- Eurostat's NUTS3 geography assigns Tarn the code FRJ27, and statistical series keyed to that code (data spanning 1862-2023 per the routing decision) are published separately from all-France national aggregates, which is the direct evidence this reporting unit is tracked distinctly from the FRA national rows.
- Tarn was constituted as one of France's original Revolutionary départements by the administrative reform enacted 4 March 1790, and is not among the four documented departures from that default origin (the later-created Territoire de Belfort, the Alsace-Lorraine trio ceded/returned in 1871/1919, the 1975 Corse split, or the overseas départements created in 1946) -- meaning its boundaries have been continuously stable since creation rather than reorganized at any point.

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the routing decision's proposed 1790**

The routing decision proposed start_year 1790, reasoning that Tarn is an original Revolutionary département created 4 March 1790. That date is historically correct, but no FRA container row in the polity table covers 1790-1800: the earliest national row is FRA-1800-1871 (start_year 1800 per data/final/polities_database.csv), and there is no FRA-* row that starts earlier. The containment gate rejects an edge whose interval falls outside the container's own span, so a 1790-start edge against FRA-1800-1871 would fail. Rather than leave a decade uncontained, this page starts Tarn's own span at 1800 to match the earliest available container. The 1790-1800 gap for this and presumably every other French département is recorded as an open question below, since it looks like a table-wide gap rather than something specific to Tarn.

### d-subunit-code-81-not-nuts

**Subunit token is the INSEE department number (81), not the NUTS code FRJ27**

The routing decision's unit_id is the NUTS3 code FRJ27, which is a Eurostat statistical-region code, not how French départements are conventionally abbreviated. The dominant table pattern for subnational codes is <ISO3>-<SUBUNIT>-<start>-<end>, and for French départements the natural, stable, widely-recognised subunit token is the INSEE/postal department number -- 81 for Tarn -- rather than a NUTS revision-dependent code (NUTS codes have been renumbered across NUTS 2013/2016/2021 revisions, while INSEE department numbers have been stable since the 1800s). No existing FRA subnational code sets a precedent (0 rows), so this choice establishes one for future French département entries.

## Open questions

### oq-1790-1800-gap-table-wide

**Does the FRA container chain need an 1790-1800 edge, or an earlier FRA row entirely?**

The routing decision's own span_basis argues Tarn should start in 1790 (the Revolutionary département reform date), but the earliest FRA national row in data/final/polities_database.csv, FRA-1800-1871, itself starts at 1800, not 1790. That means either the FRA-1800-1871 row's start_year is understated by a decade (it should arguably be 1790, matching when the modern French département system, and by extension every original département including Tarn, actually came into being), or there is deliberately no French container prior to 1800 for some documented reason (e.g. data availability) that this page's author has not located. This is not specific to Tarn -- it would affect every one of the ~83 original-1790 French départements that eventually gets a row -- so it is worth resolving once at the FRA national level rather than per-department. Until resolved, this page starts at 1800 rather than 1790, which is a conservative but possibly incorrect simplification.

### oq-gadm-fra-fetch-needed

**GADM 4.1 ADM1 local file excludes France; polygon remains unassigned until re-fetched**

The registered source gadm-4.1-adm1 is the correct global source for French département boundaries (GID_1 values like FRA.30_1 would correspond to Tarn), but the local file at data/geodata/gadm-4.1/gadm41_adm1.gpkg is a curated 81-country subset that currently excludes France entirely (0 matching rows). Until that local extract is refreshed to include France, this entry has polygon_status: unassigned and no polygon_feature_id. When the fetch happens, someone needs to confirm which GID_1 value corresponds to Tarn (expected FRA.30_1 based on alphabetic GADM department ordering, but this must be verified against the actual attribute table rather than assumed) and confirm boundary stability back to 1800 given Tarn has not been split or merged since its 1790 creation.

### oq-data-span-vs-polity-span

**Underlying data for FRJ27 spans 1862-2023; does the polity span need to match that exactly?**

The routing decision states the NUTS unit FRJ27's data spans 1862-2023, entirely within the FRA-1871-1919/FRA-1919-2025 container chain (and, per the 1800-1871 edge added here, within FRA-1800-1871 too for any pre-1862 data that might surface later). This page sets end_year to 2025 (current, open-ended) rather than 2023, on the assumption Tarn continues to exist as a département today and 2023 is simply the data's last observed year rather than the territory's end. If a future ingest finds Tarn-specific data past 2023, or if French départements as an administrative tier are reformed (there has been recurring political discussion of merging or abolishing the département level), this end_year may need revisiting.
