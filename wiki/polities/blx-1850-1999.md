# Belgium-Luxembourg

## Summary

> **`polygon_status` migrated derived -> assigned (2026-07-29).** `derived` is a legacy value that predates the documented vocabulary in [wiki/README.md](../README.md#page-schema), which says not to use it in new pages. It was never migrated, so the manifest's `claims_polygon_status` set omitted it and consumers were told this row does not claim a polygon. The polygon is composed from its members by `scripts/sources/reporting-areas/build.py`, so it IS this row's territory by construction. See [lint-polygon-status-vocabulary](../log.md#lint-polygon-status-vocabulary).


WHEP aggregate reporting-area row for FAOSTAT/FABIO area code 15, Belgium-Luxembourg. This is not a country row; it is a data reporting unit used when source data combine Belgium and Luxembourg. The 1850-1999 range follows the current WHEP primary-production and land-footprint rows; detailed trade rows using the same reporting area are observed for 1986-1999.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** Belgium and Luxembourg current GADM 4.1 adm0 polygons.
- **Proxy note:** The polygon is a current-territory union for spatializing this aggregate reporting row; it does not imply a single sovereign polity.
