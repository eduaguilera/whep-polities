# Seine-Maritime (département)

## Summary

Seine-Maritime is a French département in Normandy, on the English Channel coast, containing the cities of Rouen (the préfecture) and Le Havre, at the mouth of the Seine. It is one of the original ~83 départements created by the March 1790 Revolutionary administrative reform that replaced the old provinces with a uniform grid of units, and it has kept its present boundary ever since — it is not one of the recognized departures from that default history (not carved out of Alsace-Lorraine, not split off like the Territoire de Belfort, not part of the 1975 Corse split, and not a post-1946 overseas département). It was created as Seine-Inférieure and renamed Seine-Maritime by decree in 1955, with no change to its boundary or INSEE code (76). This entry is `type: subnational` because Seine-Maritime is an ordinary administrative subdivision of France, not a sovereign state or a historical territory with an identity distinct from the modern département — it exists in this table only because a statistical source reports data for it specifically, at a finer grain than the national FRA rows carry. Before this entry, that data had no département-level home and would have had to be routed to whichever national FRA row spans the relevant year, an overstatement of roughly ninety-five other départements' worth of territory. No polygon is attached yet: the only source with the right administrative granularity for France (GADM 4.1 admin-1) is registered in this repository but its locally-present copy is an 81-country subset that excludes France, so `polygon_source` is `none` rather than a proxy.

**Why this entry exists.** Input data: per the routing decision, a source (implied to be mitchell-style départemental agricultural series, consistent with sibling entries such as fra-14) reports series for this département specifically, spanning 1862-2023 at 97.6% observed/blank, though an exact row count was not independently verified in this authoring pass and no data file was consulted directly — worth confirming before this entry leaves draft status. Previously, in the absence of any Seine-Maritime-level polity, this data had no natural home except one of the three national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year) — routing it there would attribute département-level series to the whole of metropolitan France, roughly a ninety-six-fold territorial overstatement, silently blending this département's numbers into a national aggregate no such row is entitled to claim they represent alone. What confirms Seine-Maritime is a distinct, real administrative entity rather than a source-labelling artifact: it is one of the ~83 original départements from the 1790 Revolutionary reform, it has its own INSEE code (76), its own préfecture (Rouen), and GADM 4.1 digitises it as a discrete admin-1 feature — this is not a case of a source inventing a unit with no corresponding real jurisdiction.

GADM 4.1 adm1 is the correct source for French départements at this administrative level and is registered in scripts/sources.yaml, but the copy present in this repository is a subset covering 81 countries that does not include France (0 FRA rows), so the route cannot execute yet. cshapes-2.0 and cshapes-europe, which supply the national FRA rows, only carry whole-country geometry and cannot be subdivided into départements. See open question oq-no-polygon-source-registered.

**Territory description:** Seine-Maritime occupies the Pays de Caux and the lower Seine valley in Normandy, on the English Channel. It is bordered by Somme and Oise to the northeast/east, Eure to the south, and Calvados across the Seine estuary to the southwest, with a coastline running from the Bresle estuary near Le Tréport down to the mouth of the Seine at Le Havre. Its administrative seat is Rouen; its other major city is the port of Le Havre. On a modern map it corresponds to INSEE département code 76. Its modern area is approximately **6,278 km²** (a figure quoted from published French administrative statistics for the present-day département, not measured from any polygon attached to this entry, since none is attached).

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the département's 1790 creation date**

The routing decision proposed start_year 1790, citing the March 1790 Revolutionary reform that created Seine-Inférieure (renamed Seine-Maritime in 1955) along with the ~83 original départements. That is correct administrative history, but it is not usable here: the FRA container chain in the polity table begins at FRA-1800-1871, and there is no France row covering 1790-1800 to container against. The containment gate rejects any edge falling outside both parties' spans, so an 1790 start with no container for the first decade would fail immediately. This entry instead starts at 1800, matching the earliest available container, and the 1790-1800 gap is left open below, exactly as decided for the sibling entry fra-14-1800-2025 (Calvados). The data this entry actually receives (per the routing decision, 1862-2023) is unaffected either way, since it falls entirely inside 1800-2025. This departs from the routing decision's proposed container list, which named only FRA-1919-2025 and left 1800-1919 uncontained; three edges are used here so the edges tile the full 1800-2025 span with no gap, as the containment gate requires.

### d-subunit-code-is-insee-number

**Subunit code '76' follows INSEE numbering, matching the dominant ISO3-SUBUNIT pattern**

French départements are conventionally identified by their INSEE two-digit code rather than a postal or historical abbreviation. Seine-Maritime's INSEE code is 76 (unchanged across the 1955 rename from Seine-Inférieure). This keeps the code in the dominant <ISO3>-<SUBUNIT>-<start>-<end> family (57 of 66 subnational rows) rather than treating it as a bespoke historical territory: despite the name change, this is an ordinary administrative unit whose boundary has not moved, with no identity distinct from the modern département, so a bespoke code (like ALK or HYD) is not warranted.

### d-name-uses-modern-1955-label

**polity_name uses the modern label 'Seine-Maritime', not the 1800-1955 name 'Seine-Inférieure'**

For most of this entry's span (1800-1955) the département was legally named Seine-Inférieure; it was renamed Seine-Maritime in 1955 by decree, with no change to its boundary or INSEE code. The modern name is used as the polity_name for consistency with how the table names other long-lived subnational units by their current label (e.g. Calvados, which was never renamed), and because 'Seine-Maritime' is what a present-day reader will recognize on a map. The pre-1955 name is recorded in Sourced claims and flagged as an open question for anyone matching source labels that use 'Seine-Inférieure' directly.

## Open questions

### oq-1790-1800-gap-uncontained

**1790-1800 creation decade has no France container row to attach to**

Seine-Inférieure (now Seine-Maritime) existed as a département from March 1790, a full decade before this entry's start_year of 1800. The FRA container chain in the polity table begins at FRA-1800-1871 (cshapes-europe, first vintage 1816), so there is currently no polity row representing France 1790-1800 for this or any other French département to container against. If a pre-1800 France row is ever added to the table, this entry's start_year should be reconsidered and moved back to 1790, consistent with actual creation date and the routing decision's original span_basis reasoning. This is the same open question already recorded on the sibling entry fra-14-1800-2025 (Calvados); it will need resolving once, not once per département.

### oq-no-polygon-source-registered

**No registered, locally-present source can supply a Seine-Maritime boundary today**

The routing decision's polygon_reasoning found that gadm-4.1-adm1, the only registered source with département-level granularity for France, is present locally only as an 81-country subset that excludes France entirely (0 rows for FRA globally, per the routing decision). cshapes-2.0 and cshapes-europe, the sources used for the national FRA rows, only carry whole-country geometry, not sub-national units. No union/difference of currently registered, locally-present features can construct this département's boundary. A real boundary certainly exists (GADM 4.1's full/global adm1 layer, at GID_1 level, e.g. FRA.68_1 in the routing decision's own notes on a different département, or IGN's ADMIN-EXPRESS/GEOFLA product for France specifically) but is not registered in scripts/sources.yaml today, so polygon_source is 'none' and polygon_status is 'unassigned' rather than a proxy or estimate. Revisit once gadm-4.1-adm1 is re-sourced as its full global layer, or an IGN product is registered.

### oq-pre-1955-label-mismatch-in-sources

This entry uses the modern name 'Seine-Maritime', but the département was legally 'Seine-Inférieure' until the 1955 rename. This has not been checked against the actual row labels in this authoring pass; it should be verified before this entry leaves draft status, since a silent label split would understate this département's true row count.

### oq-boundary-stability-unverified

**Seine-Maritime's boundary stability across 1800-2025 has not been corroborated against a second source**

This page asserts the département has retained its present-day boundary since the 1790 creation (aside from the 1955 name change), based on the routing decision's general claim of stability for original départements not among the four enumerated departure cases. That claim has not been cross-checked here against an independent French administrative-history source (e.g. INSEE's historical arrondissement/canton records, or IGN's boundary-change documentation) to confirm no 19th- or 20th-century canton transfer to or from a neighbouring département (Eure, Somme, Oise, Calvados).
