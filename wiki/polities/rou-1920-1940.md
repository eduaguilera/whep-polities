# Romania (1920-1940)


> **Polygon corrected 2026-08-05: Bessarabia was missing for all twenty interwar years.**
>
> `polygon_feature_year` was `1920`, and **two** CShapes steps for gwcode 360 contain 1920 while
> **both start in it** — `1920-1920` at 251,719 km² and `1920-1940` at 296,087 km². The tie-break
> could not choose, so shapefile row order did, and it took the smaller. Measured consequence:
>
> ```
> attached      251,742 km²      Chisinau (Bessarabia) inside: False
> the step this page asks for   296,087 km²      Cluj (Transylvania)  inside: True
> missing        44,384 km²   =  15.0%
> ```
>
> This page's own Territorial extent section says "~295,000 km². Greatest territorial extent of
> Romania", so the intent was never in doubt — only the year expressing it.
> `polygon_feature_year: 1921` falls inside exactly one candidate span, which makes the binding
> both correct and deterministic.
>
> It carries **1,087** observed rows, against 39 on the sibling `ROU-1918-1919` that was corrected
> on 2026-08-05 in the same family. **The sibling was fixed first only because it happened to
> declare a `polygon_area_km2`** — this row declared none, so the area check never looked at it
> (issue 59). An area is now recorded.
>
> **Still open in this family:** `ROU-1919-1920` measures 141,305 km² and is order-dependent the
> same way (steps `1919-1919` = 141,247 and `1919-1920` = 148,934 both start in 1919). Whether
> 1919 should carry the assembling Greater Romania (~295,000, as `ROU-1918-1919` does on data
> evidence) or the smaller pre-treaty extent is a judgement about when de facto union became the
> reporting basis, so it is left rather than guessed.
## Summary

This row tracks Romania for **21 years**, Greater Romania at maximum
extent [database](../../data/final/polities_database.csv).

Greater Romania ~295,000 km². Lost territory in 1940 via three
simultaneous events: Second Vienna Award (northern Transylvania to
Hungary), Soviet ultimatum (Bessarabia and Northern Bukovina to USSR),
Treaty of Craiova (Southern Dobruja to Bulgaria).

Predecessor: [rou-1919-1920](rou-1919-1920.md) -- border settlement.
Successor: [rou-1940-2025](rou-1940-2025.md) -- reduced Romania.

## Sourced claims

- **1920-06-04: Treaty of Trianon.** Formalized Transylvania and Banat
  as Romanian territory. This is the start-of-row event.
  [database](../../data/final/polities_database.csv)
- **1940-06-26: Soviet ultimatum.** USSR demanded and received
  Bessarabia and Northern Bukovina (~50,000 km²).
  [database](../../data/final/polities_database.csv)
- **1940-08-30: Second Vienna Award.** Northern Transylvania returned to
  Hungary (~43,000 km²).
  [database](../../data/final/polities_database.csv)
- **1940-09-07: Treaty of Craiova.** Southern Dobruja returned to
  Bulgaria (~7,700 km²). This is the end-of-row event (last of the
  three 1940 losses).
  [database](../../data/final/polities_database.csv)
