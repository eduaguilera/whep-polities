# Côtes-d'Armor

## Summary

Côtes-d'Armor (known as Côtes-du-Nord until a 1990 renaming) is a French département on the northern coast of Brittany, facing the English Channel, with its préfecture at Saint-Brieuc. It is one of the roughly 83 départements created by the Revolutionary reform of 4 March 1790, replacing the ancien régime province of Brittany's territorial subdivisions with a rationalized administrative grid. This entry is `type: subnational` because a département is a sub-unit of the French state, not a sovereign polity in its own right; France held continuous sovereignty over this territory across the full 1800-2025 span, and the entry exists purely to carry a reporting-territory level (NUTS3-coded statistical series) that the national FRA rows are too coarse to represent. The department's boundary has been stable since creation — it was never touched by the Alsace-Lorraine annexation/return, the 1922 Belfort split, the 1975 Corsican split, or the 1946 overseas départements law, all of which are documented departures for other French départements in this same convention.

**Why this entry exists.** This entry captures a NUTS-coded French département-level panel (unit id FRA-FRH01, admin_name FRH01) for Côtes-d'Armor, matched by the agent-harness routing pipeline against the France country convention (pipelines/agent-harness/state/country_conventions.json, 'France' entry). Before this entry, data tagged to this NUTS unit had no département-level home: the only candidates in the polity table were the three national France rows (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025), all roughly 20x too coarse for a single département's series and would have collapsed sub-national variation into the national total. A département is not itself France, so `match_existing` against a national row was ruled out by the routing logic. What confirms this is a distinct, independently-tracked reporting unit rather than an arbitrary statistical slice is the NUTS classification itself (FR code FRH01) plus INSEE's own use of the numeric code 22 for this département in all French administrative statistics since the Revolutionary reform — Côtes-d'Armor is tracked as its own unit by the French statistical apparatus, not an ad hoc aggregation.

**Territory description:** Côtes-d'Armor occupies the north-central coast of Brittany, in the historical region of Trégor and northern Cornouaille, bordered by the English Channel to the north, Finistère to the west, Morbihan to the south, and Ille-et-Vilaine to the east. Its préfecture, Saint-Brieuc, sits roughly midway along the coast between Saint-Malo and Brest. The département's modern extent is approximately 6,878 km2 — this is the widely-published INSEE/IGN figure for the current administrative boundary, not a measurement of any polygon attached to this entry, since none is attached yet. The boundary has been essentially unchanged since the 1790 creation of Côtes-du-Nord, so a present-day GADM ADM1 feature, once fetched, would be a faithful, non-proxy match for the department's full historical span rather than an approximation requiring a caveat.

It has not been split, merged, or renamed in a way that changes its territory since — the 1990 renaming from Côtes-du-Nord to Côtes-d'Armor was cosmetic — so there is no successor either; the span simply runs to the open end year shared by every current French département in this convention.

## Decisions

### d-container-floor-clamps-start

**start_year clamped to 1800, not the department's 1790 founding, because no container tiles 1790-1800**

The routing decision proposed start_year 1790, correctly citing Côtes-d'Armor's actual founding as one of the original Revolutionary départements. But the polity table's earliest France row is FRA-1800-1871 — there is no national FRA container row covering 1790-1800, and the containment gate rejects an edge whose start falls outside the container's own span. Rather than leave a 10-year gap uncontained (which would fail the tiling requirement), this entry's start_year is clamped to 1800, the floor of the earliest available container. This is a data-coverage limitation of the polity table, not a claim that Côtes-d'Armor did not exist 1790-1800 — the summary and predecessor discussion both state the true 1790 founding date. If a future PR extends the France national chain backward past 1800, this entry's start_year should be revisited alongside it.

### d-code-uses-insee-number-not-nuts

**Subunit code uses the INSEE department number (22), not the NUTS code (FRH01) or an invented abbreviation**

France has no existing subnational polity rows, so this entry sets precedent rather than following one. Rather than embed the NUTS3 code (FRH01) — which is an EU statistical classification introduced in the 1970s and unrelated to the département's own 1790 identity — or invent a two-or-three-letter abbreviation with no external authority, this entry uses INSEE's official numeric département code (22), which has denoted Côtes-d'Armor/Côtes-du-Nord in French civil administration since the Revolutionary numbering scheme and will be recognizable to any French-administrative-history source used to route future départements.

## Open questions

**Polygon requires fetching the global GADM 4.1 ADM1 layer, not yet done**

This entry has no polygon because the on-disk `gadm-4.1-adm1.gpkg` is an 81-country subset that excludes France entirely (0 features for any FRA GID_1 code). The registered source's schema is already correct (GID_1 = FRA.6_1 for Côtes-d'Armor), so this should be a straightforward re-fetch of the global GADM ADM1 download rather than a new source registration — but until that fetch happens, this and every other future French département entry will hit the same gap. Whoever picks this up should check whether the harness's sources.yaml can point at a global file without breaking the existing 81-country curation for other countries, or whether France needs its own supplementary file.
