## Open questions

### oq-cow-750-shared

COW code 750 is assigned to both the early Indonesia rows
(IDN-1800-1889, IDN-1889-1945) and all India rows. This is
almost certainly a CSV error. Independent Indonesia uses cow=850
(COW code for Indonesia). The early colonial rows likely inherited
the wrong code.
