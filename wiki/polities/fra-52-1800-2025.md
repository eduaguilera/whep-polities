# Haute-Marne (département)

## Summary

Haute-Marne is a French département in the Grand Est region (historically Champagne-Ardenne), in the historic provinces of Champagne and Bassigny, with its préfecture at Chaumont. It is one of the roughly 83 original départements created by the 4 March 1790 Revolutionary administrative reform that replaced the old provinces with a uniform grid of units, and it is not one of the four recognized departures from that default history that this pipeline tracks for French subnational units (it was not carved from Alsace-Lorraine, not split off like the Territoire de Belfort, not part of the 1975 Corse split, and not a post-1946 overseas département), so it has kept its present administrative form continuously since creation. This entry is `type: subnational` rather than `national` because Haute-Marne is an ordinary administrative subdivision of the sovereign state of France, not a state in its own right and not a historical territory with an identity distinct from the modern département -- the same reasoning already applied to sibling entries such as Aisne, Calvados, and the other départements created in this pipeline run. It exists as a row in this table only because a statistical source (mitchell) reports production/agricultural data for Haute-Marne specifically, at a finer grain than any national FRA row carries; before this entry, that data had no département-level home and would have had to be routed to whichever national FRA row spans the relevant year -- a roughly ninety-fivefold territorial overstatement relative to Haute-Marne's actual extent, since metropolitan France has around 95-96 départements.

**Why this entry exists.** Input data: mitchell reports a production/agricultural series labelled specifically for Haute-Marne, per the routing decision, beginning in 1862 and falling entirely inside this entry's 1800-2025 span (row count not independently re-verified in this authoring pass -- flagged in sourced_claims and oq-row-count-not-reverified). Previously, in the absence of any Haute-Marne-level polity, this data had no natural home except one of the national France rows (FRA-1800-1871, FRA-1871-1919, or FRA-1919-2025 depending on year), which would have meant attributing département-scale series to the whole of metropolitan France, overstating the geographic scope roughly ninety-five-fold. What confirms Haute-Marne is a distinct, real administrative entity rather than an artifact of the source's labelling: it is one of the original 1790 départements, it carries its own INSEE code (52) and préfecture (Chaumont), and GADM 4.1's global admin-1 layer digitises it as a discrete feature -- this is not a source inventing a unit with no corresponding jurisdiction.

**Territory description:** Haute-Marne is a landlocked, largely rural département in the Grand Est region, in the historic provinces of Champagne and Bassigny, on the western edge of the Langres plateau. It borders the départements of Aube, Marne, Meuse, Vosges, Haute-Saône and Côte-d'Or, and its administrative seat (préfecture) is Chaumont, with Langres and Saint-Dizier as other significant towns. It is the source of the Marne river, which rises near Langres, and it is one of the more sparsely populated and forested départements of metropolitan France. On a modern map it corresponds to INSEE département code 52. Its modern area is approximately **6,211 km²** (a figure quoted from published French administrative statistics for the present-day département, not measured from any polygon attached to this entry, since none is attached -- consistent with the general pattern that 1790-era départements were drawn to a broadly similar size, crossable on horseback in a day from any point to the seat).

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the département's 1790 creation date, per the container floor**

The routing decision proposed start_year 1790, citing the 4 March 1790 Revolutionary reform that created Haute-Marne (from parts of the former provinces of Champagne and Bassigny, with Chaumont as préfecture) along with the ~83 original départements. That administrative date is correct, but it is not usable here: the FRA container chain in the polity table begins at FRA-1800-1871 (cshapes-europe, first vintage 1816), and there is no France row covering 1790-1800 for this entry to container against. The containment gate rejects any edge that falls outside either party's span, so a 1790 start with no container for the first decade would fail immediately -- this is the container-floor rule the harness now enforces (commit 11e8ca1). Rather than leave a gap or invent a France row this pipeline wasn't asked to create, this entry starts at 1800, matching the earliest available container, and the 1790-1800 gap is left open below, exactly as done for the sibling entries FRA-02, FRA-14, FRA-18, FRA-21, FRA-25 and the other 1800-2025 département rows created in this pipeline run.

### d-subunit-code-is-insee-number

**Subunit code '52' follows INSEE numbering, matching the dominant ISO3-SUBUNIT pattern and the sibling département entries**

French départements are conventionally identified by their INSEE two-digit code rather than a postal or historical abbreviation. Haute-Marne's INSEE code is 52. This keeps the code in the dominant <ISO3>-<SUBUNIT>-<start>-<end> family (57 of 66 subnational rows, and the established convention for every French département entry created in this pipeline run: 02, 14, 18, 21, 25, 27, 28, 36, 37, 39, 41, 50, 58, 59, 60, 61, 62, 70, 71, 76, 77, 80, 89, and so on) rather than treating Haute-Marne as a bespoke historical territory. Haute-Marne has no name-of-its-own distinct from the modern département and is not one of the four listed departures from the default département history (not Belfort, not an Alsace-Lorraine département, not the Corsican split, not a post-1946 overseas département), so bespoke-code treatment (like ALK or HYD) would be unwarranted, matching the routing decision's own reasoning.
