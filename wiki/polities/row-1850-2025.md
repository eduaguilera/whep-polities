# Rest of World


> **End year moved 2023 -> 2025 on 2026-08-05 (issue 50), replacing `ROW-1850-2023`.**
>
> This is a statistical reporting bucket, not a historical state. Its previous end
> year was an artefact of when the row was written, not a fact about any territory:
> FAOSTAT still reports this area through **2024**, so the bucket stopped before the
> data did and its most recent years resolved to `NA`.
>
> `end_year` is EXCLUSIVE, so `2025` covers through 2024. 220 live rows already
> end at 2025, which is the convention for a row covering the present.
>
> The polygon is unchanged: `scripts/sources/reporting-areas/build.py` keys its
> features by `polity_code`, so the source was regenerated with the new code rather
> than the binding being left to dangle.
## Summary

> **`polygon_status` migrated derived -> assigned (2026-07-29).** `derived` is a legacy value that predates the documented vocabulary in [wiki/README.md](../README.md#page-schema), which says not to use it in new pages. It was never migrated, so the manifest's `claims_polygon_status` set omitted it and consumers were told this row does not claim a polygon. The polygon is composed from its members by `scripts/sources/reporting-areas/build.py`, so it IS this row's territory by construction. See [lint-polygon-status-vocabulary](../log.md#lint-polygon-status-vocabulary).


WHEP aggregate reporting-area row for residual Rest of World data. This row exists so data reported against area code 999 has a first-class polity-database entry and polygon. The 1850-2025 range follows (it was 1850-2023 until issue 50; see the note above) the current WHEP primary-production rows; CBS rows are observed for 1961-2023 and detailed-trade rows for 1986-2021.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** Union of the WHEP aggregate reporting-area polygons BLX, ANT, RAFR, RASI, REUR, RLAM, RNAM, and ROCE.
- **Proxy note:** This is a residual reporting-area polygon. It is not a global land mask and should be interpreted in the context of the source dataset that reports RoW.

## Decision: the components are a FIXED list, and the overlap is intended

**Decided 2026-08-17 (issue 48).** Issue 48 asked whether a regional "Other" bucket is a
*fixed list* of territories or a *residual* that shrinks as territories acquire data of
their own — because eleven areas reattributed out of this fold in issue 39 are still inside
this polygon.

It is a **fixed list**, and the authority is not this repository. The `polity_code` column
of `inst/extdata/harmonization/regions_full.csv` in
[eduaguilera/whep](https://github.com/eduaguilera/whep) is what folds CBS and FABIO data
into these buckets, and it still assigns every one of the eleven to a bucket: Faroe Islands
to `REUR`; Cook Islands, Niue, Northern Marianas and Palau to `ROCE`; Bermuda, Guadeloupe
and Martinique to `RLAM`; Réunion to `RAFR`. A polity row exists *in parallel* for those
territories because FAOSTAT reports them individually — two reporting systems over one
piece of ground, not a residual that shrank. Dropping them from the unions here would leave
this polygon describing less ground than the data routed into it, which is the worse error.

**Consumers must therefore not spatially allocate aggregate data without first
deduplicating against the own-data rows.** Doing so double-counts the overlap.

Measured 2026-08-17 against `data/final/polities_database.gpkg` and
`data/geodata/reporting-areas/reporting_areas.gpkg` (cylindrical equal-area, `lat_ts=30`;
areas therefore differ slightly from GADM's own figures):

| polity row inside ROW | own km² | inside ROW | % |
|---|---|---|---|
| `FRO-1800-2025` | 1,439 | 1,431 | 99.4 |
| `MHL-1874-2025` | 300 | 299 | 99.5 |
| `MNP-1986-2025` | 503 | 499 | 99.1 |
| `COK-1800-2025` | 280 | 275 | 98.5 |
| `FSM-1991-2025` | 763 | 751 | 98.4 |
| `PLW-1991-2025` | 481 | 473 | 98.4 |
| `BMU-1684-1968`, `BMU-1968-2025` | 68 each | 66 each | 97.3 |
| `NIU-1800-2025` | 264 | 257 | 97.1 |
| `GLP-1816-2025` | 1,650 | 1,539 | 93.2 |
| `REU-1816-1946`, `REU-1946-2025` | 2,623 each | 2,434 each | 92.8 |
| `MTQ-1816-2025` | 1,127 | 1,018 | 90.3 |

**Thirteen polity rows overlap, not the eight the issue lists**, and the union of the
overlap is **9,040 km²** of this polygon's **2,571,894 km²** (0.35%), against the issue's
7,319 km² of 2,569,652. The issue counted only live rows among its own eleven
reattributions; the extra five are `FSM-1991-2025`, `MHL-1874-2025` and `MNP-1986-2025`
— members of `RASI`/`ROCE` that were never part of that batch — plus the historical
predecessors `BMU-1684-1968` and `REU-1816-1946`, which share their successor's polygon.
The three the issue correctly excluded (Palestine, Equatorial Guinea, French Guiana) still
measure 0 km² inside the union. The overlap being 24% larger than reported does not change
the decision; it is reported here because it is what the current data says.

No geometry changed as a result of this decision. `RASI`'s components *did* change on the
same day for a different reason — two aggregates claiming the same islands, see
[rasi-1850-2025](rasi-1850-2025.md) — and that left this union untouched, because the
islands still enter it through `ROCE`.
