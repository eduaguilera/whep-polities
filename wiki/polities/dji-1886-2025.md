# RETIRED — DJI-1886-2025

This polity row has been retired as a duplicate of the FRS chain for Djibouti territory.

**Redirect:** Use [FRS-1884-1977](frs-1884-1977.md) for colonial-era data (1884–1977) and [FRS-1977-2025](frs-1977-2025.md) for independent Djibouti (1977–2025).

**Reason for retirement:** DJI-1886-2025 overlapped entirely with the existing FRS-1884-1977 / FRS-1977-2025 chain. CShapes feature 522 (the polygon) has been reassigned to FRS-1884-1977. The cow_code=522 on this row was correct for Djibouti but was assigned to the wrong chain entry; it is now carried by FRS-1884-1977 (colonial) and FRS-1977-2025 (independent). The CSV row for DJI-1886-2025 has been deleted; the alias `djibouti -> FRS-1884-1977` (1884–1977) routes any IIA colonial-era label matches to the correct polity.

**Consolidation date:** 2026-07-01

## Polygon status consolidated (added 2026-07-28)

This page carried no `polygon_status` at all — it was the single NaN in the
field, and a row with no value is invisible to every polygon check by default.
It is now **`unassigned`**, with `polygon_source: none`, in the polygon_status
vocabulary consolidation
([log lint-consolidate-polygon-status](../log.md#lint-consolidate-polygon-status)).

`unassigned` is the correct value rather than an oversight to be filled with a
polygon: CShapes feature 522 — the Djibouti polygon this row once carried — was
deliberately reassigned to [FRS-1884-1977](frs-1884-1977.md) when the duplicate
chain was retired on 2026-07-01, and confirmed against
`data/final/polities_database.gpkg`, no geometry is attached here. A retired row
must not claim the polygon its replacement holds, or the same territory would be
counted twice on the map. Use the FRS chain for Djibouti geometry.
