# Eure-et-Loir

## Summary

Eure-et-Loir is a French département in the Centre-Val de Loire region, roughly 90 km southwest of Paris, in the historic Beauce grain-growing plain and centred on the cathedral town of Chartres. It is coded `subnational` because a département is an administrative subdivision of France, not a sovereign or internationally distinct territory: French sovereignty over this area is continuous and undisputed across the whole entry span, and that sovereignty claim is already carried by the national FRA rows in this table (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025). This entry exists purely to give a home to sub-national reporting-territory data -- statistics keyed to "Eure-et-Loir" or its Eurostat NUTS3 code FRB02 -- which cannot correctly be routed to a national French row roughly fifteen times its size. The entry follows the country's default start rule for an original Revolutionary département (1790), adjusted to 1800 to match the earliest available FRA container row (see decisions), and runs to the open end_year 2025 since the département remains an active, unaltered administrative unit of France today with no predecessor or successor.

**Why this entry exists.** This entry captures juan-subnational source data for unit FRA-FRB02 (Eure-et-Loir, NUTS3 code FRB02, INSEE department code 28), spanning the department's full reported history with the routing evidence citing 97.6% observed (non-back-cast) coverage. Prior to this decision, the underlying rows had no polity to route to at all -- the routing pipeline's match_existing search returned zero name candidates and zero boundary matches against the existing FRA table, because the only FRA rows present are the three national chain entries (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025), each of which represents the whole country rather than any single département, so matching this sub-national series to any of them would have silently conflated department-level statistics with all-France totals roughly fifteen times larger. What confirms Eure-et-Loir as a distinct, separately-tabulated entity rather than an arbitrary subdivision invented for this pipeline is that it is one of the original ~83 départements created by the 1790 Revolutionary administrative reform and has been continuously enumerated under INSEE numeric code 28 in French national statistics, while independently carrying Eurostat NUTS3 code FRB02 in EU regional statistics -- the same dual-apparatus evidence already used to justify sibling entries FRA-18 (Cher), FRA-77 and FRA-91.

A reader can locate it on a modern map as the department immediately southwest of Paris along the A11 motorway corridor toward Le Mans. Eure-et-Loir has no predecessor or successor polity in this database: it is one of the original ~83 départements created by the 1790 Revolutionary reform, assembled from parts of the former provinces of Orléanais, Île-de-France, Perche and Maine, and it has never been abolished, split, or merged into another unit. Its administrative boundaries and its INSEE numeric code (28) have remained stable since creation. It sits alongside sibling entries FRA-18-1800-2025 (Cher), FRA-77-1800-2025 and FRA-91-1968-2025 as another French département given its own row for the same reason: reporting-territory data keyed to the département, not the nation, needs a home that isn't the FRA national chain.

## Decisions

### d-start-year-1800-not-1790

**Start year set to 1800, not the 1790 creation date, to match the earliest FRA container row**

The country convention's default start rule for an original Revolutionary département is 1790, the year Eure-et-Loir was carved from parts of the former provinces of Orléanais, Île-de-France and Perche. But the earliest national FRA row in this database, FRA-1800-1871, begins at 1800, and the containment gate rejects an edge that starts before its container's own span begins. Rather than leave 1790-1800 uncontained, this entry's start_year is set to 1800 to match the available container, following the same adjustment already made for the sibling entries FRA-18-1800-2025 (Cher), FRA-77-1800-2025 and FRA-91-1968-2025. The polity_code years (1800-2025) equal the frontmatter years as the gate requires.

### d-numeric-code-28-not-fra-frb02

**Code uses the INSEE numeric département code (28), not the routing unit_id FRA-FRB02**

The routing decision names the unit FRA-FRB02 using its Eurostat NUTS3 code, but the dominant pattern for FRA subnational rows already in this table (FRA-18, FRA-77, FRA-91) keys on the INSEE numeric département code rather than the NUTS3 identifier, because INSEE's own code is the one under which French statistical series have been tabulated since the department's creation and is more legible to a reader than a Eurostat identifier. Eure-et-Loir's INSEE code is 28, giving FRA-28-1800-2025. This keeps the new entry consistent with its siblings rather than introducing a second FRA subnational naming scheme.

### d-polygon-left-unassigned

**Polygon left unassigned rather than constructed from an unregistered source**

The routing decision's polygon_route is new_source_needed: GADM 4.1's global ADM1 release covers French départements at the right admin level, but the locally registered gadm-4.1-adm1 source is a curated 81-country subset that excludes France entirely, and no other registered source (cshapes-2.0, cshapes-europe) carries subnational French boundaries. Rather than fabricate a polygon reference to a source not present on disk, this entry ships with polygon_source: none and polygon_status: unassigned, matching the identical situation already recorded on FRA-18, FRA-77 and FRA-91. Fetching and registering the GADM 4.1 global ADM1 release (or an IGN ADMIN-EXPRESS historical département layer) is future work, not something this page can resolve.

## Open questions

### oq-department-boundary-stability-1790-1800

**Whether Eure-et-Loir's boundary changed between its 1790 creation and this entry's 1800 start**

This entry starts at 1800 to match the earliest available FRA national container row, ten years after the département's actual 1790 creation. It is not yet confirmed whether any commune-level boundary adjustments occurred between 1790 and 1800 that would make a future polygon dated to 1800 differ from one dated to the creation year. Most French département boundaries stabilised quickly after 1790, but this should be checked once a source polygon is actually registered, rather than assumed.

### oq-gadm-global-adm1-not-registered

**No registered polygon source exists for any French département, including this one**

The polygon_route new_source_needed applies identically to every FRA subnational entry created so far (FRA-18, FRA-77, FRA-91, and now this one): GADM 4.1's global ADM1 release has the right schema and admin level but the locally present gadm-4.1-adm1 file is an 81-country subset that omits France. Until that global release (or an equivalent IGN historical département layer) is fetched and registered, none of these entries can move past polygon_status: unassigned. This is a repository-wide gap rather than something specific to Eure-et-Loir, and resolving it once would unblock all four entries plus any further French départements added later.

### oq-juan-subnational-coverage-gaps

**Extent of temporal coverage gaps in the juan-subnational source for this unit**

The routing evidence states the underlying data for FRA-FRB02 is 97.6% observed, implying a small share of years are back-cast or otherwise imputed rather than directly reported. Which years those are, and whether they cluster around either world war or another administrative disruption, has not been checked against the source file and would matter for anyone treating this entry's series as a continuous observed record.
