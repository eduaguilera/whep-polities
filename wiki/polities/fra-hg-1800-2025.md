# Haute-Garonne

## Summary

Haute-Garonne is a French département in the southwest of the country, in the historic region straddling Languedoc and Gascony, with its préfecture at Toulouse. It was created on 4 March 1790 during the Revolutionary reorganization of France's territory into 83 départements, replacing the patchwork of pre-Revolutionary provinces with units of roughly equal size designed for uniform administration. Unlike Alsace-Lorraine départements (ceded 1871-1919, motivating the parallel FRA-1800-1871/FRA-1871-1919/FRA-1919-2025 national rows already in the table), Belfort (split off in 1871-1922), Corsica (split into two départements in 1975), or the overseas départements (created 1946), Haute-Garonne is not one of the country convention's enumerated departures from the default span rule -- it has kept the same name, the same approximate boundary, and metropolitan (not overseas) status continuously since creation. This entry is `type: subnational` because it is a French sub-national administrative unit (NUTS3 / département), not a sovereign state in its own right; France's sovereignty and national-level statistical totals are already carried by the existing FRA-1800-1871/FRA-1800-1919/FRA-1871-1919/FRA-1919-2025 rows. This is the first subnational row created for FRA in this table -- there is no existing precedent among FRA's children to follow or depart from, so the dominant cross-country pattern <ISO3>-<SUBUNIT>-<start>-<end> (57 of 66 subnational rows in the table) is used directly.

**Why this entry exists.** This entry captures a single routed input unit, `FRA-FRJ23` (admin_name FRJ23, NUTS3 code for Haute-Garonne), from the France country-convention routing pass in pipelines/agent-harness. No row count or specific dataset years were supplied in the routing decision itself -- the decision is a structural/administrative routing (the unit exists in a subnational reference geography, e.g. Eurostat NUTS or an INSEE gazetteer, rather than being tied to a specific value-bearing dataset in this pass) rather than a data-driven match. Before this entry, FRA had zero subnational polity rows in the table (stated explicitly in the routing decision: "the three FRA polities are national totals"), so any data or reference keyed to Haute-Garonne or its NUTS3/département code had no home except the national FRA rows -- which the routing rule explicitly forbids, since a subnational unit cannot match_existing against a national row it merely sits inside (the national row is ~552,000 km2 nationwide vs. this département's roughly 6,300 km2). What confirms Haute-Garonne is a distinct, individually-administered entity rather than an arbitrary statistical grouping is that it is a first-order French administrative division (département) with its own prefect, its own INSEE code (31) and its own NUTS3 code (FRJ23), continuously gazetted since 1790 -- the same administrative status held by the other 100 metropolitan and overseas French départements, any of which could equally generate a sibling row in the future.

**Territory description:** Haute-Garonne is a département in southwestern France, part of the Occitanie region, bordering Spain (Aran Valley/Val d'Aran, Catalonia) to the south along the Pyrenees. Its préfecture is Toulouse, France's fourth-largest city. On a modern map it sits between the départements of Ariège (south), Aude and Tarn (east), Tarn-et-Garonne (north), and Gers and Hautes-Pyrénées (west). Its present-day area is approximately **6,309 km²**, per INSEE's current gazetteer figure for département 31 -- this is stated territory-description evidence, not a measurement of any attached geometry (none is attached yet, per the polygon status above). The département's outline has been essentially stable since its 1790 creation; the main structural caveat is the general possibility of small commune-level reassignments to or from neighbouring départements over 235 years, which have not been individually checked for Haute-Garonne (see open questions).

## Predecessors and successors

Haute-Garonne has no predecessor or successor polity row: it was created directly in 1790 out of parts of the pre-Revolutionary provinces of Languedoc and Gascony (with the addition of the Comminges and Nébouzan territories), not by splitting off from a different modern polity already in this table, and it has remained a continuous administrative unit ever since with no split or merger that would produce a successor. The only structural relationship it has is upward, into the national FRA container chain (FRA-1800-1919, then FRA-1919-2025), reflected in the `container` edges rather than in predecessor/successor fields.

## Sourced claims

- Haute-Garonne was created on 4 March 1790 as one of the original 83 départements of Revolutionary France, formed from portions of the former provinces of Languedoc, Gascony, Comminges, and Nébouzan -- a boundary decision documented in the decree establishing the French départemental system.
- INSEE (the French national statistics institute) and Eurostat both currently classify Haute-Garonne as NUTS3 code FRJ23, nested under the Occitanie region (NUTS2 FRJ2), which is the administrative unit this polity row is intended to match against for any subnational French statistical series keyed to that code.

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the routing decision's proposed 1790**

The routing decision proposed start_year 1790, since Haute-Garonne was created as one of the original Revolutionary départements in that year. However the earliest FRA container row in the polity table is FRA-1800-1919 (1800-1919) -- there is no FRA row covering 1790-1800, and the containment gate rejects any edge falling outside the container's own span. Rather than leave a 10-year gap uncontained, this page starts the polity at 1800, matching the earliest available container. The territory and administrative identity of the département are unchanged across 1790-1800, so this is a containment-availability constraint, not a claim that Haute-Garonne did not exist before 1800. If a pre-1800 FRA container row is added later, this entry's start_year should be revisited.

### d-two-letter-code-not-insee

**used FRA-HG (two-letter abbreviation), not FRA-31 (INSEE number)**

The rejected prior answer used FRA-31-1800-2025 (INSEE département number 31), which collided with an existing, unbuilt page. Rather than retry a numeric suffix, this entry follows the dominant subnational pattern <ISO3>-<SUBUNIT>-<start>-<end> using a short letter abbreviation (HG for Haute-Garonne), consistent with how ESP subnational rows use letter codes (ESP-AS, ESP-CA) rather than numeric province codes. This also avoids any future collision with the orphaned FRA-31 code if that page is ever cleaned up and reused.

## Open questions

### oq-pre1800-span

**Whether Haute-Garonne's polity row should eventually start at 1790 rather than 1800**

Haute-Garonne was created on 4 March 1790 as one of the 83 original Revolutionary départements, ten years before this entry's start_year. The gap exists only because the polity table's earliest FRA container row (FRA-1800-1919) begins in 1800, and the containment gate requires every edge to fall within the container's own span. If a pre-1800 France container row is ever added to the table, this entry's start_year should be reconsidered and possibly moved back to 1790, with a new container edge added for the 1790-1800 gap.

### oq-gadm-fra-missing

**gadm-4.1-adm1 is registered but returns zero FRA features locally**

polygon_source is set to gadm-4.1-adm1 per the routing decision's polygon_route of registered_source_unfetched, but the routing_reasoning notes the local GADM 4.1 file covers only a subset of 81 countries and currently returns 0 features for FRA. Until that file is re-fetched to include France, or a France-specific alternative (IGN ADMIN EXPRESS, Eurostat NUTS3) is registered and its licence checked, polygon_status remains unassigned and no polygon_feature_id can be set. This is the single largest open item blocking this page from advancing past draft.

### oq-commune-reassignments

**Minor commune-level boundary adjustments across 1800-2025 are not modeled**

Haute-Garonne's départemental outline has been essentially stable since 1790, but individual communes have occasionally been reassigned between neighbouring départements over the two centuries this entry spans (as is true generally in France). No systematic check has been done for whether any such reassignment affected Haute-Garonne specifically, and the eventual polygon (once fetched) will represent a single modern vintage rather than tracking these adjustments through time.

### oq-toulouse-metro-overlap

**No check for overlap with any Toulouse-metropolitan-area subnational row**

Haute-Garonne's préfecture is Toulouse, France's fourth-largest metropolitan area. No other FRA subnational polity rows currently exist in the table (this entry sets the precedent, per the prompt's own note that FRA has 0 existing subnational rows), so there is no present overlap risk -- but if a future entry is created for a Toulouse metropolitan/urban-community unit (e.g. Toulouse Métropole), its territory would nest inside Haute-Garonne and the container chain would need to reflect that rather than routing such a unit's data to this département-level row.
