# Beni (department of Bolivia)

## Summary

Beni is a department (admin-1 unit) of Bolivia in the northern lowlands, covering the Amazonian llanos drained by the Mamoré, Beni and Iténez/Guaporé rivers. It was created in 1842 when the Bolivian government split the sparsely-populated Amazonian territories off from the older Andean departments, giving the lowland cattle- and rubber-producing region its own administrative status; the department capital is Trinidad. Beni's own borders changed once in this span: in 1938 the northern portion was separated off to form the new department of Pando, so the polygon that will eventually represent post-1938 Beni is smaller than the 1842-1938 unit. This entry is `type: subnational` because Beni has never been sovereign — it is carried here as a first-level administrative reporting unit inside Bolivia, following the same convention already applied to Spain's provinces and Argentina's provinces in this table (department/province-level admin-1 units that appear as distinct reporting units in agricultural and trade statistics get their own polity row rather than being folded into the national row).

**Why this entry exists.** This row is created directly from a routing decision (unit_id `BOL-BEN`) rather than from a specific data extract examined here: the routing stage identified Beni, a Bolivian department, as a first-level administrative unit that the country's routing convention for Bolivia requires to have its own polity row, and flagged that no existing candidate polity represented it. Two BEN-* rows already exist in the table, but they are Benin (a West African country) — a false match produced purely by the ISO3-like string "BEN" resembling Beni's own abbreviation, not by any territorial overlap; the routing reasoning explicitly rules these out as candidates. What confirms Beni is a distinct, long-standing administrative entity rather than an artefact of the matcher is Bolivia's own department history: Beni was carved out of the Amazonian territories in 1842 and has been administered separately from La Paz, Santa Cruz and the other departments ever since, appearing as a first-level unit in Bolivian censuses and agricultural statistics from that date. Because Bolivia had no prior subnational rows in this table, this entry sets the country's own precedent for how its departments will be coded (`BOL-<SUBUNIT>-<start>-<end>`) rather than following an established BOL convention.

**Territory description:** Beni department occupies the northern lowlands of Bolivia, a flat Amazonian plain of savanna and tropical forest drained by the Mamoré, Beni, and Iténez (Guaporé) rivers, bordering Brazil to the north and east. Its capital is Trinidad. On a modern map, present-day Beni (post-1938, after Pando split off) covers roughly 213,000 km2 — one of Bolivia's largest departments by area despite low population density, historically built on cattle ranching and, in the 19th and early 20th centuries, rubber extraction. Before 1938 the department was larger, since it included the territory that became Pando; no km2 figure for the pre-1938 extent is given here because no polygon (proxy or otherwise) has been attached to compute or cite one — any figure would need to come from a period source (e.g., a 19th/early-20th-century Bolivian statistical yearbook) rather than from GADM's present-day boundary.

## Decisions

### d-code-format-ben-not-single-letter

**Used BOL-BEN-1842-2025 rather than a single-letter ISO 3166-2 subdivision code**

Bolivia's official ISO 3166-2 code for Beni is BO-B (a bare letter), but the dominant pattern in this table for subnational rows is <ISO3>-<SUBUNIT>-<start>-<end> using a short mnemonic abbreviation (e.g. ESP-AS for Asturias, ESP-CA for Cantabria), not the raw ISO 3166-2 letter. A single-letter subunit (BOL-B-1842-2025) would be harder to read and easier to mistype than a three-letter mnemonic, so BEN was kept from the routing decision's own unit_id. This does create a visual near-collision with the unrelated country Benin's BEN-* rows, which is exactly the confusion the routing reasoning flagged as a wrong-match risk for data routing (not for the code itself, since the ISO3 prefix BOL disambiguates it); noted here so a future reader does not assume BOL-BEN and BEN-* share any territory.

### d-container-split-into-four-eras

**Split the container into four edges instead of the single BOL-1938-2025 edge the routing decision proposed**

The routing decision's routing_concerns explicitly flagged that a single container edge would leave 1842-1938 uncontained, since the current national row BOL-1938-2025 only starts in 1938. Reading the polity table's four BOL national eras (1825-1903, 1903-1909, 1909-1938, 1938-2025) and tiling Beni's 1842-2025 span across all four that overlap it (starting the first edge at 1842, not 1825, since Beni did not exist before 1842) avoids the 61-year gap that a single edge would have created and satisfies the containment gate's requirement that no edge fall outside either party's own span.

## Open questions

### oq-gadm-bolivia-not-cached

**GADM 4.1 adm1 for Bolivia is not present in the locally cached GeoPackage**

The routing decision confirms that data/geodata/gadm-4.1/gadm41_adm1.gpkg is a subset covering only 81 countries and does not include Bolivia, so the candidate feature id BOL.2_1 for Beni is an unverified guess based on GADM's typical numbering convention, not a confirmed lookup. Before this entry can move from polygon_status unassigned to assigned, the full/global GADM 4.1 adm1 layer (or at minimum a Bolivia-specific extract) needs to be fetched and the feature id for Beni confirmed against GADM's own attribute table (NAME_1 = 'Beni'), since GID_1 numbering is not guaranteed to follow alphabetical or any other predictable order across all countries.

### oq-pre1938-territory-not-modeled

**No polygon or km2 figure exists yet for Beni's larger, pre-1938 (pre-Pando-split) extent**

Beni's 1842-1938 territory included the area that became Pando department in 1938, so even once GADM 4.1's present-day Beni boundary (BOL.2_1) is fetched and attached, it will only be a correct representation of Beni from 1938 onward; using it as a proxy for 1842-1938 would understate the department's actual historical extent, potentially significantly, since Pando is itself a large Amazonian department. Whether this warrants a second polygon feature (a constructed union of modern Beni + Pando) for the 1842-1938 sub-span, or whether the whole 1842-2025 row should instead be split at 1938 into two rows, is unresolved and should be revisited once GADM Bolivia data is available and an area comparison can actually be computed.
