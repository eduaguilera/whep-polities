# Netherlands Antilles

## Summary

WHEP aggregate reporting-area row for FAOSTAT/FABIO area code 151, Netherlands Antilles. This is a historical/statistical reporting unit used by source data and must be represented as its own aggregate polity row. The 1961-2010 range follows the current WHEP CBS rows and ends with the dissolution of the Netherlands Antilles in 2010.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** Bonaire/Sint Eustatius/Saba, Curacao, and Sint Maarten current GADM 4.1 adm0 polygons.
- **Proxy note:** The current successor-island union is used for the reporting-area polygon.

## Sourced Claims

- `inst/extdata/regions.csv` in WHEP records `ANT`, area code 151, as Netherlands Antilles.
- `inst/extdata/harmonization/regions_full.csv` marks this as a CBS reporting row grouped under Latin America Other.

## Polygon status consolidated (added 2026-07-28)

`polygon_status` changed from `derived` to **`assigned`** in the polygon_status
vocabulary consolidation ([log lint-consolidate-polygon-status](../log.md#lint-consolidate-polygon-status)).

`derived` described *how* the polygon was made — by the `reporting-areas`
builder — rather than what it claims, and it was not one of the values
`scripts/validate_polygons.py` check C recognises, so this row could have
declared a polygon it did not have and nothing would have failed. It does have
one: the attached geometry measures **795 km2** in an equal-area projection
(the Netherlands Antilles islands as the builder composes them). That geometry *is* this reporting area's territory rather than a
stand-in for another entity, which is what `assigned` means. The row is now
covered by check C, and by check A whenever `polygon_area_km2` is filled in
(it is currently null, so the area comparison is skipped). The builder
provenance is unchanged and stays documented under Territorial Extent.
