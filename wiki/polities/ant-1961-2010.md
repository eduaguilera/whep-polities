# Netherlands Antilles

## Summary

> **`polygon_status` migrated derived -> assigned (2026-07-29).** `derived` is a legacy value that predates the documented vocabulary in [wiki/README.md](../README.md#page-schema), which says not to use it in new pages. It was never migrated, so the manifest's `claims_polygon_status` set omitted it and consumers were told this row does not claim a polygon. The polygon is composed from its members by `scripts/sources/reporting-areas/build.py`, so it IS this row's territory by construction. See [lint-polygon-status-vocabulary](../log.md#lint-polygon-status-vocabulary).


WHEP aggregate reporting-area row for FAOSTAT/FABIO area code 151, Netherlands Antilles. This is a historical/statistical reporting unit used by source data and must be represented as its own aggregate polity row. The 1961-2010 range follows the current WHEP CBS rows and ends with the dissolution of the Netherlands Antilles in 2010.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** Bonaire/Sint Eustatius/Saba, Curacao, and Sint Maarten current GADM 4.1 adm0 polygons.
- **Proxy note:** The current successor-island union is used for the reporting-area polygon.

- `inst/extdata/harmonization/regions_full.csv` marks this as a CBS reporting row grouped under Latin America Other.
