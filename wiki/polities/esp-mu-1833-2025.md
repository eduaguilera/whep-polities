# Murcia (province of Spain)

## Summary

This entry captures the province of Murcia, one of Spain's 50 provinces, created in the 1833 territorial reform carried out under Javier de Burgos that divided Spain into provinces largely along the boundaries of the historic Kingdom of Murcia. It is `type: subnational` because Spain (ESP-1800-2025) holds sovereignty throughout; this row exists only to carry the province-level reporting territory that some statistical series (identified in this pipeline run under the NUTS code ES620) tabulate separately from the national total. Murcia today forms its own single-province Autonomous Community (Region de Murcia), one of only a handful of Spanish provinces that are also complete autonomous communities, which makes the province boundary and the modern first-order administrative boundary identical and easy to verify against a current map.

**Why this entry exists.** Input data: statistical rows keyed to the NUTS unit ES620 / admin name "ES620" for Spain, identified by this pipeline's routing pass as province-level data for Murcia, part of a batch of Spanish NUTS-coded units (ES112-ES241) being routed under the same default 1833-start rule. Previously this data had no dedicated home: it could only have been matched to ESP-1800-2025 (the national total, which contains but does not represent this province specifically) or misrouted to a same-initial-letter province such as ESP-MD (Madrid) or ESP-CO (Cordoba), both of which are different territories entirely. GADM 4.1 confirms Region de Murcia as a genuine, distinct adm1 unit, and it is one of Spain's uniprovincial autonomous communities today, which is independent confirmation (beyond the raw NUTS code) that this is a real, bounded administrative territory rather than a reporting artefact. Federico-Tena-style province-level Spanish series and the sibling ESP-XX-1833-2025 entries already in the wiki establish the convention that each of the 1833 Javier de Burgos provinces gets its own row; Murcia is the same category of unit as those already created.

## Territorial extent

**Polygon:** `mapspain-ign` source, feature id `30` (INE/IGN province code `cpro=30`, Region de Murcia), the same registered source and id-scheme already used for the seven sibling ESP-XX-1833-2025 province entries (Asturias, Cantabria, Cordoba, Lugo, Madrid, Ourense, Pontevedra). `polygon_status: assigned` rather than `proxy`, since this is the source's own registered feature for this exact administrative unit, not a period-reuse from elsewhere.

**Territory description:** the province of Murcia occupies the southeastern corner of the Iberian Peninsula, bordered by Alicante and Albacete to the north, Almeria to the west, and the Mediterranean coast to the east, centred on the city of Murcia. It corresponds exactly to the modern Autonomous Community of Region de Murcia (one of Spain's uniprovincial autonomous communities). Its area, as measured from the attached mapspain-ign geometry, is approximately **11,313 km2** — this is a measurement of the polygon, consistent with the province's well-documented modern extent, not an independent historical figure.

**Vintage risk:** the polygon reflects present-day IGN province boundaries applied back to 1833. Spanish provincial boundaries have changed little since the 1833 division, so this risk is assessed as low, consistent with the same proxy convention already accepted for the other ESP province pages in this cohort.

## Decisions

### d-code-follows-esp-nuts-pattern

**Code follows the dominant ISO3-SUBUNIT-start-end pattern used by sibling ESP provinces**

ESP-MU-1833-2025 follows the same convention as the seven existing ESP subnational rows (ESP-AS, ESP-CA, ESP-CO, ESP-LU, ESP-MD, ESP-OR, ESP-PO), all provinces created by the same 1833 Javier de Burgos reform and all carrying the same 1833-2025 span. MU is the standard two-letter INE/ISO 3166-2 subdivision code for Murcia (ES-MU), distinct from MD (Madrid) and CO (Cordoba), so there is no collision risk with existing codes. No bespoke name is warranted: Murcia is an ordinary administrative province, not a historical polity with its own name distinct from the modern subdivision, unlike ALK or HYD.

## Open questions

### oq-mapspain-vintage-risk

**mapspain-ign polygon reflects present-day IGN province boundaries applied back to 1833**

The polygon feature (cpro=30, Region de Murcia / Murcia province) comes from mapspain-ign's current INE province boundaries, standing in as a proxy for the entire 1833-2025 span. Spanish provincial boundaries have been largely stable since the 1833 division, so the risk is considered low, following the same convention already accepted for the other ESP-XX-1833-2025 provinces (AS, CA, CO, LU, MD, OR, PO). However, no minor boundary adjustments between Murcia and its neighbouring provinces (Albacete, Alicante, Almeria) over nearly two centuries have been checked against historical cartography, so small vintage drift cannot be ruled out and would not currently be caught by any gate.

### oq-registry-present-locally-flag

**polygon_route flagged present_locally=False despite mapspain-ign already backing 7 ESP entries**

The routing decision noted that mapspain-ign's source registry entry is flagged present_locally=False even though seven ESP province pages already cite this source successfully, which suggests either the registry flag is stale or the source file is fetched/cached at build time rather than stored locally. This was not resolved before creating this page and should be verified in the pipeline: if the flag is accurate and the file truly is not locally present, the polygon_status here may need to be revisited from assigned to something more provisional.
