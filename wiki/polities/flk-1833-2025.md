# Falkland Islands

## Summary

This row tracks the Falkland Islands as a British Crown Colony / British Overseas Territory from 1833 to 2025. The territory comprises East Falkland, West Falkland, and ~776 smaller islands (~12,173–12,397 km²) in the South Atlantic.

Why this entry exists: fao1952 contains 19 rows attributed to "Falkland Islands" (1937–1951, cattle/sheep/horses/land use/population) with no WHEP polity to receive them. Routing to GBR-1921-2025 would produce a ~20× territorial overstatement (~242,000 km² vs ~12,397 km²).

Boundary stable since 1833; GADM-4.1 modern polygon is a valid period proxy.

## Contradictions

### the iia "fertilizer, mixed" series is GUANO PRODUCTION

Recorded 2026-08-18 while clearing the wiki notes queue. **A queued note called
these values implausible; they are not, and the problem is the item name.**

IIA's six rows for this polity, 1914-1919, carry the item `fertilizer mixed`
(tonnes): 8,603 / 7,109 / 9,563 / 986 / 0 / 606. Traced to the raw IIA extract
they match, value for value, the product **`fertilizers: guano, natural`,
variable `production`**, under the raw label
`british falkland islands and dependencies`.

So this is **guano output**, an extractive industry, not fertiliser *consumption*.
Roughly 8,600 t/yr is entirely plausible: the same raw label carries guano
**exports** of 17,672 t (1926), 29,993 t (1927) and 24,216 t (1929) — larger
still — and the Dependencies' seabird colonies and whaling stations were the
source. The 1917-1919 fall to 986 / 0 / 606 is wartime shipping, not a
territorial question.

The queued note read the figures as "not a plausible Falkland Islands quantity"
and pointed at `iia-layerb-magnitude-scale-inconsistent`. **That is withdrawn**:
the magnitudes are right and no scale defect is involved.

What survives is a labelling problem, and it is already registered:
`state/item_equivalences.csv` records `fertilizer mixed` <- `fertilizers: guano,
natural` as `approved_aggregation`, on the grounds that guano is a genuine
fertiliser. That is defensible as a *mapping*, but for this territory the series
is production of a mineral export, so a consumer reading "fertilizer, mixed" here
will take it for input use and be wrong about what the number is. Compare the same
registry's `australia` and `french polynesia` `p` series, which are Christmas
Island and Makatea **phosphate mining** for exactly the same reason.
