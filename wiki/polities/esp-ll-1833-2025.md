# Lleida (province of Spain)

## Summary

Lleida (Catalan; Spanish "Lérida") is one of Spain's 50 provinces, created along with the rest of the current provincial map in the 1833 Javier de Burgos territorial reform that replaced the old kingdom/intendancy divisions with a uniform grid of provinces under a single national administration. It sits in the northwest of Catalonia, bordering France and Andorra to the north, Huesca (Aragon) to the west, Tarragona to the south, and Barcelona and Girona to the east. The province combines the high Pyrenean valleys (Val d'Aran, Pallars, Alta Ribagorça) with the flat irrigated plain of the Segrià around the provincial capital, also called Lleida. `type: subnational` is used because this is a first-order administrative division of a sovereign state (Spain), not an independent polity in its own right — Spain held sovereignty over this territory throughout the entire 1833-2025 span, and the row exists purely to carry statistics reported at the provincial level rather than to represent a separate country.

**Why this entry exists.** This entry captures data reported under the label "Lleida" (or "Lérida") for Spain, at the province level, which prior to this pipeline run had no dedicated polity row and would have defaulted to the national total ESP-1800-2025 — a container roughly 32x the area of this single province and covering data from 49 other provinces plus autonomous cities. Routing province-level series into the national total silently aggregates distinct regional economies (Segrià irrigated agriculture, Pyrenean livestock and forestry, hydropower in the Val d'Aran) into one figure, which is exactly the kind of scale mismatch this pipeline is built to catch. Lleida is confirmed as a distinct, stable administrative unit by its continuous existence as one of Spain's 50 provinces since the 1833 Javier de Burgos reform, by INE's standard `cpro` provincial code vocabulary (Lleida = 25), and by the mapspain-ign dataset digitising it as a discrete polygon at the same code. This is the same treatment already applied in this pipeline run to the sibling provinces A Coruña, Asturias, Cantabria, Lugo, Ourense and Pontevedra: no existing ESP subnational row named or covered Lleida specifically, and the national total is the wrong container for provincial statistics.

## Territorial extent

**Polygon status:** `assigned`. Sourced from `mapspain-ign`, feature id `25`, the INE/mapspain-ign `cpro` provincial code for Lleida. This is a `registered_source_feature` route, not a construction — the same route and source already used in this pipeline run for the sibling Spanish provinces (A Coruña, Asturias, Cantabria, Lugo, Ourense, Pontevedra), since GADM 4.1's adm1 level for Spain represents autonomous communities rather than provinces and has zero name matches for ESP provinces.

**Vintage risk:** low. Spanish provincial boundaries have been essentially stable since the 1833 reform that created them; mapspain-ign digitises the present-day (2025) boundary, and no province-level boundary change affecting Lleida is documented across the 1833-2025 span, so the modern boundary is treated as a valid proxy for the entire period.

**Territory description:** Lleida province covers roughly 12,150 km2 in the northwest of Catalonia, Spain. It runs from the Pyrenean crest on the French and Andorran border (comarques of Val d'Aran, Alta Ribagorça, Pallars Sobirà, Pallars Jussà, Alt Urgell) down through pre-Pyrenean hill country (Solsonès, Noguera) to the flat, heavily irrigated Segrià plain around the provincial capital, Lleida city, near the Aragon border. A reader can locate it on a modern map as the inland (non-coastal) of Catalonia's four provinces, sharing borders with Huesca (Aragon) to the west, Tarragona to the south, Barcelona and Girona to the east, and France/Andorra to the north.

## Predecessors and successors

No predecessor: the province was created directly by the 1833 Javier de Burgos reform from parts of the earlier Catalan territorial divisions (corregimientos), which this pipeline does not carry as separate polity rows. No successor: the province remains current as of 2025, hence the open `end_year` of 2025 following the country convention already applied to the sibling ESP provincial rows (A Coruña, Asturias, Cantabria, Lugo, Ourense, Pontevedra, Madrid), none of which record a predecessor or successor either.

### d-code-pattern-ll

**Used the dominant ISO3-SUBUNIT-start-end code pattern with a two-letter INE-style abbreviation**

Lleida is a standard province created in the same 1833 reform as the other Spanish provinces already routed in this pipeline run (Asturias -> AS, Cantabria -> CA, Lugo -> LU, Ourense -> OR, Pontevedra -> PO, A Coruna -> CO), all coded ESP-<2-letter>-1833-2025.
