# Ciudad Real (province of Spain)

## Summary

Ciudad Real is one of Spain's 50 provinces, created in the 1833 Javier de Burgos territorial reform along with the rest of the modern province system, and it has existed continuously since with no boundary reorganization known to have altered its extent. This is a `type: subnational` entry, not a national polity: sovereignty over the territory has belonged to Spain (ESP-1800-2025) throughout the entry's span, and the entry exists to carry data reported at province scale rather than to represent an independent state. It joins seven existing ESP province siblings (Asturias, Cantabria, A Coruña, Lugo, Madrid, Ourense, Pontevedra) already routed the same way: create a province-level polity where no existing polity name-matches the unit, following the sibling pattern rather than the two exceptions in the subnational-code table (ALK, HYD, RYU) reserved for territories with a pre-existing historical identity distinct from a modern administrative creation. Ciudad Real has no such prior identity — its territory before 1833 was administered as part of the old Kingdom of Castile / La Mancha region without a province-level tier of its own — so the ordinary ESP-<SUBUNIT>-<start>-<end> code applies.

**Why this entry exists.** Input data: the routing unit ES422 (admin_name ES422), corresponding to Spain's INE province code 13 / NUTS-3 code ES422, covering rows for the country "Spain" over the province's data span. Per the routing decision, this and sibling units ES112 through ES241 were previously unmatched to any existing polity in the database (no name match to any prior ESP entry), except ES111 which matched an existing A Coruña polity by name. Ciudad Real had no such match: the two existing ESP subnational siblings at the time of this decision were A Coruña and Madrid, neither of which represents Ciudad Real's territory. What confirms this unit is a distinct, independently-tracked entity rather than an artifact of the data source: Ciudad Real is one of the 50 provinces created by the 1833 Javier de Burgos reform, a foundational and still-current tier of Spanish administrative and statistical geography -- Spain's national statistical office (INE) and all modern administrative sources report at this same province granularity, and no other ESP polity in this database's routing table claims this unit's territory.

## Territorial extent

**Polygon status:** Assigned. `polygon_source: mapspain-ign`, `polygon_feature_id: CR`, looked up by INE province code (cpro=13) / ISO 3166-2 abbreviation ES-CR in the registered mapspain-ign source, the same current-day IGN provincial boundary dataset already used to assign the seven sibling ESP province polities (Asturias, Cantabria, A Coruña, Lugo, Madrid, Ourense, Pontevedra). This is a direct lookup of the feature representing this exact unit, not a proxy borrowed from a different period or a different territory, and it is treated as `assigned` rather than `proxy` because Spanish provincial boundaries have seen negligible reorganization since 1833 -- the same low-vintage-risk basis already accepted for the sibling entries.

**Why this entry exists:** No existing ESP polity name-matches Ciudad Real; the sibling ESP subnational rows created so far are A Coruña and Madrid, and Ciudad Real's own data (routing unit ES422 / admin_name ES422) was previously unmatched rather than misrouted to a wrong existing polity. Its status as a distinct administrative and statistical reporting unit is confirmed by the same 1833 Javier de Burgos reform that created every other Spanish province still tracked individually in Spanish national statistics (INE) today -- Ciudad Real is not merged into any neighboring province's reporting in any modern or historical Spanish administrative source.

**Territory description:** Ciudad Real province sits in south-central Spain, in the autonomous community of Castilla-La Mancha, comprising the southern part of the historical La Mancha plain plus the Sierra Morena foothills along its southern edge (bordering Andalusia). Its capital is the city of Ciudad Real. It borders the provinces of Toledo (north), Cuenca (northeast), Albacete (east), Jaén and Córdoba (south, across the Sierra Morena), and Badajoz (west). The province covers approximately 19,813 km², making it the third-largest Spanish province by area -- a figure a reader can cross-check against modern INE/IGN provincial-area statistics, distinct from and not sourced from this entry's attached polygon geometry.

## Predecessors and successors

No predecessor: Ciudad Real did not exist as a distinct administrative unit before 1833. It was created directly by the Javier de Burgos territorial reform of 30 November 1833, which redrew the map of Spain from the old kingdoms and historic regions (Ciudad Real's territory had previously fallen within the old Kingdom of Castile / La Mancha region, without its own province-level administration) into 49 (later 50) provinces roughly matching modern boundaries. No successor: the province remains a current first-order administrative division of Spain within the autonomous community of Castilla-La Mancha, with no annexation, merger, or abolition since creation, hence the open end_year of 2025.

## Open questions

### oq-mapspain-ign-present-locally-flag

**mapspain-ign's present_locally=False flag conflicts with its active use by 7 sibling rows**

The routing decision flags that the source table lists mapspain-ign as present_locally=False, yet seven sibling ESP province polities (AS, CA, CO, LU, MD, OR, PO) already resolve through this exact source and are in active use with assigned polygons. This discrepancy should be verified by checking whether data/geodata/mapspain-ign/provinces.gpkg actually exists on disk before this route is executed for Ciudad Real; if the file is genuinely absent, the CR feature cannot be fetched despite being the demonstrably correct route, and the ingest step (not the routing decision) would need to resolve or re-flag the source's local availability.

### oq-boundary-vintage-1833-vs-modern

**IGN boundary is current-day; no check for intervening boundary changes since 1833**

The polygon comes from mapspain-ign, a present-day IGN provincial boundary set, reused across the full 1833-2025 span on the premise that Spanish province boundaries have seen negligible change since creation. This has not been individually verified for Ciudad Real specifically -- e.g., whether any municipios were transferred to/from neighboring provinces (Toledo, Cuenca, Albacete, Jaén, Córdoba, Badajoz) in intervening reorganizations. The same assumption underlies the seven already-accepted siblings, so this is a shared open question rather than one unique to this entry, but it has not been falsified for any of them either.

### oq-data-currency-past-2021

**end_year 2025 is open per country convention, but underlying data runs only to 2021**

The routing decision states the data feeding this polity runs to 2021, and end_year=2025 (exclusive) is applied only because the province is still current under the country's open-end convention, not because data has been observed through 2025. If a future ingest finds this province was merged, split, or renamed after 2021 (no such event is known, but has not been checked against a post-2021 administrative source), the open end_year would need correction independent of the data gap itself.
