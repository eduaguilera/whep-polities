# Asia Other

## Summary

WHEP aggregate reporting-area row for residual Asian and Pacific trust-territory entries in WHEP harmonization tables. The 1850-2021 range follows the current WHEP land-footprint production rows for area code 902.

## Territorial Extent

- **Polygon source:** derived WHEP `reporting-areas` source.
- **Components:** British Indian Ocean Territory plus the Pacific Islands Trust Territory proxied by Micronesia, Marshall Islands, Northern Mariana Islands, and Palau current GADM 4.1 adm0 polygons.
- **Proxy note:** This is a residual reporting-area polygon, not a country polygon.

## Sourced Claims

- `inst/extdata/regions.csv` in WHEP records `RASI`, area code 902, as Asia Other.
- `inst/extdata/harmonization/regions_full.csv` lists British Indian Ocean Territory and Pacific Islands Trust Territory under `RASI`.

## Polygon status consolidated (added 2026-07-28)

`polygon_status` changed from `derived` to **`assigned`** in the polygon_status
vocabulary consolidation ([log lint-consolidate-polygon-status](../log.md#lint-consolidate-polygon-status)).

`derived` described *how* the polygon was made — by the `reporting-areas`
builder — rather than what it claims, and it was not one of the values
`scripts/validate_polygons.py` check C recognises, so this row could have
declared a polygon it did not have and nothing would have failed. It does have
one: the attached geometry measures **1,965 km2** in an equal-area projection
(the residual Asian reporting area). That geometry *is* this reporting area's territory rather than a
stand-in for another entity, which is what `assigned` means. The row is now
covered by check C, and by check A whenever `polygon_area_km2` is filled in
(it is currently null, so the area comparison is skipped). The builder
provenance is unchanged and stays documented under Territorial Extent.
