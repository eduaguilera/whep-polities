# Gers (département)

## Summary

Gers is a French département in the Occitanie region of southwestern France, seat at Auch, roughly 100km west of Toulouse. It was created, along with the other original Revolutionary départements, by the law of 4 March 1790 and has held essentially the same boundaries ever since — it is not one of the four documented exceptions (Belfort split from Haut-Rhin in 1871-1922, the Alsace-Lorraine trio annexed/returned 1871-1919, the 1975 Corse split, or the post-1946 overseas départements). This entry is `type: subnational` because it is a sub-unit of a continuously sovereign France: sovereignty and national container membership never changed, only the reporting/administrative tier being tracked. The start_year is set to 1800, not the department's true 1790 creation date, because the whep-polities table currently has no FRA container row earlier than FRA-1800-1871 — an 1790-1800 span would leave the polity uncontained and fail the containment-tiling gate. This is a data-availability constraint on this table, not a claim that Gers did not exist as a département before 1800.

**Why this entry exists.** This entry captures the France admin-1 unit `FRJ24` (Gers) from the routing pipeline's country-conventions pass over French départements: an incoming subnational series keyed to a French administrative unit that had no existing polity row, since the wiki previously only carried national-level France rows (FRA-1800-1871, FRA-1871-1919, FRA-1919-2025). Those national rows are the wrong match for any département-level series because they aggregate the whole of France; a value reported for Gers specifically (e.g. any agricultural or population series keyed at the département level) would be silently over-counted or mis-scaled if routed to a row covering all ~550,000 km2 of France rather than Gers's ~6,257 km2. Federico-Tena and equivalent historical statistical compilations, as well as INSEE's own administrative geography, treat French départements including Gers as the standard sub-national reporting unit for agricultural, demographic, and trade statistics from the Revolutionary period onward, confirming Gers as a distinct, continuously tracked administrative entity rather than an artifact of a single source's labeling.

## Territorial extent

**Polygon status:** Not yet assigned. `polygon_source: gadm-4.1-adm1` is the registered source (feature `FRA.32_1`), but the locally fetched `gadm41_adm1.gpkg` is a curated 81-country subset that excludes France entirely (0 matching features for any French département). This is the `registered_source_unfetched` case: the source is known and registered, the specific France data has simply not been fetched into `data/geodata/gadm-4.1/` yet. `polygon_status: unassigned` reflects that, not a modeling choice. No polygon is constructed from other registered sources because cshapes only carries FRA at the national level, not départements, so there is no fallback geometry to proxy from.

**Territory description:** Gers is a rural département in the Occitanie region of southwestern France, bordered by Landes, Lot-et-Garonne, Tarn-et-Garonne, Haute-Garonne, Hautes-Pyrénées, and Pyrénées-Atlantiques. Its préfecture is Auch. It covers approximately 6,257 km2 (this is the area a reader can look up for the modern département on any current reference; it is NOT a measurement of any polygon attached to this entry, since no geometry is attached yet — see polygon status above). It has held these boundaries with only trivial adjustments since its 1790 creation from parts of the former provinces of Gascony and Armagnac.

## Decisions

### d-start-year-1800-not-1790

**start_year set to 1800, not the department's 1790 creation date**

The country convention for French départements defaults to a 1790 start_year unless one of four listed exceptions applies (Belfort, Alsace-Lorraine trio, Corse split, overseas départements); Gers is none of these, so 1790 would be the convention-correct start. However, the whep-polities table's earliest FRA national container row is FRA-1800-1871 — there is no container row spanning 1790-1800. Since the containment gate rejects any edge falling outside a container's own span, and rejects a member span left partially uncontained, using 1790 here would leave a decade uncontained and fail validation. start_year was therefore set to 1800 to match the earliest available container, with this note flagging that the true administrative start (1790) predates what this table can currently represent for France.

### d-code-avoids-collision

**Polity code FRA-D32-1800-2025 chosen to avoid a code collision**

The dominant subnational naming pattern in this table is <ISO3>-<SUBUNIT>-<start>-<end>, and the natural subunit token for Gers would be GERS, giving FRA-GERS-1800-2025. That exact code is already held by a different page in wiki/polities/ (a page whose row is not present in the built table, per the rejection notice), so it cannot be reused for this distinct territory (routing unit FRJ24, admin_name 'FRJ24'). D32 (Gers's INSEE département number, 32) is used as the subunit token instead, giving FRA-D32-1800-2025, which is free and still legible as identifying Gers specifically.

If a FRA-1790-1800 (or similar) national row is ever added, this entry's start_year should be revisited and potentially moved back to 1790 with a new container edge added.
