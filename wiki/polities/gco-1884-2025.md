# German colonies Oceania (RETIRED — was an impossible row)

## Decision: retired (2026-07-28)

> **`polygon_status` migrated excluded -> unassigned (2026-07-29).** `excluded` is a legacy value that predates the documented vocabulary in [wiki/README.md](../README.md#page-schema), which says not to use it in new pages. It was never migrated, so the manifest's `claims_polygon_status` set omitted it and consumers were told this row does not claim a polygon. This row has no geometry at all, which is exactly what `unassigned` means. See [lint-polygon-status-vocabulary](../log.md#lint-polygon-status-vocabulary).


**`status: retired`, decided by Catalin Covaci.** This row asserted that German
colonial territory in the Pacific exists in 2025, which is impossible. It is
withdrawn from polity resolution rather than deleted, and the reasoning for each
part of that choice is below.

**Why retired rather than corrected to GCO-1884-1914.** Option 2 of
[oq-umbrella-deletion-proposal](#oq-umbrella-deletion-proposal) made a corrected
row conditional on data existing for 1884-1914. Checked, and none does: no
FAOSTAT reporting area maps to the `GCO` prefix (0 rows in
`data/final/faostat_area_polity_map.csv`), and no source assertion targets it. A
corrected row would carry no data and would still be an aggregate that CShapes
has no polygon for. If German Pacific data is ever ingested, the right answer is
option 3 — separate rows for German New Guinea, German Samoa and German
Micronesia, each with its own extent — not a revived umbrella.

**Why retired rather than deleted.** Two pages reference this code in prose:
[nru-1888-2025](nru-1888-2025.md) and [mhl-1874-2025](mhl-1874-2025.md) both
record that their territory was part of German Pacific territory until 1914.
Those statements are historically accurate and worth keeping. `retired` keeps the
code resolvable so they do not dangle, while `DEAD_STATUS` excludes the row from
every matcher and from the crosswalk — which is precisely what that mechanism is
for. Deleting it would break two true references to remove one false row.

**Downstream effect.** The row stays in `polities_database.csv` and in the WHEP R
package's `polities` table for provenance, moves from `live_polity_codes` to
`dead_polity_codes` in the manifest, and changes `identity_sha256`. Nothing
routed to it before (it was unreachable from every reporting area), so no data
attribution changes.

## Summary

This row as currently structured in the WHEP CSV is almost certainly an error. "German colonies Oceania" with end_year=2025 implies that German colonial territory in the Pacific exists to the present day, which is historically impossible: Germany lost all its Pacific colonial territories during and after World War I (1914–1919), and they were redistributed as League of Nations mandates to Australia, New Zealand, and Japan. The CSV cow_code=255 is Germany (COW ccode=255, stateabb=GMY/GFR), which is the metropolitan German state — not a colonial aggregate. The row appears to be a legacy placeholder or umbrella artifact that has not been corrected. **This page documents the anomaly and recommends deletion or restructuring of the row.** See [Open questions](#oq-umbrella-deletion-proposal) for the proposed correction.

## Territorial extent

**Polygon:** `polygon_status: excluded`, `polygon_source: none`. Earlier
iterations of this row had `polygon_feature_id: 255` pointing at CShapes
mainland Germany — an obvious bug that coloured a row labelled "Oceania"
as Central Europe on the map. Until the row is restructured per
[oq-umbrella-deletion-proposal](#oq-umbrella-deletion-proposal), no
polygon is attached.

German colonial territory in the Pacific (1884–1914/1919) consisted of:

- German New Guinea (Kaiser-Wilhelmsland + Bismarck Archipelago + northern Solomons), acquired 1884–1885
- German Samoa (western Samoa), acquired 1899
- German Micronesia (Caroline, Marshall, and Mariana islands, except Guam), acquired 1899 from Spain

CShapes 2.0 does not record a "German colonies Oceania" aggregate polygon. CShapes cowcode=255 refers to metropolitan Germany (Prussia/German Empire/Federal Republic), with the largest time-step area being 70.15 sq deg (the German Empire 1886–1919 including European territory). No Pacific colonial polygon is associated with cowcode=255 in CShapes. [cshapes-2.0 §scope](../sources/cshapes-2.0.md#scope)

## Predecessors and successors

The German Pacific colonies were administered 1884–1914 (German New Guinea, Samoa) and 1899–1914 (Micronesian islands). After WWI:

- German New Guinea → Australian mandate (1920–1975), then Papua New Guinea (PNG-1975-2025)
- German Samoa → New Zealand mandate, then independent Samoa (WSM-1900-2025 in WHEP)
- German Micronesia → Japanese mandate (1919–1944), then U.S. Trust Territory, then independent Micronesia/Marshall Islands/Palau/CNMI

## Sourced claims

- CShapes 2.0 records no Oceania colonial polygon for Germany (cowcode=255). CShapes covers dependencies=TRUE but the Pacific German colonies ended before 1919; CShapes temporal coverage starts in 1886, so some German colonial time-steps may exist but are not aggregated under a GCO code. [cshapes-2.0 §scope](../sources/cshapes-2.0.md#scope)
- COW ccode=255 refers to metropolitan Germany (Germany/Prussia), not a colonial aggregate. The COW state list records Germany with start dates in 1816 (Prussia) through the present Federal Republic. [cow-state-system-v2024 §key-dates](../sources/cow-state-system-v2024.md#key-dates)
- German colonial activity in the Pacific began in 1884 (protectorate over northern New Guinea and the Marshall Islands) and ended with WWI and the Treaty of Versailles (1919). [database](../../data/final/polities_database.csv)

## Contradictions

**end_year=2025 is historically impossible.** Germany has had no Pacific colonial territory since 1919. This is either a data entry error (end_year should be approximately 1919) or the row is a legacy umbrella placeholder that was never corrected. The row conflicts with the actual historical record.

**cow_code=255 is metropolitan Germany.** Assigning the metropolitan German state's COW code to a "German colonies Oceania" aggregate implies a false continuity between the German state and a colonial aggregate that no longer exists. This is inconsistent with how other colonial rows are coded in the WHEP database.

## Open questions

### oq-umbrella-deletion-proposal

This row is a strong candidate for deletion or restructuring. Options:

1. **Delete** GCO-1884-2025 entirely if no trade data is actually attached to this row for the period 1884–1914. Check whether data_sources (FT; FAOSTAT; M49; CShapes) contain actual GCO-coded observations.
2. **Correct end_year** to 1914 or 1919 and fix cow_code. If trade data exists for 1884–1914, a corrected row GCO-1884-1914 (or GCO-1884-1919) with appropriate polygon(s) may be legitimate.
3. **Restructure** into sub-rows matching the individual German Pacific colonial territories if different polygons are needed.

**RESOLVED 2026-07-28 (Catalin Covaci): option 1, by retirement rather than
deletion.** The condition option 1 rests on was checked and holds — no data is
attached to this row from any source, and no reporting area maps to `GCO`. It is
retired rather than deleted so that the two pages referencing the code in prose
([nru-1888-2025](nru-1888-2025.md), [mhl-1874-2025](mhl-1874-2025.md)) keep a
resolvable target. See [Decision: retired](#decision-retired-2026-07-28).
