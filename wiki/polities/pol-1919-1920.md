# Poland (1919-1920)

## Summary

This row tracks Poland for **2 years**, during the border-settling
period [database](../../data/final/polities_database.csv).

Polish borders still being settled. The Treaty of Saint-Germain
(10 September 1919) incorporated Galicia (formerly Austrian territory)
into Poland. The Polish-Soviet War (1919–1921) was ongoing, with a
major Polish expansion following the armistice of October 1920.

Predecessor: [pol-1918-1919](pol-1918-1919.md) -- initial independence.
Successor: [pol-1920-1921](pol-1920-1921.md) -- Treaty of Riga period.

## Territorial extent

- **Polygon source.** `CShapes 2.0`, gwcode=290, feature gwsdate=**1919-09-10**
  (Treaty of Saint-Germain). Area ~**256,573 km²**.
- **Polygon choice rationale.** Galician agricultural data (hops, rye, grain)
  attributed to this polity reflects the post-Saint-Germain extent.
  The earlier CShapes feature (gwsdate=1919-06-28, post-Versailles,
  ~177,762 km²) excludes Galicia and would understate the actual
  territorial extent by ~44%. The 1919-09-10 feature is therefore the
  correct polygon for the bulk of production data assigned to this row.
- **Polygon status: `polygon_vintage_drift`.** A residual ~11%
  understatement remains for data covering October–December 1920: the
  post-Polish-Soviet-War expansion (gwsdate=1920-10-07, ~284,598 km²)
  is captured only in the successor row POL-1920-1921. Data for that
  sub-period is therefore attributed to a polygon ~11% smaller than
  the actual territorial extent.
- **COW code 290** [database](../../data/final/polities_database.csv).
  COW code POL, 290, from 1918-11-03 to 1939-09-27
  [cow-state-system-v2024 §key-dates](../sources/cow-state-system-v2024.md#key-dates).

## Sourced claims

- **1919-06-28: Treaty of Versailles.** Confirmed Poland's western
  borders, including the "Polish Corridor" (West Prussia/Posen from
  Germany) and access to the Baltic Sea via the Free City of Danzig
  arrangement. CShapes records ~177,762 km² at this date.
  [database](../../data/final/polities_database.csv)
- **1919-09-10: Treaty of Saint-Germain.** Settled the Galician
  border (formerly Austrian territory). CShapes records ~256,573 km²
  at this date. Galician agricultural production data (hops, rye, grain)
  is attributed to the post-Saint-Germain Poland.
  [database](../../data/final/polities_database.csv)
- **1919-1921: Polish-Soviet War.** Ongoing conflict over the eastern
  border. The October 1920 armistice/expansion (~284,598 km²) is
  handled in the successor row POL-1920-1921.
  [database](../../data/final/polities_database.csv)

## Approximation note

The polygon (1919-09-10, ~256,573 km²) is accurate for January–September
1920 data but understates by ~11% for October–December 1920 data, when
Poland's territory was ~284,598 km² (post-Polish-Soviet-War expansion).

A sub-year split (e.g. POL-1919-1920a / POL-1919-1920b at 1920-10-07)
is not currently feasible under the year-keyed data model. This
approximation is documented here; the `polygon_vintage_drift` flag
signals that downstream users should account for this when using
late-1920 production figures.

## Polygon caveat (added 2026-07-24)

`polygon_area_km2` corrected from **256,573** to **177,754 km²** by
`scripts/validate_polygons.py`, which found a 31% divergence from the attached
geometry.

177,754 km² is what the CShapes 1919-1920 feature actually measures, and it is
the plausible figure for this transitional row: Poland's eastern border was not
settled until the **Treaty of Riga (18 March 1921)**, so the 1919-1920 state was
substantially smaller than the ~389,000 km² interwar republic. The former value
appears to have been carried from a later date. `polygon_status` remains
`polygon_vintage_drift`, which correctly flags that borders were moving
throughout this window.
