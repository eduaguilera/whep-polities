# wiki/sources/pdfs/

Local cache of primary-source PDFs referenced by `wiki/sources/*.md` files.

**Not checked into git.** Each PDF is copyrighted; the institutional
license under which it was downloaded does not permit redistribution.
The source files in `wiki/sources/` contain the citation, short quoted
excerpts, and the SHA-256 of the PDF so a future reader can verify
they have the same file on disk.

To re-obtain a PDF, look up the DOI recorded in the corresponding
source file and download via your own institutional access.
