# Source slugs declared in polity-page `sources:` frontmatter that resolve to NO record
# under wiki/sources/, and are accepted as unregistered FOR NOW.
#
# A slug in this list is a citation that looks like evidence and is not: the page names a
# source, nothing in the repo can open it, and the verification pipeline reads the page as
# evidence anyway (issue 19). scripts/validate_declared_sources.py fails on any slug NOT in
# this list, and equally on any line here whose slug now resolves or that no page declares
# any more -- a stale entry silently accepts the next page that mistypes that slug.
#
# THIS FILE IS A WORKLIST, ORDERED BY EXPOSURE, in the same spirit as
# validate_page_depth_baseline.txt. `rows` is the layer-B row count of the data-receiving
# pages naming the slug (`layerb_data_rows` in
# pipelines/polity-autoimprove/state/territory_basis.csv), which is issue 19's priority
# order: fix what actually receives data first.
#
# MEASURED 2026-08-17. On main, 146 of 775 pages declared one of 38 unregistered slugs.
# The commit that added this gate cleared six of them -- one by registering the source
# (wiki/sources/gadm-4.1.md, 46 pages) and five by correcting the slug on 53 pages, where
# the page had written scripts/sources.yaml's MACHINE slug or a case variant instead of the
# readable record's name: CShapes -> cshapes-2.0 (22 pages), gadm-4.1-adm0 -> gadm-4.1 (23),
# cliopatria -> cliopatria-v0.1.3 (6), paine-2024 -> paine-et-al-2024 (1),
# federico_tena -> federico-tena-2019 (1). 32 slugs on 105 page references remain, and they
# fall into four kinds, named below because the kind IS the fix.
#
# KIND 1 -- NOT A SOURCE AT ALL. `database` names this database itself, so a page citing it
# cites the artefact the page is the source of truth for. That is the circularity issue 19
# describes, in one word, on 18 pages holding 7,153 rows. The fix is to replace it with the
# source the claim actually came from, or delete it; it is NOT to register a page.
database                        # 18 pages, 13 data-receiving, 7,153 rows -- self-citation, delete or replace
whep-regions                    # 16 pages,  0 data-receiving,     0 rows -- the reporting-area convention, not a source; the record would be a wiki page under docs, not wiki/sources

# and `iia`/`iia-agricultural-statistics`/`iia-cotton` the same IIA yearbooks under three;
